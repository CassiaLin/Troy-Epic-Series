| 1 | αὐτὰρ ἐπεὶ κόσμηθεν ἅμʼ ἡγεμόνεσσιν ἕκαστοι, | 待雙方各自在統帥的率領下列陣完畢後， |
| 2 | Τρῶες μὲν κλαγγῇ τʼ ἐνοπῇ τʼ ἴσαν ὄρνιθες ὣς | 特洛伊人便伴著喧嘩與呼喊聲前進，宛如飛鳥一般， |
| 3 | ἠΰτε περ κλαγγὴ γεράνων πέλει οὐρανόθι πρό· | 正如鶴群在天際發出的鳴叫聲一般； |
| 4 | αἵ τʼ ἐπεὶ οὖν χειμῶνα φύγον καὶ ἀθέσφατον ὄμβρον | 那鶴群逃過了冬日的酷寒與無盡的暴雨， |
| 5 | κλαγγῇ ταί γε πέτονται ἐπʼ ὠκεανοῖο ῥοάων | 便一路鳴叫著，飛越俄刻阿諾斯的水流， |
| 6 | ἀνδράσι Πυγμαίοισι φόνον καὶ κῆρα φέρουσαι· | 為那皮格米人帶去殺戮與死亡的命運； |
| 7 | ἠέριαι δʼ ἄρα ταί γε κακὴν ἔριδα προφέρονται. | 牠們自晨曦中展開這場殘酷的爭鬥。 |
| 8 | οἳ δʼ ἄρʼ ἴσαν σιγῇ μένεα πνείοντες Ἀχαιοὶ | 而亞該亞人則靜默無聲地前進，氣勢豪邁， |
| 9 | ἐν θυμῷ μεμαῶτες ἀλεξέμεν ἀλλήλοισιν. | 心中一心渴望著彼此扶持、共同奮戰。 |
| 10 | εὖτʼ ὄρεος κορυφῇσι Νότος κατέχευεν ὀμίχλην | 宛如南風在山巔之上灑下濃霧， |
| 11 | ποιμέσιν οὔ τι φίλην, κλέπτῃ δέ τε νυκτὸς ἀμείνω, | 那並非牧羊人所樂見，卻對盜賊而言勝過黑夜的掩護， |
| 12 | τόσσόν τίς τʼ ἐπιλεύσσει ὅσον τʼ ἐπὶ λᾶαν ἵησιν· | 視線所及，僅有投石可達的距離； |
| 13 | ὣς ἄρα τῶν ὑπὸ ποσσὶ κονίσαλος ὄρνυτʼ ἀελλὴς | 眾人邁步前行之際，腳下便如此揚起狂風般的塵沙， |
| 14 | ἐρχομένων· μάλα δʼ ὦκα διέπρησσον πεδίοιο. | 他們迅速穿越了那片平原。 |
| 15 | οἳ δʼ ὅτε δὴ σχεδὸν ἦσαν ἐπʼ ἀλλήλοισιν ἰόντες, | 待雙方逐漸逼近、即將交鋒之際， |
| 16 | Τρωσὶν μὲν προμάχιζεν Ἀλέξανδρος θεοειδὴς | 神一般的亞歷山德羅斯（帕里斯）自特洛伊陣中率先出列迎戰， |
| 17 | παρδαλέην ὤμοισιν ἔχων καὶ καμπύλα τόξα | 肩披豹皮，手持彎弓， |
| 18 | καὶ ξίφος· αὐτὰρ δοῦρε δύω κεκορυθμένα χαλκῷ | 佩劍在身；他又揮舞著兩支包覆青銅的長槍， |
| 19 | πάλλων Ἀργείων προκαλίζετο πάντας ἀρίστους | 向阿爾戈斯人中所有的精銳勇士挑戰， |
| 20 | ἀντίβιον μαχέσασθαι ἐν αἰνῇ δηϊοτῆτι. | 邀他們在那可怖的鏖戰中，與他正面對決。 |
| 21 | τὸν δʼ ὡς οὖν ἐνόησεν ἀρηΐφιλος Μενέλαος | 那深受戰神所愛的墨涅拉俄斯，一見此人 |
| 22 | ἐρχόμενον προπάροιθεν ὁμίλου μακρὰ βιβάντα, | 大步走出隊列、來到眾人之前， |
| 23 | ὥς τε λέων ἐχάρη μεγάλῳ ἐπὶ σώματι κύρσας | 心中頓時大喜，宛如一頭飢餓的獅子， |
| 24 | εὑρὼν ἢ ἔλαφον κεραὸν ἢ ἄγριον αἶγα | 偶然撞見一頭肥碩的獵物，無論是長角的鹿， |
| 25 | πεινάων· μάλα γάρ τε κατεσθίει, εἴ περ ἂν αὐτὸν | 或是野生的山羊；牠必定會狼吞虎嚥，即便有 |
| 26 | σεύωνται ταχέες τε κύνες θαλεροί τʼ αἰζηοί· | 迅捷的獵犬與強壯的獵人前來追趕，也在所不惜； |
| 27 | ὣς ἐχάρη Μενέλαος Ἀλέξανδρον θεοειδέα | 墨涅拉俄斯正是如此地欣喜，一眼望見 |
| 28 | ὀφθαλμοῖσιν ἰδών· φάτο γὰρ τίσεσθαι ἀλείτην· | 神一般的亞歷山德羅斯；因他自忖終於能懲治這名犯下罪愆之人； |
| 29 | αὐτίκα δʼ ἐξ ὀχέων σὺν τεύχεσιν ἆλτο χαμᾶζε. | 他立刻身披甲冑，自戰車上一躍而下。 |
| 30 | τὸν δʼ ὡς οὖν ἐνόησεν Ἀλέξανδρος θεοειδὴς | 神一般的亞歷山德羅斯，一見他 |
| 31 | ἐν προμάχοισι φανέντα, κατεπλήγη φίλον ἦτορ, | 出現在前線鬥士之列，心中頓時驚駭萬分， |
| 32 | ἂψ δʼ ἑτάρων εἰς ἔθνος ἐχάζετο κῆρʼ ἀλεείνων. | 便退回同伴的隊列之中，躲避那可能降臨的死劫。 |
| 33 | ὡς δʼ ὅτε τίς τε δράκοντα ἰδὼν παλίνορσος ἀπέστη | 宛如有人在山谷之中，猛然瞥見一條巨蛇 |
| 34 | οὔρεος ἐν βήσσῃς, ὑπό τε τρόμος ἔλλαβε γυῖα, | 而驚退後撤，四肢頓時因恐懼而顫抖， |
| 35 | ἂψ δʼ ἀνεχώρησεν, ὦχρός τέ μιν εἷλε παρειάς, | 便連連後退，臉頰也因驚恐而變得慘白； |
| 36 | ὣς αὖτις καθʼ ὅμιλον ἔδυ Τρώων ἀγερώχων | 便再度退入那些高傲的特洛伊人隊列之中， |
| 37 | δείσας Ἀτρέος υἱὸν Ἀλέξανδρος θεοειδής. | 神一般的亞歷山德羅斯正是如此，因畏懼阿特柔斯之子。 |
| 38 | τὸν δʼ Ἕκτωρ νείκεσσεν ἰδὼν αἰσχροῖς ἐπέεσσιν· | 赫克托耳見狀，以羞辱的言語斥責他道： |
| 39 | Δύσπαρι εἶδος ἄριστε γυναιμανὲς ἠπεροπευτὰ | 「你這禍害帕里斯，容貌雖俊美，卻是個沉迷女色、慣於欺騙之人， |
| 40 | αἴθʼ ὄφελες ἄγονός τʼ ἔμεναι ἄγαμός τʼ ἀπολέσθαι· | 但願你當初從未出生，或至死未婚才好； |
| 41 | καί κε τὸ βουλοίμην, καί κεν πολὺ κέρδιον ἦεν | 我寧願如此，那樣反而更為划算， |
| 42 | ἢ οὕτω λώβην τʼ ἔμεναι καὶ ὑπόψιον ἄλλων. | 也好過像現在這樣，成為眾人的恥辱與側目的對象。 |
| 43 | ἦ που καγχαλόωσι κάρη κομόωντες Ἀχαιοὶ | 想必那些蓄長髮的亞該亞人此刻正暗自竊笑， |
| 44 | φάντες ἀριστῆα πρόμον ἔμμεναι, οὕνεκα καλὸν | 以為你是一位傑出的先鋒勇士，只因你外表 |
| 45 | εἶδος ἔπʼ, ἀλλʼ οὐκ ἔστι βίη φρεσὶν οὐδέ τις ἀλκή. | 俊美，殊不知你心中既無力量，也毫無勇氣。 |
| 46 | ἦ τοιόσδε ἐὼν ἐν ποντοπόροισι νέεσσι | 你就是這樣的人，卻曾乘著那渡海的船隻， |
| 47 | πόντον ἐπιπλώσας, ἑτάρους ἐρίηρας ἀγείρας, | 遠航海上，召集忠實的同伴， |
| 48 | μιχθεὶς ἀλλοδαποῖσι γυναῖκʼ εὐειδέʼ ἀνῆγες | 與異邦人相處往來，最終帶回一位美貌的女子， |
| 49 | ἐξ ἀπίης γαίης νυὸν ἀνδρῶν αἰχμητάων | 自那遙遠之地，那是善使長槍之人的兒媳， |
| 50 | πατρί τε σῷ μέγα πῆμα πόληΐ τε παντί τε δήμῳ, | 為你的父親、為整座城池、為全體百姓帶來巨大的災禍， |
| 51 | δυσμενέσιν μὲν χάρμα, κατηφείην δὲ σοὶ αὐτῷ; | 讓仇敵歡欣鼓舞，卻讓你自己蒙受屈辱？ |
| 52 | οὐκ ἂν δὴ μείνειας ἀρηΐφιλον Μενέλαον; | 難道你竟不敢面對那深受戰神所愛的墨涅拉俄斯嗎？ |
| 53 | γνοίης χʼ οἵου φωτὸς ἔχεις θαλερὴν παράκοιτιν· | 你若敢面對他，便會知曉自己所奪走的，究竟是何等壯士的妻室； |
| 54 | οὐκ ἄν τοι χραίσμῃ κίθαρις τά τε δῶρʼ Ἀφροδίτης | 屆時你的基薩拉琴、阿芙蘿黛蒂所賜的贈禮， |
| 55 | ἥ τε κόμη τό τε εἶδος ὅτʼ ἐν κονίῃσι μιγείης. | 那頭秀髮、那副容貌，都將救不了你，當你倒臥塵土之時。 |
| 56 | ἀλλὰ μάλα Τρῶες δειδήμονες· ἦ τέ κεν ἤδη | 但特洛伊人實在太過懦弱，否則你早該 |
| 57 | λάϊνον ἕσσο χιτῶνα κακῶν ἕνεχʼ ὅσσα ἔοργας. | 為你所犯下的種種罪過，披上那石頭做成的外衣（被亂石砸死）了。」 |
| 58 | τὸν δʼ αὖτε προσέειπεν Ἀλέξανδρος θεοειδής· | 神一般的亞歷山德羅斯隨即回答他道： |
| 59 | Ἕκτορ ἐπεί με κατʼ αἶσαν ἐνείκεσας οὐδʼ ὑπὲρ αἶσαν· | 「赫克托耳啊，你這番斥責合乎情理，並不算過分； |
| 60 | αἰεί τοι κραδίη πέλεκυς ὥς ἐστιν ἀτειρὴς | 你的心向來如斧頭一般堅不可摧， |
| 61 | ὅς τʼ εἶσιν διὰ δουρὸς ὑπʼ ἀνέρος ὅς ῥά τε τέχνῃ | 那斧頭在匠人手中劈開木材， |
| 62 | νήϊον ἐκτάμνῃσιν, ὀφέλλει δʼ ἀνδρὸς ἐρωήν· | 助長了匠人揮砍的力道；你的心正是如此堅韌； |
| 63 | ὣς σοὶ ἐνὶ στήθεσσιν ἀτάρβητος νόος ἐστί· | 你胸中的心志，也是如此無所畏懼； |
| 64 | μή μοι δῶρʼ ἐρατὰ πρόφερε χρυσέης Ἀφροδίτης· | 但請別拿那金色的阿芙蘿黛蒂所賜的迷人贈禮來責難我； |
| 65 | οὔ τοι ἀπόβλητʼ ἐστὶ θεῶν ἐρικυδέα δῶρα | 神明所賜的光榮贈禮，終究不該被輕易拋棄， |
| 66 | ὅσσά κεν αὐτοὶ δῶσιν, ἑκὼν δʼ οὐκ ἄν τις ἕλοιτο· | 那是神明親自所賜，凡人也絕不會主動選擇擁有這些贈禮； |
| 67 | νῦν αὖτʼ εἴ μʼ ἐθέλεις πολεμίζειν ἠδὲ μάχεσθαι, | 如今，若你希望我出戰、與人一決生死， |
| 68 | ἄλλους μὲν κάθισον Τρῶας καὶ πάντας Ἀχαιούς, | 那就讓其餘的特洛伊人與全體亞該亞人都坐下， |
| 69 | αὐτὰρ ἔμʼ ἐν μέσσῳ καὶ ἀρηΐφιλον Μενέλαον | 讓我與那深受戰神所愛的墨涅拉俄斯， |
| 70 | συμβάλετʼ ἀμφʼ Ἑλένῃ καὶ κτήμασι πᾶσι μάχεσθαι· | 在陣前單獨對決，為海倫與全部的財物一決高下； |
| 71 | ὁππότερος δέ κε νικήσῃ κρείσσων τε γένηται, | 誰能獲勝、誰更為強悍， |
| 72 | κτήμαθʼ ἑλὼν εὖ πάντα γυναῖκά τε οἴκαδʼ ἀγέσθω· | 誰便能取得全部的財物，並將那女子帶回家中； |
| 73 | οἳ δʼ ἄλλοι φιλότητα καὶ ὅρκια πιστὰ ταμόντες | 而其餘眾人則立下堅定的友好誓約， |
| 74 | ναίοιτε Τροίην ἐριβώλακα, τοὶ δὲ νεέσθων | 你們便安居在這沃土肥饒的特洛伊，而他們則返回 |
| 75 | Ἄργος ἐς ἱππόβοτον καὶ Ἀχαιΐδα καλλιγύναικα. | 那牧馬豐美的阿爾戈斯，以及那盛產美女的亞該亞之地。」 |
| 76 | ὣς ἔφαθʼ, Ἕκτωρ δʼ αὖτʼ ἐχάρη μέγα μῦθον ἀκούσας, | 他如此說道，赫克托耳聽聞此言，心中大喜， |
| 77 | καί ῥʼ ἐς μέσσον ἰὼν Τρώων ἀνέεργε φάλαγγας | 便走到陣前，攔住了特洛伊人的方陣， |
| 78 | μέσσου δουρὸς ἑλών· τοὶ δʼ ἱδρύνθησαν ἅπαντες. | 手持長槍中段將眾人攔下；眾人便都停下就座。 |
| 79 | τῷ δʼ ἐπετοξάζοντο κάρη κομόωντες Ἀχαιοὶ | 而那些蓄長髮的亞該亞人卻對他張弓搭箭， |
| 80 | ἰοῖσίν τε τιτυσκόμενοι λάεσσί τʼ ἔβαλλον· | 瞄準他射箭，也向他投擲石塊； |
| 81 | αὐτὰρ ὃ μακρὸν ἄϋσεν ἄναξ ἀνδρῶν Ἀγαμέμνων· | 眾人之王阿伽門農見狀高聲喝止道： |
| 82 | ἴσχεσθʼ Ἀργεῖοι, μὴ βάλλετε κοῦροι Ἀχαιῶν· | 「住手，阿爾戈斯人！別再投擲了，亞該亞的子弟們！ |
| 83 | στεῦται γάρ τι ἔπος ἐρέειν κορυθαίολος Ἕκτωρ. | 因那頭盔閃耀的赫克托耳似乎有話要說。」 |
| 84 | ὣς ἔφαθʼ, οἳ δʼ ἔσχοντο μάχης ἄνεῴ τʼ ἐγένοντο | 他如此說道，眾人便停止了攻擊、迅速 |
| 85 | ἐσσυμένως· Ἕκτωρ δὲ μετʼ ἀμφοτέροισιν ἔειπε· | 安靜下來；赫克托耳便對雙方陣營開口說道： |
| 86 | κέκλυτέ μευ Τρῶες καὶ ἐϋκνήμιδες Ἀχαιοὶ | 「特洛伊人，還有脛甲精良的亞該亞人啊，且聽我一言， |
| 87 | μῦθον Ἀλεξάνδροιο, τοῦ εἵνεκα νεῖκος ὄρωρεν. | 這是亞歷山德羅斯的提議，也正是這場紛爭的起因。 |
| 88 | ἄλλους μὲν κέλεται Τρῶας καὶ πάντας Ἀχαιοὺς | 他提議讓其餘的特洛伊人與全體亞該亞人 |
| 89 | τεύχεα κάλʼ ἀποθέσθαι ἐπὶ χθονὶ πουλυβοτείρῃ, | 卸下精美的甲冑，放置在那滋養萬物的大地上， |
| 90 | αὐτὸν δʼ ἐν μέσσῳ καὶ ἀρηΐφιλον Μενέλαον | 讓他自己與那深受戰神所愛的墨涅拉俄斯， |
| 91 | οἴους ἀμφʼ Ἑλένῃ καὶ κτήμασι πᾶσι μάχεσθαι. | 二人單獨在陣前，為海倫與全部的財物一決高下。 |
| 92 | ὁππότερος δέ κε νικήσῃ κρείσσων τε γένηται | 誰能獲勝、誰更為強悍， |
| 93 | κτήμαθʼ ἑλὼν εὖ πάντα γυναῖκά τε οἴκαδʼ ἀγέσθω· | 誰便能取得全部的財物，並將那女子帶回家中； |
| 94 | οἳ δʼ ἄλλοι φιλότητα καὶ ὅρκια πιστὰ τάμωμεν. | 而我們其餘眾人，則就此立下堅定的友好誓約。」 |
| 95 | ὣς ἔφαθʼ, οἳ δʼ ἄρα πάντες ἀκὴν ἐγένοντο σιωπῇ· | 他如此說道，眾人聞言皆陷入一片靜默； |
| 96 | τοῖσι δὲ καὶ μετέειπε βοὴν ἀγαθὸς Μενέλαος· | 這時，那擅長吶喊的墨涅拉俄斯開口說道： |
| 97 | κέκλυτε νῦν καὶ ἐμεῖο· μάλιστα γὰρ ἄλγος ἱκάνει | 「如今且也聽我一言：畢竟這苦痛降臨最深的， |
| 98 | θυμὸν ἐμόν, φρονέω δὲ διακρινθήμεναι ἤδη | 正是我自己的心；我認為，阿爾戈斯人與特洛伊人 |
| 99 | Ἀργείους καὶ Τρῶας, ἐπεὶ κακὰ πολλὰ πέπασθε | 如今理當就此分出高下，因你們雙方已承受了太多苦難， |
| 100 | εἵνεκʼ ἐμῆς ἔριδος καὶ Ἀλεξάνδρου ἕνεκʼ ἀρχῆς· | 皆是為了我這場紛爭、為了亞歷山德羅斯所挑起的禍端而起； |
| 101 | ἡμέων δʼ ὁπποτέρῳ θάνατος καὶ μοῖρα τέτυκται | 我們二人之中，誰命中注定要死， |
| 102 | τεθναίη· ἄλλοι δὲ διακρινθεῖτε τάχιστα. | 誰便死去；而其餘眾人則盡速就此分道揚鑣。 |
| 103 | οἴσετε ἄρνʼ, ἕτερον λευκόν, ἑτέρην δὲ μέλαιναν, | 你們去取來兩隻羔羊，一隻潔白，一隻烏黑， |
| 104 | Γῇ τε καὶ Ἠελίῳ· Διὶ δʼ ἡμεῖς οἴσομεν ἄλλον· | 分別獻給大地與太陽神；而我們則另外準備一隻獻給宙斯； |
| 105 | ἄξετε δὲ Πριάμοιο βίην, ὄφρʼ ὅρκια τάμνῃ | 也去請那強悍的普里阿摩斯前來，好讓他親自主持誓約， |
| 106 | αὐτός, ἐπεί οἱ παῖδες ὑπερφίαλοι καὶ ἄπιστοι, | 因他的兒子們既狂妄又不可信賴， |
| 107 | μή τις ὑπερβασίῃ Διὸς ὅρκια δηλήσηται. | 免得有人因狂妄自大，破壞了宙斯的誓約。 |
| 108 | αἰεὶ δʼ ὁπλοτέρων ἀνδρῶν φρένες ἠερέθονται· | 年輕人的心思向來輕浮不定； |
| 109 | οἷς δʼ ὁ γέρων μετέῃσιν ἅμα πρόσσω καὶ ὀπίσσω | 而有老者參與其中的事務，則能兼顧前後、瞻前顧後， |

| 441 | ἀλλʼ ἄγε δὴ φιλότητι τραπείομεν εὐνηθέντε· | 來吧，讓我們就此轉向愛情，共赴床榻歡愉； |
| 442 | οὐ γάρ πώ ποτέ μʼ ὧδέ γʼ ἔρως φρένας ἀμφεκάλυψεν, | 因我從未曾有一刻，像現在這樣，被慾望籠罩了心神， |
| 443 | οὐδʼ ὅτε σε πρῶτον Λακεδαίμονος ἐξ ἐρατεινῆς | 即便是當初我初次從那美麗宜人的拉刻代蒙， |
| 444 | ἔπλεον ἁρπάξας ἐν ποντοπόροισι νέεσσι, | 將你劫走、乘著渡海的船隻航行之時亦然， |
| 445 | νήσῳ δʼ ἐν Κραναῇ ἐμίγην φιλότητι καὶ εὐνῇ, | 那時我們曾在克拉奈島上共赴魚水之歡， |
| 446 | ὥς σεο νῦν ἔραμαι καί με γλυκὺς ἵμερος αἱρεῖ. | 但都比不上我此刻對你的渴望，這股甜蜜的慾望正緊緊攫住了我。」 |
| 447 | ἦ ῥα, καὶ ἄρχε λέχος δὲ κιών· ἅμα δʼ εἵπετʼ ἄκοιτις. | 他說完便率先走向床榻；他的妻子也隨之而行。 |
| 448 | τὼ μὲν ἄρʼ ἐν τρητοῖσι κατεύνασθεν λεχέεσσιν, | 二人便在那雕飾精美的床榻上安歇， |
| 449 | Ἀτρεΐδης δʼ ἀνʼ ὅμιλον ἐφοίτα θηρὶ ἐοικὼς | 而阿特柔斯之子則在人群之中四處遊走，宛如猛獸一般， |
| 450 | εἴ που ἐσαθρήσειεν Ἀλέξανδρον θεοειδέα. | 一心想尋找神一般的亞歷山德羅斯的蹤影。 |
| 451 | ἀλλʼ οὔ τις δύνατο Τρώων κλειτῶν τʼ ἐπικούρων | 然而無論是特洛伊人，還是那些聲名遠播的盟軍， |
| 452 | δεῖξαι Ἀλέξανδρον τότʼ ἀρηϊφίλῳ Μενελάῳ· | 都無人能向那深受戰神所愛的墨涅拉俄斯指出帕里斯的下落； |
| 453 | οὐ μὲν γὰρ φιλότητί γʼ ἐκεύθανον εἴ τις ἴδοιτο· | 若有人真見到他，也絕不會出於情誼而替他隱瞞； |
| 454 | ἶσον γάρ σφιν πᾶσιν ἀπήχθετο κηρὶ μελαίνῃ. | 因眾人對他的憎恨，都如同對那黑暗死劫一般深切。 |
| 455 | τοῖσι δὲ καὶ μετέειπεν ἄναξ ἀνδρῶν Ἀγαμέμνων· | 眾人之王阿伽門農隨即向雙方開口說道： |
| 456 | κέκλυτέ μευ Τρῶες καὶ Δάρδανοι ἠδʼ ἐπίκουροι· | 「特洛伊人、達爾達尼亞人，以及盟軍們，且聽我一言： |
| 457 | νίκη μὲν δὴ φαίνετʼ ἀρηϊφίλου Μενελάου, | 這場勝利顯然已歸屬那深受戰神所愛的墨涅拉俄斯， |
| 458 | ὑμεῖς δʼ Ἀργείην Ἑλένην καὶ κτήμαθʼ ἅμʼ αὐτῇ | 因此你們理應交出阿爾戈斯的海倫，連同她的財物， |
| 459 | ἔκδοτε, καὶ τιμὴν ἀποτινέμεν ἥν τινʼ ἔοικεν, | 並支付合宜的補償金， |
| 460 | ἥ τε καὶ ἐσσομένοισι μετʼ ἀνθρώποισι πέληται. | 好讓這件事在後世子孫之中，也能成為一項合宜的先例。」 |
| 461 | ὣς ἔφατʼ Ἀτρεΐδης, ἐπὶ δʼ ᾔνεον ἄλλοι Ἀχαιοί. | 阿特柔斯之子如此說道，其餘的亞該亞人也都表示贊同。 |
