# 《伊里亞德》卷五　雙語逐行對照版

| 1 | ἔνθʼ αὖ Τυδεΐδῃ Διομήδεϊ Παλλὰς Ἀθήνη | 這時，帕拉斯．雅典娜將力量與勇氣， |
| 2 | δῶκε μένος καὶ θάρσος, ἵνʼ ἔκδηλος μετὰ πᾶσιν | 賜予圖丟斯之子狄俄墨得斯，好讓他在阿爾戈斯人中 |
| 3 | Ἀργείοισι γένοιτο ἰδὲ κλέος ἐσθλὸν ἄροιτο· | 格外顯眼、贏得傑出的聲譽； |
| 4 | δαῖέ οἱ ἐκ κόρυθός τε καὶ ἀσπίδος ἀκάματον πῦρ | 她讓他的頭盔與盾牌燃起不息的火焰， |
| 5 | ἀστέρʼ ὀπωρινῷ ἐναλίγκιον, ὅς τε μάλιστα | 宛如秋日夜空中最為明亮的星辰， |
| 6 | λαμπρὸν παμφαίνῃσι λελουμένος ὠκεανοῖο· | 剛自俄刻阿諾斯沐浴而出，光芒格外燦爛； |
| 7 | τοῖόν οἱ πῦρ δαῖεν ἀπὸ κρατός τε καὶ ὤμων, | 那樣的火焰，正自他的頭部與雙肩燃起， |
| 8 | ὦρσε δέ μιν κατὰ μέσσον ὅθι πλεῖστοι κλονέοντο. | 她隨即將他推向戰陣最為激烈之處。 |
| 9 | ἦν δέ τις ἐν Τρώεσσι Δάρης ἀφνειὸς ἀμύμων | 特洛伊人中有位名叫達瑞斯之人，富裕而無可挑剔， |
| 10 | ἱρεὺς Ἡφαίστοιο· δύω δέ οἱ υἱέες ἤστην | 是赫淮斯托斯的祭司；他有兩個兒子， |
| 11 | Φηγεὺς Ἰδαῖός τε μάχης εὖ εἰδότε πάσης. | 名叫菲革烏斯與伊代俄斯，二人皆精通各種戰法。 |
| 12 | τώ οἱ ἀποκρινθέντε ἐναντίω ὁρμηθήτην· | 二人自隊列中脫離，迎向狄俄墨得斯衝去； |
| 13 | τὼ μὲν ἀφʼ ἵπποιιν, ὃ δʼ ἀπὸ χθονὸς ὄρνυτο πεζός. | 二人乘著戰車，狄俄墨得斯則自地面徒步迎戰。 |
| 14 | οἳ δʼ ὅτε δὴ σχεδὸν ἦσαν ἐπʼ ἀλλήλοισιν ἰόντες | 待雙方逐漸逼近、即將交鋒之際， |
| 15 | Φηγεύς ῥα πρότερος προΐει δολιχόσκιον ἔγχος· | 菲革烏斯率先擲出那投影修長的長槍； |
| 16 | Τυδεΐδεω δʼ ὑπὲρ ὦμον ἀριστερὸν ἤλυθʼ ἀκωκὴ | 那槍尖自圖丟斯之子的左肩上方掠過， |
| 17 | ἔγχεος, οὐδʼ ἔβαλʼ αὐτόν· ὃ δʼ ὕστερος ὄρνυτο χαλκῷ | 未能擊中他；圖丟斯之子隨即以青銅長槍反擊， |
| 18 | Τυδεΐδης· τοῦ δʼ οὐχ ἅλιον βέλος ἔκφυγε χειρός, | 他這一擲並未落空， |
| 19 | ἀλλʼ ἔβαλε στῆθος μεταμάζιον, ὦσε δʼ ἀφʼ ἵππων. | 正中對方兩乳之間的胸膛，將他自戰車上撞落。 |
| 20 | Ἰδαῖος δʼ ἀπόρουσε λιπὼν περικαλλέα δίφρον, | 伊代俄斯見狀，棄下那輛美輪美奐的戰車跳下逃走， |
| 21 | οὐδʼ ἔτλη περιβῆναι ἀδελφειοῦ κταμένοιο· | 未敢留下護衛已然陣亡的兄長； |
| 22 | οὐδὲ γὰρ οὐδέ κεν αὐτὸς ὑπέκφυγε κῆρα μέλαιναν, | 即便如此，他自己恐怕也難逃那黑暗的死劫， |
| 23 | ἀλλʼ Ἥφαιστος ἔρυτο, σάωσε δὲ νυκτὶ καλύψας, | 幸而赫淮斯托斯出手護衛，以夜色將他籠罩、救走了他， |
| 24 | ὡς δή οἱ μὴ πάγχυ γέρων ἀκαχήμενος εἴη. | 好讓他那年邁的父親不至於徹底陷入悲痛之中。 |
| 25 | ἵππους δʼ ἐξελάσας μεγαθύμου Τυδέος υἱὸς | 心胸豪邁的圖丟斯之子，隨即驅趕著繳獲的戰馬， |
| 26 | δῶκεν ἑταίροισιν κατάγειν κοίλας ἐπὶ νῆας. | 交給同伴牽往那空心船隊。 |
| 27 | Τρῶες δὲ μεγάθυμοι ἐπεὶ ἴδον υἷε Δάρητος | 心胸豪邁的特洛伊人見到達瑞斯的兩個兒子， |
| 28 | τὸν μὲν ἀλευάμενον, τὸν δὲ κτάμενον παρʼ ὄχεσφι, | 一個逃走、一個陣亡在戰車旁， |
| 29 | πᾶσιν ὀρίνθη θυμός· ἀτὰρ γλαυκῶπις Ἀθήνη | 眾人心中無不震動；而灰眸的雅典娜， |
| 30 | χειρὸς ἑλοῦσʼ ἐπέεσσι προσηύδα θοῦρον Ἄρηα· | 則牽起那猛烈的戰神阿瑞斯之手，開口說道： |
| 31 | Ἆρες Ἄρες βροτολοιγὲ μιαιφόνε τειχεσιπλῆτα | 「阿瑞斯啊，阿瑞斯，你這殘害凡人、沾滿血污、攻城拔寨之神， |
| 32 | οὐκ ἂν δὴ Τρῶας μὲν ἐάσαιμεν καὶ Ἀχαιοὺς | 我們何不就此讓特洛伊人與亞該亞人 |
| 33 | μάρνασθʼ, ὁπποτέροισι πατὴρ Ζεὺς κῦδος ὀρέξῃ, | 自行廝殺，讓父神宙斯決定將榮耀賜予何方， |
| 34 | νῶϊ δὲ χαζώμεσθα, Διὸς δʼ ἀλεώμεθα μῆνιν; | 而我們二人則退避一旁，避開宙斯的怒火？」 |
| 35 | ὣς εἰποῦσα μάχης ἐξήγαγε θοῦρον Ἄρηα· | 她如此說完，便將那猛烈的戰神帶離了戰場； |
| 36 | τὸν μὲν ἔπειτα καθεῖσεν ἐπʼ ἠϊόεντι Σκαμάνδρῳ, | 讓他坐在那水岸交錯的斯卡曼德羅斯河畔， |
| 37 | Τρῶας δʼ ἔκλιναν Δαναοί· ἕλε δʼ ἄνδρα ἕκαστος | 達那奧斯人隨即擊退了特洛伊人；每位統帥 |
| 38 | ἡγεμόνων· πρῶτος δὲ ἄναξ ἀνδρῶν Ἀγαμέμνων | 都各自擊殺了一名敵將；率先出手的是眾人之王阿伽門農， |
| 39 | ἀρχὸν Ἁλιζώνων Ὀδίον μέγαν ἔκβαλε δίφρου· | 他將哈利佐涅斯人的統帥、高大的俄狄俄斯自戰車上擊落； |
| 40 | πρώτῳ γὰρ στρεφθέντι μεταφρένῳ ἐν δόρυ πῆξεν | 那人正轉身之際，阿伽門農將長槍刺入他的背脊， |
| 41 | ὤμων μεσσηγύς, διὰ δὲ στήθεσφιν ἔλασσε, | 就在雙肩之間，長槍貫穿了他的胸膛， |
| 42 | δούπησεν δὲ πεσών, ἀράβησε δὲ τεύχεʼ ἐπʼ αὐτῷ. | 他轟然倒地，身上的甲冑也隨之發出鏗鏘的碰撞聲。 |
| 43 | Ἰδομενεὺς δʼ ἄρα Φαῖστον ἐνήρατο Μῄονος υἱὸν | 伊多梅紐斯則殺死了法伊斯托斯，他是邁奧尼亞人 |
| 44 | Βώρου, ὃς ἐκ Τάρνης ἐριβώλακος εἰληλούθει. | 波羅斯之子，是自沃土肥饒的塔爾涅而來的。 |
| 45 | τὸν μὲν ἄρʼ Ἰδομενεὺς δουρικλυτὸς ἔγχεϊ μακρῷ | 以槍術聞名的伊多梅紐斯，以那修長的長槍 |
| 46 | νύξʼ ἵππων ἐπιβησόμενον κατὰ δεξιὸν ὦμον· | 刺中他正要登上戰車時的右肩； |
| 47 | ἤριπε δʼ ἐξ ὀχέων, στυγερὸς δʼ ἄρα μιν σκότος εἷλε. | 他隨即自戰車上跌落，那可憎的黑暗隨之籠罩了他。 |
| 48 | τὸν μὲν ἄρʼ Ἰδομενῆος ἐσύλευον θεράποντες· | 伊多梅紐斯的隨從們則剝取了他的甲冑； |
| 49 | υἱὸν δὲ Στροφίοιο Σκαμάνδριον αἵμονα θήρης | 而阿特柔斯之子墨涅拉俄斯，則以那銳利的長槍， |
| 50 | Ἀτρεΐδης Μενέλαος ἕλʼ ἔγχεϊ ὀξυόεντι | 殺死了斯特羅菲俄斯之子斯卡曼德里俄斯， |
| 51 | ἐσθλὸν θηρητῆρα· δίδαξε γὰρ Ἄρτεμις αὐτὴ | 那是一位傑出的獵人，正是阿蒂蜜絲親自教導他 |
| 52 | βάλλειν ἄγρια πάντα, τά τε τρέφει οὔρεσιν ὕλη· | 如何獵殺山林間所滋養的一切野獸； |
| 53 | ἀλλʼ οὔ οἱ τότε γε χραῖσμʼ Ἄρτεμις ἰοχέαιρα, | 但那降箭如雨的阿蒂蜜絲，此刻卻救不了他， |
| 54 | οὐδὲ ἑκηβολίαι ᾗσιν τὸ πρίν γε κέκαστο· | 他先前引以為傲的遠射之術，此刻也無濟於事； |
| 55 | ἀλλά μιν Ἀτρεΐδης δουρικλειτὸς Μενέλαος | 因那以槍術聞名的阿特柔斯之子墨涅拉俄斯， |
| 56 | πρόσθεν ἕθεν φεύγοντα μετάφρενον οὔτασε δουρὶ | 在他轉身逃跑之際，一槍刺穿了他的背脊， |
| 57 | ὤμων μεσσηγύς, διὰ δὲ στήθεσφιν ἔλασσεν, | 就在雙肩之間，長槍貫穿了他的胸膛， |
| 58 | ἤριπε δὲ πρηνής, ἀράβησε δὲ τεύχεʼ ἐπʼ αὐτῷ. | 他面朝下轟然倒地，身上的甲冑也隨之發出鏗鏘的碰撞聲。 |
| 59 | Μηριόνης δὲ Φέρεκλον ἐνήρατο, τέκτονος υἱὸν | 墨里奧涅斯則殺死了那匠人哈爾摩尼德斯之子 |
| 60 | Ἁρμονίδεω, ὃς χερσὶν ἐπίστατο δαίδαλα πάντα | 費瑞克羅斯，他雙手精通各種精巧的工藝， |
| 61 | τεύχειν· ἔξοχα γάρ μιν ἐφίλατο Παλλὰς Ἀθήνη· | 帕拉斯．雅典娜格外鍾愛他； |
| 62 | ὃς καὶ Ἀλεξάνδρῳ τεκτήνατο νῆας ἐΐσας | 正是他為亞歷山德羅斯（帕里斯）打造了那些均衡精良的船隻， |
| 63 | ἀρχεκάκους, αἳ πᾶσι κακὸν Τρώεσσι γένοντο | 那些船隻正是災禍的根源，為特洛伊人帶來了 |
| 64 | οἷ τʼ αὐτῷ, ἐπεὶ οὔ τι θεῶν ἐκ θέσφατα ᾔδη. | 全體的災禍，也為他自己招來了禍患，因他並不知曉神明的旨意。 |
| 65 | τὸν μὲν Μηριόνης ὅτε δὴ κατέμαρπτε διώκων | 墨里奧涅斯追上他之時， |
| 66 | βεβλήκει γλουτὸν κατὰ δεξιόν· ἣ δὲ διαπρὸ | 一槍擊中他的右臀；那槍尖 |
| 67 | ἀντικρὺ κατὰ κύστιν ὑπʼ ὀστέον ἤλυθʼ ἀκωκή· | 徑直穿透膀胱，從骨頭下方穿出； |
| 68 | γνὺξ δʼ ἔριπʼ οἰμώξας, θάνατος δέ μιν ἀμφεκάλυψε. | 他跪地哀嚎倒下，死亡隨即將他籠罩。 |
| 69 | Πήδαιον δʼ ἄρʼ ἔπεφνε Μέγης Ἀντήνορος υἱὸν | 墨革斯則殺死了安忒諾爾之子珀代俄斯， |
| 70 | ὅς ῥα νόθος μὲν ἔην, πύκα δʼ ἔτρεφε δῖα Θεανὼ | 他本是私生子，卻由那神聖的忒阿諾悉心撫養， |
| 71 | ἶσα φίλοισι τέκεσσι χαριζομένη πόσεϊ ᾧ. | 她待他如同己出，是為了討自己丈夫的歡心。 |
| 72 | τὸν μὲν Φυλεΐδης δουρὶ κλυτὸς ἐγγύθεν ἐλθὼν | 那以槍術聞名的菲勒烏斯之子（墨革斯）逼近他身旁， |
| 73 | βεβλήκει κεφαλῆς κατὰ ἰνίον ὀξέϊ δουρί· | 一槍擊中他後腦的頸窩； |
| 74 | ἀντικρὺ δʼ ἀνʼ ὀδόντας ὑπὸ γλῶσσαν τάμε χαλκός· | 那青銅槍尖徑直穿過牙齒，切斷了舌根； |
| 75 | ἤριπε δʼ ἐν κονίῃ, ψυχρὸν δʼ ἕλε χαλκὸν ὀδοῦσιν. | 他便倒臥在塵土之中，牙齒咬著那冰冷的青銅。 |
| 76 | Εὐρύπυλος δʼ Εὐαιμονίδης Ὑψήνορα δῖον | 歐埃蒙之子歐律皮羅斯，則殺死了神聖的許普塞諾爾， |
| 77 | υἱὸν ὑπερθύμου Δολοπίονος, ὅς ῥα Σκαμάνδρου | 那心高氣傲的多羅皮昂之子，其父本是斯卡曼德羅斯河的 |
| 78 | ἀρητὴρ ἐτέτυκτο, θεὸς δʼ ὣς τίετο δήμῳ, | 祭司，在百姓中備受尊崇，如同神明一般； |
| 79 | τὸν μὲν ἄρʼ Εὐρύπυλος, Εὐαίμονος ἀγλαὸς υἱός, | 歐埃蒙那光輝的兒子歐律皮羅斯， |
| 80 | πρόσθεν ἕθεν φεύγοντα μεταδρομάδην ἔλασʼ ὦμον | 在他轉身逃跑之際緊追而上，一劍砍向他的肩膀， |
| 81 | φασγάνῳ ἀΐξας, ἀπὸ δʼ ἔξεσε χεῖρα βαρεῖαν· | 猛然揮劍，削去了他那沉重的手臂； |
| 82 | αἱματόεσσα δὲ χεὶρ πεδίῳ πέσε· τὸν δὲ κατʼ ὄσσε | 那染血的手臂便墜落在平原之上；死亡的紫色陰影 |
| 83 | ἔλλαβε πορφύρεος θάνατος καὶ μοῖρα κραταιή. | 與那強大的命運女神，隨即籠罩了他的雙眼。 |
| 84 | ὣς οἳ μὲν πονέοντο κατὰ κρατερὴν ὑσμίνην· | 眾人便如此在這激烈的鏖戰中奮戰不休； |
| 85 | Τυδεΐδην δʼ οὐκ ἂν γνοίης ποτέροισι μετείη | 而圖丟斯之子，你恐怕根本無法分辨他究竟 |
| 86 | ἠὲ μετὰ Τρώεσσιν ὁμιλέοι ἦ μετʼ Ἀχαιοῖς. | 屬於特洛伊人的陣營，還是亞該亞人的陣營。 |
| 87 | θῦνε γὰρ ἂμ πεδίον ποταμῷ πλήθοντι ἐοικὼς | 因他在平原上橫衝直撞，宛如一條暴漲的河流， |
| 88 | χειμάρρῳ, ὅς τʼ ὦκα ῥέων ἐκέδασσε γεφύρας· | 那湍急的洪流沖垮了堤岸與橋樑； |
| 89 | τὸν δʼ οὔτʼ ἄρ τε γέφυραι ἐεργμέναι ἰσχανόωσιν, | 無論是築起的堤岸，還是那些 |
| 90 | οὔτʼ ἄρα ἕρκεα ἴσχει ἀλωάων ἐριθηλέων | 圍護著茂盛葡萄園的籬笆，都無法阻擋它， |
| 91 | ἐλθόντʼ ἐξαπίνης ὅτʼ ἐπιβρίσῃ Διὸς ὄμβρος· | 每當宙斯的暴雨驟然而至、傾盆而下之時； |
| 92 | πολλὰ δʼ ὑπʼ αὐτοῦ ἔργα κατήριπε κάλʼ αἰζηῶν· | 那洪流沖垮了壯士們辛勤耕耘的無數美好田產； |
| 93 | ὣς ὑπὸ Τυδεΐδῃ πυκιναὶ κλονέοντο φάλαγγες | 特洛伊人那密集的方陣，也是如此在圖丟斯之子面前 |
| 94 | Τρώων, οὐδʼ ἄρα μιν μίμνον πολέες περ ἐόντες. | 潰散，儘管他們人數眾多，卻無人敢與他正面對峙。 |
| 95 | τὸν δʼ ὡς οὖν ἐνόησε Λυκάονος ἀγλαὸς υἱὸς | 呂卡昂那光輝的兒子（潘達羅斯）一見他 |
| 96 | θύνοντʼ ἂμ πεδίον πρὸ ἕθεν κλονέοντα φάλαγγας, | 正在平原上橫衝直撞，將方陣沖散在自己面前， |
| 97 | αἶψʼ ἐπὶ Τυδεΐδῃ ἐτιταίνετο καμπύλα τόξα, | 便立刻拉滿那把彎弓，瞄準圖丟斯之子， |
| 98 | καὶ βάλʼ ἐπαΐσσοντα τυχὼν κατὰ δεξιὸν ὦμον | 趁他猛衝向前之際射出一箭，正中他右肩、 |
| 99 | θώρηκος γύαλον· διὰ δʼ ἔπτατο πικρὸς ὀϊστός, | 胸甲的凹陷處；那支苦澀的箭矢貫穿而過， |
| 100 | ἀντικρὺ δὲ διέσχε, παλάσσετο δʼ αἵματι θώρηξ. | 徑直穿透了胸甲，鮮血隨即染紅了甲冑。 |
| 101 | τῷ δʼ ἐπὶ μακρὸν ἄϋσε Λυκάονος ἀγλαὸς υἱός· | 呂卡昂光輝的兒子（潘達羅斯）隨即對他高聲喊道： |
| 102 | ὄρνυσθε Τρῶες μεγάθυμοι κέντορες ἵππων· | 「起身吧，心胸豪邁、善馭馬的特洛伊人啊！ |
| 103 | βέβληται γὰρ ἄριστος Ἀχαιῶν, οὐδέ ἕ φημι | 亞該亞人中最為傑出之人已然中箭，我料想 |
| 104 | δήθʼ ἀνσχήσεσθαι κρατερὸν βέλος, εἰ ἐτεόν με | 他絕撐不了多久，若那位宙斯之子王 |
