| 1 | μῆνιν ἄειδε θεὰ Πηληϊάδεω Ἀχιλῆος | 女神啊，歌詠佩琉斯之子阿基里斯的怒火， |
| 2 | οὐλομένην, ἣ μυρίʼ Ἀχαιοῖς ἄλγεʼ ἔθηκε, | 那毀滅性的怒火，給亞該亞人帶來無數苦難， |
| 3 | πολλὰς δʼ ἰφθίμους ψυχὰς Ἄϊδι προΐαψεν | 將許多勇士的健壯魂魄提早送給黑帝斯， |
| 4 | ἡρώων, αὐτοὺς δὲ ἑλώρια τεῦχε κύνεσσιν | 而讓他們的軀體成為野狗的獵物， |
| 5 | οἰωνοῖσί τε πᾶσι, Διὸς δʼ ἐτελείετο βουλή, | 也成為各種飛禽的餌食；宙斯的旨意由此完成， |
| 6 | ἐξ οὗ δὴ τὰ πρῶτα διαστήτην ἐρίσαντε | 從那兩人初次爭執決裂之時開始， |
| 7 | Ἀτρεΐδης τε ἄναξ ἀνδρῶν καὶ δῖος Ἀχιλλεύς. | 即眾人之王阿特柔斯之子，與神聖的阿基里斯。 |
| 8 | τίς τʼ ἄρ σφωε θεῶν ἔριδι ξυνέηκε μάχεσθαι; | 究竟是哪位神明，讓這兩人陷入爭鬥？ |
| 9 | Λητοῦς καὶ Διὸς υἱός· ὃ γὰρ βασιλῆϊ χολωθεὶς | 是勒托與宙斯之子；他對那位王動了怒， |
| 10 | νοῦσον ἀνὰ στρατὸν ὄρσε κακήν, ὀλέκοντο δὲ λαοί, | 在全軍中降下惡疫，士兵接連死去， |
| 11 | οὕνεκα τὸν Χρύσην ἠτίμασεν ἀρητῆρα | 只因阿特柔斯之子侮辱了祭司克律塞斯， |
| 12 | Ἀτρεΐδης· ὃ γὰρ ἦλθε θοὰς ἐπὶ νῆας Ἀχαιῶν | 那祭司曾來到亞該亞人的快船邊， |
| 13 | λυσόμενός τε θύγατρα φέρων τʼ ἀπερείσιʼ ἄποινα, | 想贖回女兒，帶著無數的贖禮， |
| 14 | στέμματʼ ἔχων ἐν χερσὶν ἑκηβόλου Ἀπόλλωνος | 手裡拿著遠射的阿波羅的花冠， |
| 15 | χρυσέῳ ἀνὰ σκήπτρῳ, καὶ λίσσετο πάντας Ἀχαιούς, | 繫在金杖之上，向全體亞該亞人懇求， |
| 16 | Ἀτρεΐδα δὲ μάλιστα δύω, κοσμήτορε λαῶν· | 尤其懇求阿特柔斯的兩個兒子，那兩位統帥： |
| 17 | Ἀτρεΐδαι τε καὶ ἄλλοι ἐϋκνήμιδες Ἀχαιοί, | 「阿特柔斯的兒子們啊，還有其餘脛甲精良的亞該亞人， |
| 18 | ὑμῖν μὲν θεοὶ δοῖεν Ὀλύμπια δώματʼ ἔχοντες | 願住在奧林波斯宮殿的眾神賜予你們， |
| 19 | ἐκπέρσαι Πριάμοιο πόλιν, εὖ δʼ οἴκαδʼ ἱκέσθαι· | 攻陷普里阿摩斯的城池，並平安歸返家鄉； |
| 20 | παῖδα δʼ ἐμοὶ λύσαιτε φίλην, τὰ δʼ ἄποινα δέχεσθαι, | 只求你們將我親愛的女兒還我，收下這贖禮， |
| 21 | ἁζόμενοι Διὸς υἱὸν ἑκηβόλον Ἀπόλλωνα. | 敬畏宙斯之子、遠射的阿波羅。」 |
| 22 | ἔνθʼ ἄλλοι μὲν πάντες ἐπευφήμησαν Ἀχαιοὶ | 這時其餘的亞該亞人全都齊聲贊同， |
| 23 | αἰδεῖσθαί θʼ ἱερῆα καὶ ἀγλαὰ δέχθαι ἄποινα· | 認為應當敬重祭司，收下豐厚的贖禮； |
| 24 | ἀλλʼ οὐκ Ἀτρεΐδῃ Ἀγαμέμνονι ἥνδανε θυμῷ, | 但阿特柔斯之子阿伽門農心中卻不悅， |
| 25 | ἀλλὰ κακῶς ἀφίει, κρατερὸν δʼ ἐπὶ μῦθον ἔτελλε· | 惡言將他斥退，並撂下強硬的話語： |
| 26 | μή σε γέρον κοίλῃσιν ἐγὼ παρὰ νηυσὶ κιχείω | 「老頭，別讓我在空心船邊撞見你， |
| 27 | ἢ νῦν δηθύνοντʼ ἢ ὕστερον αὖτις ἰόντα, | 不論是現在逗留不去，還是日後再來， |
| 28 | μή νύ τοι οὐ χραίσμῃ σκῆπτρον καὶ στέμμα θεοῖο· | 免得那神的權杖與花冠救不了你； |
| 29 | τὴν δʼ ἐγὼ οὐ λύσω· πρίν μιν καὶ γῆρας ἔπεισιν | 那女子我絕不釋放；她將先在我家中 |
| 30 | ἡμετέρῳ ἐνὶ οἴκῳ ἐν Ἄργεϊ τηλόθι πάτρης | 老去，遠離故土，身在阿爾戈斯， |
| 31 | ἱστὸν ἐποιχομένην καὶ ἐμὸν λέχος ἀντιόωσαν· | 織布持家，並侍奉我的床榻； |
| 32 | ἀλλʼ ἴθι μή μʼ ἐρέθιζε σαώτερος ὥς κε νέηαι. | 走吧，別再激怒我，你才能平安離去。」 |
| 33 | ὣς ἔφατʼ, ἔδεισεν δʼ ὃ γέρων καὶ ἐπείθετο μύθῳ· | 他如此說，老者心生畏懼，聽從了這話， |
| 34 | βῆ δʼ ἀκέων παρὰ θῖνα πολυφλοίσβοιο θαλάσσης· | 便默默沿著波濤喧囂的海岸離去； |
| 35 | πολλὰ δʼ ἔπειτʼ ἀπάνευθε κιὼν ἠρᾶθʼ ὁ γεραιὸς | 老者獨自走遠後，向著阿波羅王懇切祈求， |
| 36 | Ἀπόλλωνι ἄνακτι, τὸν ἠΰκομος τέκε Λητώ· | 那位阿波羅，是秀髮的勒托所生： |
| 37 | κλῦθί μευ ἀργυρότοξʼ, ὃς Χρύσην ἀμφιβέβηκας | 「銀弓之神啊，請聽我禱告，你守護著克律塞， |
| 38 | Κίλλαν τε ζαθέην Τενέδοιό τε ἶφι ἀνάσσεις, | 與神聖的基拉，並以威力統治忒涅多斯， |
| 39 | Σμινθεῦ εἴ ποτέ τοι χαρίεντʼ ἐπὶ νηὸν ἔρεψα, | 斯敏透斯啊，若我曾為你蓋起悅目的神殿， |
| 40 | ἢ εἰ δή ποτέ τοι κατὰ πίονα μηρίʼ ἔκηα | 或若我曾為你焚燒肥美的股肉獻祭， |
| 41 | ταύρων ἠδʼ αἰγῶν, τὸ δέ μοι κρήηνον ἐέλδωρ· | 無論公牛或山羊，請你成全我這心願： |
| 42 | τίσειαν Δαναοὶ ἐμὰ δάκρυα σοῖσι βέλεσσιν. | 願達那奧斯人以你的箭矢，償還我的淚水。」 |
| 43 | ὣς ἔφατʼ εὐχόμενος, τοῦ δʼ ἔκλυε Φοῖβος Ἀπόλλων, | 他如此祈禱，福玻斯．阿波羅聽見了， |
| 44 | βῆ δὲ κατʼ Οὐλύμποιο καρήνων χωόμενος κῆρ, | 便心中震怒，自奧林波斯山頂而下， |
| 45 | τόξʼ ὤμοισιν ἔχων ἀμφηρεφέα τε φαρέτρην· | 肩上背著弓，與蓋合嚴密的箭袋； |
| 46 | ἔκλαγξαν δʼ ἄρʼ ὀϊστοὶ ἐπʼ ὤμων χωομένοιο, | 那震怒之神肩上的箭矢鏗鏘作響， |
| 47 | αὐτοῦ κινηθέντος· ὃ δʼ ἤϊε νυκτὶ ἐοικώς. | 隨他的移動而震響；他行來如黑夜一般。 |
| 48 | ἕζετʼ ἔπειτʼ ἀπάνευθε νεῶν, μετὰ δʼ ἰὸν ἕηκε· | 他隨後坐在遠離船隊之處，射出一箭， |
| 49 | δεινὴ δὲ κλαγγὴ γένετʼ ἀργυρέοιο βιοῖο· | 那銀弓發出可怖的轟鳴； |
| 50 | οὐρῆας μὲν πρῶτον ἐπῴχετο καὶ κύνας ἀργούς, | 他先射向騾子與敏捷的犬群， |
| 51 | αὐτὰρ ἔπειτʼ αὐτοῖσι βέλος ἐχεπευκὲς ἐφιεὶς | 隨後又將銳利的箭矢對準人群， |
| 52 | βάλλʼ· αἰεὶ δὲ πυραὶ νεκύων καίοντο θαμειαί. | 不斷射殺；焚燒屍體的柴堆終日不熄。 |
| 53 | ἐννῆμαρ μὲν ἀνὰ στρατὸν ᾤχετο κῆλα θεοῖο, | 那神的箭矢在軍中肆虐九日， |
| 54 | τῇ δεκάτῃ δʼ ἀγορὴν δὲ καλέσσατο λαὸν Ἀχιλλεύς· | 第十日，阿基里斯召集眾人聚會； |
| 55 | τῷ γὰρ ἐπὶ φρεσὶ θῆκε θεὰ λευκώλενος Ἥρη· | 這是白臂的女神赫拉將此念頭放入他心中， |
| 56 | κήδετο γὰρ Δαναῶν, ὅτι ῥα θνήσκοντας ὁρᾶτο. | 因她眼見達那奧斯人相繼死去，心中憂慮。 |
| 57 | οἳ δʼ ἐπεὶ οὖν ἤγερθεν ὁμηγερέες τε γένοντο, | 待眾人集合、聚齊之後， |
| 58 | τοῖσι δʼ ἀνιστάμενος μετέφη πόδας ὠκὺς Ἀχιλλεύς· | 疾足的阿基里斯起身向他們說道： |
| 59 | Ἀτρεΐδη νῦν ἄμμε παλιμπλαγχθέντας ὀΐω | 「阿特柔斯之子啊，我想我們終將 |
| 60 | ἂψ ἀπονοστήσειν, εἴ κεν θάνατόν γε φύγοιμεν, | 被迫折返，若我們能逃過此劫， |
| 61 | εἰ δὴ ὁμοῦ πόλεμός τε δαμᾷ καὶ λοιμὸς Ἀχαιούς· | 因戰爭與瘟疫已同時重創亞該亞人； |
| 62 | ἀλλʼ ἄγε δή τινα μάντιν ἐρείομεν ἢ ἱερῆα | 來吧，讓我們去請教某位先知或祭司， |
| 63 | ἢ καὶ ὀνειροπόλον, καὶ γάρ τʼ ὄναρ ἐκ Διός ἐστιν, | 或是解夢者，因夢境本也出自宙斯， |
| 64 | ὅς κʼ εἴποι ὅ τι τόσσον ἐχώσατο Φοῖβος Ἀπόλλων, | 請他告訴我們，福玻斯．阿波羅為何如此震怒， |
| 65 | εἴτʼ ἄρʼ ὅ γʼ εὐχωλῆς ἐπιμέμφεται ἠδʼ ἑκατόμβης, | 是否因誓言未還、百牲祭未獻而見責， |
| 66 | αἴ κέν πως ἀρνῶν κνίσης αἰγῶν τε τελείων | 或許他若嚐得羔羊與完好山羊的油香， |
| 67 | βούλεται ἀντιάσας ἡμῖν ἀπὸ λοιγὸν ἀμῦναι. | 便願意接納，為我們免去這場瘟疫。」 |
| 68 | ἤτοι ὅ γʼ ὣς εἰπὼν κατʼ ἄρʼ ἕζετο· τοῖσι δʼ ἀνέστη | 他說完便坐下；這時起身的是 |
| 69 | Κάλχας Θεστορίδης οἰωνοπόλων ὄχʼ ἄριστος, | 卡爾卡斯，忒斯托爾之子，卜鳥之術中最為出眾者， |
| 70 | ὃς ᾔδη τά τʼ ἐόντα τά τʼ ἐσσόμενα πρό τʼ ἐόντα, | 他通曉現今、未來，也通曉過往之事， |
| 71 | καὶ νήεσσʼ ἡγήσατʼ Ἀχαιῶν Ἴλιον εἴσω | 憑著福玻斯．阿波羅所賜予的預言之術， |
| 72 | ἣν διὰ μαντοσύνην, τήν οἱ πόρε Φοῖβος Ἀπόλλων· | 曾引領亞該亞人的船隊駛入伊利昂； |
| 73 | ὅ σφιν ἐὺ φρονέων ἀγορήσατο καὶ μετέειπεν· | 他懷著善意，向眾人開口說道： |
| 74 | ὦ Ἀχιλεῦ κέλεαί με Διῒ φίλε μυθήσασθαι | 「阿基里斯啊，宙斯所愛之人，你要我道出 |
| 75 | μῆνιν Ἀπόλλωνος ἑκατηβελέταο ἄνακτος· | 遠射之王阿波羅的怒火根由； |
| 76 | τοὶ γὰρ ἐγὼν ἐρέω· σὺ δὲ σύνθεο καί μοι ὄμοσσον | 我便說出來；但你須應允並向我起誓， |
| 77 | ἦ μέν μοι πρόφρων ἔπεσιν καὶ χερσὶν ἀρήξειν· | 誓言你將以言語與雙手誠心助我； |
| 78 | ἦ γὰρ ὀΐομαι ἄνδρα χολωσέμεν, ὃς μέγα πάντων | 因我料想此言將觸怒一人，他在眾阿爾戈斯人中 |
| 79 | Ἀργείων κρατέει καί οἱ πείθονται Ἀχαιοί· | 權力最大，亞該亞人也都對他俯首聽命； |
| 80 | κρείσσων γὰρ βασιλεὺς ὅτε χώσεται ἀνδρὶ χέρηϊ· | 因君王對下位者動怒時，力量總是更強大； |
| 81 | εἴ περ γάρ τε χόλον γε καὶ αὐτῆμαρ καταπέψῃ, | 即使他當日便將怒氣壓下， |
| 82 | ἀλλά τε καὶ μετόπισθεν ἔχει κότον, ὄφρα τελέσσῃ, | 日後仍會將怨恨存於胸中，直到報復得逞， |
| 83 | ἐν στήθεσσιν ἑοῖσι· σὺ δὲ φράσαι εἴ με σαώσεις. | 深埋心底；你且想清楚，是否真能保護我。」 |
| 84 | τὸν δʼ ἀπαμειβόμενος προσέφη πόδας ὠκὺς Ἀχιλλεύς· | 疾足的阿基里斯回答他道： |
| 85 | θαρσήσας μάλα εἰπὲ θεοπρόπιον ὅ τι οἶσθα· | 「儘管放心，說出你所知的神諭吧； |
| 86 | οὐ μὰ γὰρ Ἀπόλλωνα Διῒ φίλον, ᾧ τε σὺ Κάλχαν | 我指著宙斯所愛的阿波羅起誓──你卡爾卡斯 |
| 87 | εὐχόμενος Δαναοῖσι θεοπροπίας ἀναφαίνεις, | 正是向他祈禱、為達那奧斯人揭示神諭之人── |
| 88 | οὔ τις ἐμεῦ ζῶντος καὶ ἐπὶ χθονὶ δερκομένοιο | 只要我尚在人世、仍見天日， |
| 89 | σοὶ κοίλῃς παρὰ νηυσί βαρείας χεῖρας ἐποίσει | 就絕無人敢在空心船邊對你 |
| 90 | συμπάντων Δαναῶν, οὐδʼ ἢν Ἀγαμέμνονα εἴπῃς, | 動用重手，即使你所指之人是阿伽門農， |
| 91 | ὃς νῦν πολλὸν ἄριστος Ἀχαιῶν εὔχεται εἶναι. | 他如今自誇是亞該亞人中最為卓越之人。」 |
| 92 | καὶ τότε δὴ θάρσησε καὶ ηὔδα μάντις ἀμύμων· | 於是那無可挑剔的先知放心開口道： |
| 93 | οὔ τʼ ἄρ ὅ γʼ εὐχωλῆς ἐπιμέμφεται οὐδʼ ἑκατόμβης, | 「他並非因誓言未還、百牲祭未獻而見責， |
| 94 | ἀλλʼ ἕνεκʼ ἀρητῆρος ὃν ἠτίμησʼ Ἀγαμέμνων, | 而是因阿伽門農侮辱了那位祭司， |
| 95 | οὐδʼ ἀπέλυσε θύγατρα καὶ οὐκ ἀπεδέξατʼ ἄποινα, | 既不肯釋放他的女兒，也不肯收下贖禮， |
| 96 | τοὔνεκʼ ἄρʼ ἄλγεʼ ἔδωκεν ἑκηβόλος ἠδʼ ἔτι δώσει· | 因此遠射之神降下災禍，且仍將繼續降下； |
| 97 | οὐδʼ ὅ γε πρὶν Δαναοῖσιν ἀεικέα λοιγὸν ἀπώσει | 他絕不會在此之前，為達那奧斯人除去這場慘禍， |
| 98 | πρίν γʼ ἀπὸ πατρὶ φίλῳ δόμεναι ἑλικώπιδα κούρην | 除非那明眸的女子被還給她親愛的父親， |
| 99 | ἀπριάτην ἀνάποινον, ἄγειν θʼ ἱερὴν ἑκατόμβην | 不索代價、不取贖禮，並將神聖的百牲祭 |
| 100 | ἐς Χρύσην· τότε κέν μιν ἱλασσάμενοι πεπίθοιμεν. | 帶往克律塞；如此我們才能平息、說服他。」 |
| 101 | ἤτοι ὅ γʼ ὣς εἰπὼν κατʼ ἄρʼ ἕζετο· τοῖσι δʼ ἀνέστη | 他說完便坐下；這時起身的是 |
| 102 | ἥρως Ἀτρεΐδης εὐρὺ κρείων Ἀγαμέμνων | 英雄阿特柔斯之子、統治廣大的阿伽門農， |
| 103 | ἀχνύμενος· μένεος δὲ μέγα φρένες ἀμφιμέλαιναι | 心中悲憤；他那深黑的心胸滿溢著 |
| 104 | πίμπλαντʼ, ὄσσε δέ οἱ πυρὶ λαμπετόωντι ἐΐκτην· | 怒氣，雙眼有如烈火般閃爍； |
| 105 | Κάλχαντα πρώτιστα κάκʼ ὀσσόμενος προσέειπε· | 他先惡狠狠瞪著卡爾卡斯，開口說道： |
| 106 | μάντι κακῶν οὐ πώ ποτέ μοι τὸ κρήγυον εἶπας· | 「凶事的先知啊，你從未對我說過好話； |
| 107 | αἰεί τοι τὰ κάκʼ ἐστὶ φίλα φρεσὶ μαντεύεσθαι, | 你心中總是偏好預言凶事， |
| 108 | ἐσθλὸν δʼ οὔτέ τί πω εἶπας ἔπος οὔτʼ ἐτέλεσσας· | 卻從未說過一句吉言，也從未使吉事成真； |
| 109 | καὶ νῦν ἐν Δαναοῖσι θεοπροπέων ἀγορεύεις | 如今你又在達那奧斯人面前傳達神諭， |
| 110 | ὡς δὴ τοῦδʼ ἕνεκά σφιν ἑκηβόλος ἄλγεα τεύχει, | 說遠射之神降下這場災禍， |
| 111 | οὕνεκʼ ἐγὼ κούρης Χρυσηΐδος ἀγλάʼ ἄποινα | 只因我不肯收下克律塞伊絲那女子的 |
| 112 | οὐκ ἔθελον δέξασθαι, ἐπεὶ πολὺ βούλομαι αὐτὴν | 豐厚贖禮，因為我更願意將她 |
| 113 | οἴκοι ἔχειν· καὶ γάρ ῥα Κλυταιμνήστρης προβέβουλα | 留在家中；她甚至勝過克呂泰涅斯特拉， |
| 114 | κουριδίης ἀλόχου, ἐπεὶ οὔ ἑθέν ἐστι χερείων, | 我明媒正娶的妻子，因她絲毫不比她遜色， |
| 115 | οὐ δέμας οὐδὲ φυήν, οὔτʼ ἂρ φρένας οὔτέ τι ἔργα. | 無論身形、姿容，還是心智、手藝皆然。 |
