| 1 | Ἠὼς μὲν κροκόπεπλος ἐκίδνατο πᾶσαν ἐπʼ αἶαν, | 身披藏紅色衣袍的黎明女神將光輝灑向大地， |
| 2 | Ζεὺς δὲ θεῶν ἀγορὴν ποιήσατο τερπικέραυνος | 喜好雷霆的宙斯便召開了眾神的集會， |
| 3 | ἀκροτάτῃ κορυφῇ πολυδειράδος Οὐλύμποιο· | 就在多脊的奧林波斯山最高的峰頂； |
| 4 | αὐτὸς δέ σφʼ ἀγόρευε, θεοὶ δʼ ὑπὸ πάντες ἄκουον· | 他親自向眾神訓話，眾神皆側耳靜聽： |
| 5 | κέκλυτέ μευ πάντές τε θεοὶ πᾶσαί τε θέαιναι, | 「聽我說，諸位男神與眾位女神啊， |

| 7 | μήτέ τις οὖν θήλεια θεὸς τό γε μήτέ τις ἄρσην | 無論男神女神，誰都不准 |
| 8 | πειράτω διακέρσαι ἐμὸν ἔπος, ἀλλʼ ἅμα πάντες | 試圖違抗我這番話，反而全都要 |
| 9 | αἰνεῖτʼ, ὄφρα τάχιστα τελευτήσω τάδε ἔργα. | 一致贊同，好讓我盡快完成此事。 |

| 11 | ἐλθόντʼ ἢ Τρώεσσιν ἀρηγέμεν ἢ Δαναοῖσι | 前去援助特洛伊人或達那奧斯人， |
| 12 | πληγεὶς οὐ κατὰ κόσμον ἐλεύσεται Οὔλυμπον δέ· | 必將遭我重擊、狼狽不堪地返回奧林波斯； |

| 18 | εἰ δʼ ἄγε πειρήσασθε θεοὶ ἵνα εἴδετε πάντες· | 來吧，眾神，不妨都來試一試，好讓你們明白： |
| 19 | σειρὴν χρυσείην ἐξ οὐρανόθεν κρεμάσαντες | 把一條金鏈從天上垂下， |
| 20 | πάντές τʼ ἐξάπτεσθε θεοὶ πᾶσαί τε θέαιναι· | 你們所有男神女神，一起抓住它拉扯； |
| 21 | ἀλλʼ οὐκ ἂν ἐρύσαιτʼ ἐξ οὐρανόθεν πεδίον δὲ | 但你們絕不可能把我──那至高的謀略者宙斯── |
| 22 | Ζῆνʼ ὕπατον μήστωρʼ, οὐδʼ εἰ μάλα πολλὰ κάμοιτε. | 從天上拉到地面，即便你們竭盡全力也是徒然。 |
| 23 | ἀλλʼ ὅτε δὴ καὶ ἐγὼ πρόφρων ἐθέλοιμι ἐρύσσαι, | 但若我自己真心想要拉扯， |
| 24 | αὐτῇ κεν γαίῃ ἐρύσαιμʼ αὐτῇ τε θαλάσσῃ· | 我便能連同大地與海洋一併拉起； |
| 25 | σειρὴν μέν κεν ἔπειτα περὶ ῥίον Οὐλύμποιο | 然後我會把那條鏈子繫在奧林波斯山峰上， |
| 26 | δησαίμην, τὰ δέ κʼ αὖτε μετήορα πάντα γένοιτο. | 讓一切都懸在半空之中。 |
| 27 | τόσσον ἐγὼ περί τʼ εἰμὶ θεῶν περί τʼ εἴμʼ ἀνθρώπων. | 我便是如此遠遠超越諸神、超越凡人。」 |
| 28 | ὣς ἔφαθʼ, οἱ δʼ ἄρα πάντες ἀκὴν ἐγένοντο σιωπῇ | 他如此說罷，眾神皆陷入一片沉默， |
| 29 | μῦθον ἀγασσάμενοι· μάλα γὰρ κρατερῶς ἀγόρευσεν. | 對這番話深感敬畏；因為他說得極為嚴厲。 |
| 30 | ὀψὲ δὲ δὴ μετέειπε θεὰ γλαυκῶπις Ἀθήνη· | 終於，灰眸的女神雅典娜開口說道： |
| 31 | ὦ πάτερ ἡμέτερε Κρονίδη ὕπατε κρειόντων | 「我們的父親啊，克洛諾斯之子，統治者中的至尊， |
| 32 | εὖ νυ καὶ ἡμεῖς ἴδμεν ὅ τοι σθένος οὐκ ἐπιεικτόν· | 我們自然深知你的力量無可抗衡； |
| 33 | ἀλλʼ ἔμπης Δαναῶν ὀλοφυρόμεθʼ αἰχμητάων, | 但我們仍為那些持槍的達那奧斯人感到悲憫， |
| 34 | οἵ κεν δὴ κακὸν οἶτον ἀναπλήσαντες ὄλωνται. | 他們終將迎來悲慘的命運而滅亡。 |
| 35 | ἀλλʼ ἤτοι πολέμου μὲν ἀφεξόμεθʼ ὡς σὺ κελεύεις· | 但我們確實會依你的命令，遠離戰事； |
| 36 | βουλὴν δʼ Ἀργείοις ὑποθησόμεθʼ ἥ τις ὀνήσει, | 只是想為阿爾戈斯人獻上一計，或許能有所助益， |
| 37 | ὡς μὴ πάντες ὄλωνται ὀδυσσαμένοιο τεοῖο. | 好讓他們不至於因你的震怒而全數覆滅。」 |
| 38 | τὴν δʼ ἐπιμειδήσας προσέφη νεφεληγερέτα Ζεύς· | 聚雲之神宙斯微笑著回答她道： |
| 39 | θάρσει Τριτογένεια φίλον τέκος· οὔ νύ τι θυμῷ | 「放心吧，特里托格涅亞，我親愛的孩子；我這番話 |
| 40 | πρόφρονι μυθέομαι, ἐθέλω δέ τοι ἤπιος εἶναι. | 並非出於真心的嚴厲，我對你其實是溫和的。」 |
| 41 | ὣς εἰπὼν ὑπʼ ὄχεσφι τιτύσκετο χαλκόποδʼ ἵππω | 他如此說罷，便為他那對銅蹄快足的駿馬 |
| 42 | ὠκυπέτα χρυσέῃσιν ἐθείρῃσιν κομόωντε, | 繫上車軛，牠們鬃毛金黃、飛馳如電， |
| 43 | χρυσὸν δʼ αὐτὸς ἔδυνε περὶ χροΐ, γέντο δʼ ἱμάσθλην | 他自己也披上黃金甲冑，握起 |
| 44 | χρυσείην εὔτυκτον, ἑοῦ δʼ ἐπεβήσετο δίφρου, | 那精製的黃金馬鞭，登上自己的戰車， |
| 45 | μάστιξεν δʼ ἐλάαν· τὼ δʼ οὐκ ἀέκοντε πετέσθην | 揮鞭驅車前行；駿馬便欣然飛馳， |
| 46 | μεσσηγὺς γαίης τε καὶ οὐρανοῦ ἀστερόεντος. | 奔馳於大地與繁星滿布的天空之間。 |
| 47 | Ἴδην δʼ ἵκανεν πολυπίδακα μητέρα θηρῶν | 他來到多泉的伊達山，那野獸之母， |
| 48 | Γάργαρον, ἔνθά τέ οἱ τέμενος βωμός τε θυήεις. | 直抵加爾加羅斯峰，那裡有他的聖域與焚香的祭壇。 |
| 49 | ἔνθʼ ἵππους ἔστησε πατὴρ ἀνδρῶν τε θεῶν τε | 人神之父便在那裡讓駿馬停下， |
| 50 | λύσας ἐξ ὀχέων, κατὰ δʼ ἠέρα πουλὺν ἔχευεν. | 自車上鬆開牠們，並在四周布下濃霧。 |
| 51 | αὐτὸς δʼ ἐν κορυφῇσι καθέζετο κύδεϊ γαίων | 他自己則坐在峰頂之上，因榮耀而滿心歡喜， |
| 52 | εἰσορόων Τρώων τε πόλιν καὶ νῆας Ἀχαιῶν. | 俯瞰著特洛伊人的城池與亞該亞人的船隊。 |
| 53 | οἳ δʼ ἄρα δεῖπνον ἕλοντο κάρη κομόωντες Ἀχαιοὶ | 長髮的亞該亞人便在營帳中 |
| 54 | ῥίμφα κατὰ κλισίας, ἀπὸ δʼ αὐτοῦ θωρήσσοντο. | 匆匆用過早膳，隨即武裝起來。 |
| 55 | Τρῶες δʼ αὖθʼ ἑτέρωθεν ἀνὰ πτόλιν ὁπλίζοντο | 另一邊，特洛伊人也在城中武裝起來， |
| 56 | παυρότεροι· μέμασαν δὲ καὶ ὧς ὑσμῖνι μάχεσθαι | 人數雖較少，卻仍渴望投入戰鬥， |
| 57 | χρειοῖ ἀναγκαίῃ, πρό τε παίδων καὶ πρὸ γυναικῶν. | 因為情勢所迫，要為妻兒挺身而戰。 |
| 58 | πᾶσαι δʼ ὠΐγνυντο πύλαι, ἐκ δʼ ἔσσυτο λαός, | 所有的城門都敞開，軍隊蜂擁而出， |
| 59 | πεζοί θʼ ἱππῆές τε· πολὺς δʼ ὀρυμαγδὸς ὀρώρει. | 步兵與騎兵齊發；喧囂之聲大作。 |
| 60 | οἳ δʼ ὅτε δή ῥʼ ἐς χῶρον ἕνα ξυνιόντες ἵκοντο | 待雙方會聚於同一戰場之時， |
| 61 | σύν ῥʼ ἔβαλον ῥινούς, σὺν δʼ ἔγχεα καὶ μένεʼ ἀνδρῶν | 盾牌與盾牌相撞，長槍與長槍交錯，身披銅甲的 |

| 64 | ἔνθα δʼ ἅμʼ οἰμωγή τε καὶ εὐχωλὴ πέλεν ἀνδρῶν | 這時，哀號與誇勝之聲同時響起， |
| 65 | ὀλλύντων τε καὶ ὀλλυμένων, ῥέε δʼ αἵματι γαῖα. | 有人殺敵、有人殞命，大地為鮮血所浸染。 |
| 66 | ὄφρα μὲν ἠὼς ἦν καὶ ἀέξετο ἱερὸν ἦμαρ, | 當黎明尚在、這神聖的白晝漸漸增長之時， |
| 67 | τόφρα μάλʼ ἀμφοτέρων βέλεʼ ἥπτετο, πῖπτε δὲ λαός. | 雙方的箭矢紛紛命中，士兵接連倒下。 |
| 68 | ἦμος δʼ Ἠέλιος μέσον οὐρανὸν ἀμφιβεβήκει, | 待太陽行至天空正中之時， |

| 71 | Τρώων θʼ ἱπποδάμων καὶ Ἀχαιῶν χαλκοχιτώνων, | 一份屬於馴馬的特洛伊人，一份屬於身披銅甲的亞該亞人， |

| 78 | ἔνθʼ οὔτʼ Ἰδομενεὺς τλῆ μίμνειν οὔτʼ Ἀγαμέμνων, | 此時，伊多梅紐斯不敢再堅守陣地，阿伽門農也不敢， |

| 80 | Νέστωρ οἶος ἔμιμνε Γερήνιος οὖρος Ἀχαιῶν | 唯有格瑞尼亞的涅斯托爾、亞該亞人的守護者依舊堅守， |
| 81 | οὔ τι ἑκών, ἀλλʼ ἵππος ἐτείρετο, τὸν βάλεν ἰῷ | 並非出於自願，而是他的馬匹受了傷──光耀的 |
| 82 | δῖος Ἀλέξανδρος Ἑλένης πόσις ἠϋκόμοιο | 帕里斯、秀髮的海倫之夫，一箭 |
| 83 | ἄκρην κὰκ κορυφήν, ὅθι τε πρῶται τρίχες ἵππων | 正中馬頭頂端，正是馬鬃初生之處， |
