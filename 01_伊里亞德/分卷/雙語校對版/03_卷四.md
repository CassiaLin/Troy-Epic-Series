| 4 | δειδέχατʼ ἀλλήλους, Τρώων πόλιν εἰσορόωντες· | 彼此舉杯致意，望著特洛伊那座城池； |
| 5 | αὐτίκʼ ἐπειρᾶτο Κρονίδης ἐρεθιζέμεν Ἥρην | 克洛諾斯之子隨即試著以譏諷的話語， |

| 8 | Ἥρη τʼ Ἀργείη καὶ Ἀλαλκομενηῒς Ἀθήνη. | 那便是阿爾戈斯的赫拉，與阿拉爾科墨涅的雅典娜。 |

| 10 | τέρπεσθον· τῷ δʼ αὖτε φιλομειδὴς Ἀφροδίτη | 自得其樂；而愛笑的阿芙蘿黛蒂 |
| 11 | αἰεὶ παρμέμβλωκε καὶ αὐτοῦ κῆρας ἀμύνει· | 卻始終陪伴在帕里斯身旁，替他抵擋死劫； |
| 12 | καὶ νῦν ἐξεσάωσεν ὀϊόμενον θανέεσθαι. | 就連方才，她也救走了那自認必死無疑之人。 |
| 13 | ἀλλʼ ἤτοι νίκη μὲν ἀρηϊφίλου Μενελάου· | 然而，這場勝利終究屬於那深受戰神所愛的墨涅拉俄斯； |
| 14 | ἡμεῖς δὲ φραζώμεθʼ ὅπως ἔσται τάδε ἔργα, | 如今讓我們商議，這件事該如何收場， |
| 15 | ἤ ῥʼ αὖτις πόλεμόν τε κακὸν καὶ φύλοπιν αἰνὴν | 究竟該再度掀起這場慘烈的戰事與可怖的鏖戰， |
| 16 | ὄρσομεν, ἦ φιλότητα μετʼ ἀμφοτέροισι βάλωμεν. | 還是該在雙方之間播下友誼的種子。 |
| 17 | εἰ δʼ αὖ πως τόδε πᾶσι φίλον καὶ ἡδὺ γένοιτο, | 若此事能讓眾人皆大歡喜、樂於接受， |
| 18 | ἤτοι μὲν οἰκέοιτο πόλις Πριάμοιο ἄνακτος, | 那便讓普里阿摩斯王的城池就此保全， |

| 20 | ὣς ἔφαθʼ, αἳ δʼ ἐπέμυξαν Ἀθηναίη τε καὶ Ἥρη· | 他如此說道，雅典娜與赫拉聞言皆低聲嘀咕不滿； |
| 21 | πλησίαι αἵ γʼ ἥσθην, κακὰ δὲ Τρώεσσι μεδέσθην. | 二人並肩而坐，心中一心盤算著要為特洛伊人降下災禍。 |
| 22 | ἤτοι Ἀθηναίη ἀκέων ἦν οὐδέ τι εἶπε | 雅典娜靜默不語，什麼也沒說， |
| 23 | σκυζομένη Διὶ πατρί, χόλος δέ μιν ἄγριος ᾕρει· | 只是對父神宙斯滿懷慍怒，一股狂野的怒火攫住了她； |
| 24 | Ἥρῃ δʼ οὐκ ἔχαδε στῆθος χόλον, ἀλλὰ προσηύδα· | 而赫拉的胸中卻按捺不住怒火，開口說道： |
| 25 | αἰνότατε Κρονίδη ποῖον τὸν μῦθον ἔειπες· | 「最為可畏的克洛諾斯之子啊，你這是說的什麼話？ |
| 26 | πῶς ἐθέλεις ἅλιον θεῖναι πόνον ἠδʼ ἀτέλεστον, | 你竟想讓我先前的一切辛勞都化為徒然、一事無成， |
| 27 | ἱδρῶ θʼ ὃν ἵδρωσα μόγῳ, καμέτην δέ μοι ἵπποι | 我曾為此揮灑多少汗水、多少辛勞，我的戰馬也曾因 |
| 28 | λαὸν ἀγειρούσῃ, Πριάμῳ κακὰ τοῖό τε παισίν. | 召集百姓、為普里阿摩斯與其子孫降下災禍而疲憊不堪。 |
| 29 | ἕρδʼ· ἀτὰρ οὔ τοι πάντες ἐπαινέομεν θεοὶ ἄλλοι. | 你儘管去做吧；但我們其餘的神明未必都會贊同你。」 |
| 30 | τὴν δὲ μέγʼ ὀχθήσας προσέφη νεφεληγερέτα Ζεύς· | 聚雲之神宙斯滿懷不悅，回答她道： |
| 31 | δαιμονίη τί νύ σε Πρίαμος Πριάμοιό τε παῖδες | 「你這奇怪的女子啊，普里阿摩斯與普里阿摩斯的兒子們， |
| 32 | τόσσα κακὰ ῥέζουσιν, ὅ τʼ ἀσπερχὲς μενεαίνεις | 究竟對你做了什麼天大的惡事，讓你如此執意地渴望 |
| 33 | Ἰλίου ἐξαλαπάξαι ἐϋκτίμενον πτολίεθρον; | 摧毀那建造精良的城邦伊利昂？ |
| 34 | εἰ δὲ σύ γʼ εἰσελθοῦσα πύλας καὶ τείχεα μακρὰ | 依你的心意，恐怕你真想闖入那城門與高聳的城牆， |
| 35 | ὠμὸν βεβρώθοις Πρίαμον Πριάμοιό τε παῖδας | 生吞活剝普里阿摩斯與普里阿摩斯的兒子們， |
| 36 | ἄλλους τε Τρῶας, τότε κεν χόλον ἐξακέσαιο. | 以及其餘的特洛伊人，那樣或許才能平息你的怒火。 |
| 37 | ἕρξον ὅπως ἐθέλεις· μὴ τοῦτό γε νεῖκος ὀπίσσω | 你儘管照你的心意行事吧；但別讓這件事日後 |
| 38 | σοὶ καὶ ἐμοὶ μέγʼ ἔρισμα μετʼ ἀμφοτέροισι γένηται. | 在你我之間，成為一場更大的爭端。 |
| 39 | ἄλλο δέ τοι ἐρέω, σὺ δʼ ἐνὶ φρεσὶ βάλλεο σῇσιν· | 我還有一事要告訴你，你且將它銘記於心： |
| 40 | ὁππότε κεν καὶ ἐγὼ μεμαὼς πόλιν ἐξαλαπάξαι | 日後若有一日，換我一心渴望摧毀 |
| 41 | τὴν ἐθέλω ὅθι τοι φίλοι ἀνέρες ἐγγεγάασι, | 某座你所鍾愛之人所居的城池， |
| 42 | μή τι διατρίβειν τὸν ἐμὸν χόλον, ἀλλά μʼ ἐᾶσαι· | 到時你也休想阻撓我的怒火，只管讓我行事； |
| 43 | καὶ γὰρ ἐγὼ σοὶ δῶκα ἑκὼν ἀέκοντί γε θυμῷ· | 因這次我雖心不甘情不願，卻也是主動讓步於你； |
| 44 | αἳ γὰρ ὑπʼ ἠελίῳ τε καὶ οὐρανῷ ἀστερόεντι | 須知，在那太陽與滿佈星辰的蒼穹之下， |
| 45 | ναιετάουσι πόληες ἐπιχθονίων ἀνθρώπων, | 凡人所居住的城邦之中， |
| 46 | τάων μοι περὶ κῆρι τιέσκετο Ἴλιος ἱρὴ | 我心中最為珍視的，正是那神聖的伊利昂， |
| 47 | καὶ Πρίαμος καὶ λαὸς ἐϋμμελίω Πριάμοιο. | 還有普里阿摩斯，以及那善使梣木長槍的普里阿摩斯的百姓。 |
| 48 | οὐ γάρ μοί ποτε βωμὸς ἐδεύετο δαιτὸς ἐΐσης | 我的祭壇從未缺少過那公平的祭品、 |
| 49 | λοιβῆς τε κνίσης τε· τὸ γὰρ λάχομεν γέρας ἡμεῖς. | 奠酒與油香；那正是我們神明應得的榮耀。」 |
| 50 | τὸν δʼ ἠμείβετʼ ἔπειτα βοῶπις πότνια Ἥρη· | 牛眼的尊貴女神赫拉隨即回答他道： |
| 51 | ἤτοι ἐμοὶ τρεῖς μὲν πολὺ φίλταταί εἰσι πόληες | 「在我心中，最為珍愛的三座城邦， |
| 52 | Ἄργός τε Σπάρτη τε καὶ εὐρυάγυια Μυκήνη· | 便是阿爾戈斯、斯巴達，以及那街道寬闊的邁錫尼； |
| 53 | τὰς διαπέρσαι ὅτʼ ἄν τοι ἀπέχθωνται περὶ κῆρι· | 若這三座城邦日後令你深惡痛絕，你儘管摧毀它們； |
| 54 | τάων οὔ τοι ἐγὼ πρόσθʼ ἵσταμαι οὐδὲ μεγαίρω. | 我絕不會為此阻擋你，也絕不會心懷妒忌。 |
| 55 | εἴ περ γὰρ φθονέω τε καὶ οὐκ εἰῶ διαπέρσαι, | 即便我心懷妒忌、不願讓你摧毀它們， |
| 56 | οὐκ ἀνύω φθονέουσʼ ἐπεὶ ἦ πολὺ φέρτερός ἐσσι. | 我的妒忌也終究無濟於事，因你的力量遠勝過我。 |
| 57 | ἀλλὰ χρὴ καὶ ἐμὸν θέμεναι πόνον οὐκ ἀτέλεστον· | 但我的辛勞終究也不該就這樣白費； |
| 58 | καὶ γὰρ ἐγὼ θεός εἰμι, γένος δέ μοι ἔνθεν ὅθεν σοί, | 因我同樣是神明，出身與你血脈相同， |
| 59 | καί με πρεσβυτάτην τέκετο Κρόνος ἀγκυλομήτης, | 而狡黠多智的克洛諾斯，更是將我生為長女， |
| 60 | ἀμφότερον γενεῇ τε καὶ οὕνεκα σὴ παράκοιτις | 無論論出身，還是論身分──身為你的妻子， |
| 61 | κέκλημαι, σὺ δὲ πᾶσι μετʼ ἀθανάτοισιν ἀνάσσεις. | 我都名列前茅，而你則統治著全體不朽的神明。 |
| 62 | ἀλλʼ ἤτοι μὲν ταῦθʼ ὑποείξομεν ἀλλήλοισι, | 罷了，讓我們就這件事彼此各退一步吧， |
| 63 | σοὶ μὲν ἐγώ, σὺ δʼ ἐμοί· ἐπὶ δʼ ἕψονται θεοὶ ἄλλοι | 我讓你，你也讓我；其餘不朽的神明 |
| 64 | ἀθάνατοι· σὺ δὲ θᾶσσον Ἀθηναίῃ ἐπιτεῖλαι | 也將隨之而行；你且速速命令雅典娜， |
| 65 | ἐλθεῖν ἐς Τρώων καὶ Ἀχαιῶν φύλοπιν αἰνήν, | 前往特洛伊人與亞該亞人之間那可怖的戰陣， |
| 66 | πειρᾶν δʼ ὥς κε Τρῶες ὑπερκύδαντας Ἀχαιοὺς | 設法讓特洛伊人率先違背誓約， |
| 67 | ἄρξωσι πρότεροι ὑπὲρ ὅρκια δηλήσασθαι. | 對那意氣風發的亞該亞人首開破壞誓約的先例。」 |
| 68 | ὣς ἔφατʼ, οὐδʼ ἀπίθησε πατὴρ ἀνδρῶν τε θεῶν τε· | 她如此說道，眾神與凡人之父並未違逆； |
| 69 | αὐτίκʼ Ἀθηναίην ἔπεα πτερόεντα προσηύδα· | 他立刻對雅典娜開口，說出有翼的話語道： |
| 70 | αἶψα μάλʼ ἐς στρατὸν ἐλθὲ μετὰ Τρῶας καὶ Ἀχαιούς, | 「你速速前往軍營，前往特洛伊人與亞該亞人之間， |
| 71 | πειρᾶν δʼ ὥς κε Τρῶες ὑπερκύδαντας Ἀχαιοὺς | 設法讓特洛伊人率先違背誓約， |
| 72 | ἄρξωσι πρότεροι ὑπὲρ ὅρκια δηλήσασθαι. | 對那意氣風發的亞該亞人首開破壞誓約的先例。」 |
| 73 | ὣς εἰπὼν ὄτρυνε πάρος μεμαυῖαν Ἀθήνην, | 他如此說完，便催促著那本就渴望出動的雅典娜， |
| 74 | βῆ δὲ κατʼ Οὐλύμποιο καρήνων ἀΐξασα. | 她便自奧林波斯的山頂疾速而下。 |
| 75 | οἷον δʼ ἀστέρα ἧκε Κρόνου πάϊς ἀγκυλομήτεω | 宛如狡黠多智的克洛諾斯之子降下一顆流星， |
| 76 | ἢ ναύτῃσι τέρας ἠὲ στρατῷ εὐρέϊ λαῶν | 作為給水手，或給那廣大軍營中百姓的一個徵兆， |
| 77 | λαμπρόν· τοῦ δέ τε πολλοὶ ἀπὸ σπινθῆρες ἵενται· | 那流星光芒燦爛，尾隨著無數的火花； |
| 78 | τῷ ἐϊκυῖʼ ἤϊξεν ἐπὶ χθόνα Παλλὰς Ἀθήνη, | 帕拉斯．雅典娜化作那流星的模樣，疾速降落大地， |
| 79 | κὰδ δʼ ἔθορʼ ἐς μέσσον· θάμβος δʼ ἔχεν εἰσορόωντας | 一躍落入雙方陣中央；觀戰之人無不驚嘆， |
| 80 | Τρῶάς θʼ ἱπποδάμους καὶ ἐϋκνήμιδας Ἀχαιούς· | 無論是特洛伊善馭馬之人，還是脛甲精良的亞該亞人； |
| 81 | ὧδε δέ τις εἴπεσκεν ἰδὼν ἐς πλησίον ἄλλον· | 人人望著身旁之人，紛紛如此說道： |
| 82 | ἦ ῥʼ αὖτις πόλεμός τε κακὸς καὶ φύλοπις αἰνὴ | 「這究竟預示著這場慘烈的戰事、可怖的鏖戰 |
| 83 | ἔσσεται, ἢ φιλότητα μετʼ ἀμφοτέροισι τίθησι | 即將再度爆發，還是宙斯即將在雙方之間 |
| 84 | Ζεύς, ὅς τʼ ἀνθρώπων ταμίης πολέμοιο τέτυκται. | 播下友誼的種子？畢竟他正是凡人戰事的裁決者。」 |
| 85 | ὣς ἄρα τις εἴπεσκεν Ἀχαιῶν τε Τρώων τε. | 亞該亞人與特洛伊人中，都有人如此議論著。 |
| 86 | ἣ δʼ ἀνδρὶ ἰκέλη Τρώων κατεδύσεθʼ ὅμιλον | 她隨即化作凡人的模樣，混入特洛伊人的隊列之中， |
| 87 | Λαοδόκῳ Ἀντηνορίδῃ κρατερῷ αἰχμητῇ, | 化作那強悍的槍手、安忒諾爾之子拉俄多科斯的模樣， |
| 88 | Πάνδαρον ἀντίθεον διζημένη εἴ που ἐφεύροι. | 四處尋找那神一般的潘達羅斯，看是否能找到他。 |
| 89 | εὗρε Λυκάονος υἱὸν ἀμύμονά τε κρατερόν τε | 她終於找到呂卡昂之子，那無可挑剔又強悍之人， |
| 90 | ἑσταότʼ· ἀμφὶ δέ μιν κρατεραὶ στίχες ἀσπιστάων | 正站立不動；他的周圍圍繞著強悍的持盾戰士隊列， |
| 91 | λαῶν, οἵ οἱ ἕποντο ἀπʼ Αἰσήποιο ῥοάων· | 那是自埃塞波斯河而來、隨他而行的百姓； |
| 92 | ἀγχοῦ δʼ ἱσταμένη ἔπεα πτερόεντα προσηύδα· | 她走近他身旁，說出有翼的話語道： |
| 93 | ἦ ῥά νύ μοί τι πίθοιο Λυκάονος υἱὲ δαΐφρον. | 「呂卡昂那機智善戰的兒子啊，你可願聽從我的一項提議？ |
| 94 | τλαίης κεν Μενελάῳ ἐπιπροέμεν ταχὺν ἰόν, | 你若敢向墨涅拉俄斯射出一支疾速的箭矢， |
| 95 | πᾶσι δέ κε Τρώεσσι χάριν καὶ κῦδος ἄροιο, | 你便能贏得全體特洛伊人的感激與榮耀， |
| 96 | ἐκ πάντων δὲ μάλιστα Ἀλεξάνδρῳ βασιλῆϊ. | 而在眾人之中，最感激你的莫過於亞歷山德羅斯王了。 |
| 97 | τοῦ κεν δὴ πάμπρωτα παρʼ ἀγλαὰ δῶρα φέροιο, | 你必定會率先自他那裡獲得豐厚的贈禮， |
| 98 | αἴ κεν ἴδῃ Μενέλαον ἀρήϊον Ἀτρέος υἱὸν | 若他見到那驍勇的阿特柔斯之子墨涅拉俄斯， |
| 99 | σῷ βέλεϊ δμηθέντα πυρῆς ἐπιβάντʼ ἀλεγεινῆς. | 敗於你的箭下，登上那令人悲痛的火葬堆。 |
| 100 | ἀλλʼ ἄγʼ ὀΐστευσον Μενελάου κυδαλίμοιο, | 來吧，向那光榮的墨涅拉俄斯射箭吧， |
| 101 | εὔχεο δʼ Ἀπόλλωνι Λυκηγενέϊ κλυτοτόξῳ | 並向那生於呂基亞、以弓術聞名的阿波羅祈禱， |
| 102 | ἀρνῶν πρωτογόνων ῥέξειν κλειτὴν ἑκατόμβην | 承諾將以頭生的羔羊獻上一場盛大的百牲祭， |
| 103 | οἴκαδε νοστήσας ἱερῆς εἰς ἄστυ Ζελείης. | 待你平安歸返那神聖的澤勒亞城之時。」 |
| 104 | ὣς φάτʼ Ἀθηναίη, τῷ δὲ φρένας ἄφρονι πεῖθεν· | 雅典娜如此說道，說動了他那愚昧的心智； |
| 105 | αὐτίκʼ ἐσύλα τόξον ἐΰξοον ἰξάλου αἰγὸς | 他立刻取出那把以野生山羊角製成、打磨精良的弓， |
| 106 | ἀγρίου, ὅν ῥά ποτʼ αὐτὸς ὑπὸ στέρνοιο τυχήσας | 那山羊本是他當年埋伏守候， |
| 107 | πέτρης ἐκβαίνοντα δεδεγμένος ἐν προδοκῇσι | 趁牠自岩石中走出時，親手射中其胸膛， |
| 108 | βεβλήκει πρὸς στῆθος· ὃ δʼ ὕπτιος ἔμπεσε πέτρῃ. | 那山羊便仰面倒在岩石上而死。 |
| 109 | τοῦ κέρα ἐκ κεφαλῆς ἑκκαιδεκάδωρα πεφύκει· | 牠頭上那對角，足有十六掌之長； |
