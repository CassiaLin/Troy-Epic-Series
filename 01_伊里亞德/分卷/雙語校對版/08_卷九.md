| 672 | πρῶτος δʼ ἐξερέεινεν ἄναξ ἀνδρῶν Ἀγαμέμνων· | 眾人之王阿伽門農率先發問： |
| 673 | εἴπʼ ἄγε μʼ ὦ πολύαινʼ Ὀδυσεῦ μέγα κῦδος Ἀχαιῶν | 「告訴我，備受讚譽的奧德修斯啊，亞該亞人的莫大榮耀， |
| 674 | ἤ ῥʼ ἐθέλει νήεσσιν ἀλεξέμεναι δήϊον πῦρ, | 他究竟願不願意保衛船隊、擋退那毀滅的烈火， |
| 675 | ἦ ἀπέειπε, χόλος δʼ ἔτʼ ἔχει μεγαλήτορα θυμόν; | 還是仍舊拒絕，怒氣依然佔據著他那高傲的心？」 |
| 676 | τὸν δʼ αὖτε προσέειπε πολύτλας δῖος Ὀδυσσεύς· | 久經磨難的光耀的奧德修斯便回答他說道： |
| 677 | Ἀτρεΐδη κύδιστε ἄναξ ἀνδρῶν Ἀγάμεμνον | 「最尊貴的阿特柔斯之子，眾人之王阿伽門農啊， |
| 678 | κεῖνός γʼ οὐκ ἐθέλει σβέσσαι χόλον, ἀλλʼ ἔτι μᾶλλον | 那人絲毫不願平息怒氣，反而更加 |
| 679 | πιμπλάνεται μένεος, σὲ δʼ ἀναίνεται ἠδὲ σὰ δῶρα. | 怒火填膺，拒絕了你和你的禮物。 |
| 680 | αὐτόν σε φράζεσθαι ἐν Ἀργείοισιν ἄνωγεν | 他要你自己在阿爾戈斯人當中思量， |
| 681 | ὅππως κεν νῆάς τε σαῷς καὶ λαὸν Ἀχαιῶν· | 該如何保全船隊與亞該亞人的軍隊； |
| 682 | αὐτὸς δʼ ἠπείλησεν ἅμʼ ἠοῖ φαινομένηφι | 他自己更揚言，待到黎明破曉之時， |
| 683 | νῆας ἐϋσσέλμους ἅλαδʼ ἑλκέμεν ἀμφιελίσσας. | 便要將那舷側堅固、兩端彎翹的船隻拖下海去。 |
| 684 | καὶ δʼ ἂν τοῖς ἄλλοισιν ἔφη παραμυθήσασθαι | 他還說，他會勸告其他人也一同 |
| 685 | οἴκαδʼ ἀποπλείειν, ἐπεὶ οὐκέτι δήετε τέκμωρ | 乘船歸鄉，因為你們再也找不到攻陷 |
| 686 | Ἰλίου αἰπεινῆς· μάλα γάρ ἑθεν εὐρύοπα Ζεὺς | 那高聳的伊利昂的辦法了；因為聲如洪鐘的宙斯 |
| 687 | χεῖρα ἑὴν ὑπερέσχε, τεθαρσήκασι δὲ λαοί. | 已然大力庇護著它，那裡的軍民也因此士氣大振。 |
| 688 | ὣς ἔφατʼ· εἰσὶ καὶ οἵδε τάδʼ εἰπέμεν, οἵ μοι ἕποντο, | 這便是他所說的話；跟隨我前去的這幾位── |
| 689 | Αἴας καὶ κήρυκε δύω πεπνυμένω ἄμφω. | 埃阿斯與兩位精明幹練的傳令官──也都能為我作證。 |

| 691 | ὄφρά οἱ ἐν νήεσσι φίλην ἐς πατρίδʼ ἕπηται | 以便明日若他自己願意的話， |
| 692 | αὔριον, ἢν ἐθέλῃσιν· ἀνάγκῃ δʼ οὔ τί μιν ἄξει. | 便可乘船隨阿基里斯回到他親愛的故鄉；他絕不會被強迫帶走。」 |
| 693 | ὣς ἔφαθʼ, οἳ δʼ ἄρα πάντες ἀκὴν ἐγένοντο σιωπῇ | 他如此說罷，眾人皆陷入一片沉默， |
| 694 | μῦθον ἀγασσάμενοι· μάλα γὰρ κρατερῶς ἀγόρευσε. | 對這番話深感震驚；因為他說得如此決絕強硬。 |
| 695 | δὴν δʼ ἄνεῳ ἦσαν τετιηότες υἷες Ἀχαιῶν· | 亞該亞的兒郎們久久沉默，滿懷憂傷； |
| 696 | ὀψὲ δὲ δὴ μετέειπε βοὴν ἀγαθὸς Διομήδης· | 終於，擅長吶喊的狄俄墨得斯開口說道： |
| 697 | Ἀτρεΐδη κύδιστε ἄναξ ἀνδρῶν Ἀγάμεμνον | 「最尊貴的阿特柔斯之子，眾人之王阿伽門農啊， |
| 698 | μὴ ὄφελες λίσσεσθαι ἀμύμονα Πηλεΐωνα | 你本不該去懇求那無可挑剔的佩琉斯之子， |
| 699 | μυρία δῶρα διδούς· ὃ δʼ ἀγήνωρ ἐστὶ καὶ ἄλλως· | 更不該奉上無數的禮物；他這人本就高傲自負， |
| 700 | νῦν αὖ μιν πολὺ μᾶλλον ἀγηνορίῃσιν ἐνῆκας. | 如今你這樣做，反倒使他更加驕矜自大了。 |
| 701 | ἀλλʼ ἤτοι κεῖνον μὲν ἐάσομεν ἤ κεν ἴῃσιν | 罷了，我們姑且由他去吧，任憑他去、 |
| 702 | ἦ κε μένῃ· τότε δʼ αὖτε μαχήσεται ὁππότε κέν μιν | 或是留下；日後，他自會再度出戰， |
| 703 | θυμὸς ἐνὶ στήθεσσιν ἀνώγῃ καὶ θεὸς ὄρσῃ. | 只等他心中湧起戰意、神明也催促他之時。 |
| 704 | ἀλλʼ ἄγεθʼ ὡς ἂν ἐγὼ εἴπω πειθώμεθα πάντες· | 來吧，眾人且都聽從我的提議： |

| 706 | σίτου καὶ οἴνοιο· τὸ γὰρ μένος ἐστὶ καὶ ἀλκή· | 振奮心神，因為那正是勇力與士氣的泉源； |
| 707 | αὐτὰρ ἐπεί κε φανῇ καλὴ ῥοδοδάκτυλος Ἠώς, | 待到那玫瑰指的黎明美麗地顯現之時， |
| 708 | καρπαλίμως πρὸ νεῶν ἐχέμεν λαόν τε καὶ ἵππους | 你便要迅速地在船前整頓軍隊與戰車， |
| 709 | ὀτρύνων, καὶ δʼ αὐτὸς ἐνὶ πρώτοισι μάχεσθαι. | 親自督戰，並身先士卒地投入前線廝殺。」 |
