# 《伊里亞德》卷七（雙語逐行對照版）

> 底本：Monro-Allen, *Homeri Opera* Editio Tertia (Perseus, tlg0012.tlg001.perseus-grc2)
> 參考譯本：A. T. Murray, Loeb Classical Library, 1924/1925
> 冊次：01冊　|　卷次：卷七　|　行數：482行

| 行 | 希臘原文 | 中文譯文 |
|---|---|---|
| 1 | ὣς εἰπὼν πυλέων ἐξέσσυτο φαίδιμος Ἕκτωρ, | 如此說罷，光輝的赫克托耳便自城門衝出， |
| 2 | τῷ δʼ ἅμʼ Ἀλέξανδρος κίʼ ἀδελφεός· ἐν δʼ ἄρα θυμῷ | 與他同行的是他的兄弟帕里斯；二人心中 |
| 3 | ἀμφότεροι μέμασαν πολεμίζειν ἠδὲ μάχεσθαι. | 皆渴望作戰廝殺。 |
| 4 | ὡς δὲ θεὸς ναύτῃσιν ἐελδομένοισιν ἔδωκεν | 猶如神明賜予渴盼的水手 |
| 5 | οὖρον, ἐπεί κε κάμωσιν ἐϋξέστῃς ἐλάτῃσι | 順風──當他們以打磨精良的松槳 |
| 6 | πόντον ἐλαύνοντες, καμάτῳ δʼ ὑπὸ γυῖα λέλυνται, | 划槳渡海、四肢已因勞累而鬆軟無力之時── |
| 7 | ὣς ἄρα τὼ Τρώεσσιν ἐελδομένοισι φανήτην. | 這二人便如此出現在渴盼他們的特洛伊人眼前。 |
| 8 | ἔνθʼ ἑλέτην ὃ μὲν υἱὸν Ἀρηϊθόοιο ἄνακτος | 於是他們二人各有斬獲：一人殺了王者阿瑞伊托斯之子── |
| 9 | Ἄρνῃ ναιετάοντα Μενέσθιον, ὃν κορυνήτης | 居於阿爾涅的墨涅斯提俄斯，那是使棍者 |
| 10 | γείνατʼ Ἀρηΐθοος καὶ Φυλομέδουσα βοῶπις· | 阿瑞伊托斯與牛眼的菲羅墨杜莎所生； |
| 11 | Ἕκτωρ δʼ Ἠϊονῆα βάλʼ ἔγχεϊ ὀξυόεντι | 赫克托耳則以銳利的長槍擊中厄伊俄紐斯 |
| 12 | αὐχένʼ ὑπὸ στεφάνης εὐχάλκου, λύντο δὲ γυῖα. | 銅盔之下的頸項，其四肢頓時鬆軟。 |
| 13 | Γλαῦκος δʼ Ἱππολόχοιο πάϊς Λυκίων ἀγὸς ἀνδρῶν | 希波羅科斯之子格勞科斯，呂基亞人的統帥， |
| 14 | Ἰφίνοον βάλε δουρὶ κατὰ κρατερὴν ὑσμίνην | 在激烈的戰鬥中以長槍擊中伊菲諾俄斯， |
| 15 | Δεξιάδην ἵππων ἐπιάλμενον ὠκειάων | 那德克西俄斯之子，正要躍上快馬拉的戰車時 |
| 16 | ὦμον· ὃ δʼ ἐξ ἵππων χαμάδις πέσε, λύντο δὲ γυῖα. | 擊中他的肩頭；他便自戰車上墜地，四肢頓時鬆軟。 |
| 17 | τοὺς δʼ ὡς οὖν ἐνόησε θεὰ γλαυκῶπις Ἀθήνη | 灰眸的女神雅典娜見此 |
| 18 | Ἀργείους ὀλέκοντας ἐνὶ κρατερῇ ὑσμίνῃ, | 阿爾戈斯人在激烈戰鬥中不斷倒下， |
| 19 | βῆ ῥα κατʼ Οὐλύμποιο καρήνων ἀΐξασα | 便自奧林波斯山巔疾衝而下， |
| 20 | Ἴλιον εἰς ἱερήν· τῇ δʼ ἀντίος ὄρνυτʼ Ἀπόλλων | 奔赴神聖的伊利昂；阿波羅則迎面而來， |
| 21 | Περγάμου ἐκκατιδών, Τρώεσσι δὲ βούλετο νίκην· | 自珀耳伽摩斯高處望見了她，他盼望特洛伊人得勝； |
| 22 | ἀλλήλοισι δὲ τώ γε συναντέσθην παρὰ φηγῷ. | 二神便在那株橡樹旁相遇。 |
| 23 | τὴν πρότερος προσέειπεν ἄναξ Διὸς υἱὸς Ἀπόλλων· | 王者、宙斯之子阿波羅先開口對她說道： |
| 24 | τίπτε σὺ δʼ αὖ μεμαυῖα Διὸς θύγατερ μεγάλοιο | 「偉大宙斯之女啊，你又如此急切， |
| 25 | ἦλθες ἀπʼ Οὐλύμποιο, μέγας δέ σε θυμὸς ἀνῆκεν; | 自奧林波斯前來，是什麼強烈的心意驅使你？ |
| 26 | ἦ ἵνα δὴ Δαναοῖσι μάχης ἑτεραλκέα νίκην | 莫非是要將戰爭中扭轉局勢的勝利 |
| 27 | δῷς; ἐπεὶ οὔ τι Τρῶας ἀπολλυμένους ἐλεαίρεις. | 賜給達那奧斯人？你對特洛伊人的敗亡毫不憐惜。 |
| 28 | ἀλλʼ εἴ μοί τι πίθοιο τό κεν πολὺ κέρδιον εἴη· | 但若你肯聽我一言，那對大家都更為有利： |
| 29 | νῦν μὲν παύσωμεν πόλεμον καὶ δηϊοτῆτα | 讓我們今日暫且停止這場戰爭與殺伐， |
| 30 | σήμερον· ὕστερον αὖτε μαχήσοντʼ εἰς ὅ κε τέκμωρ | 日後他們自會再戰，直到伊利昂 |
| 31 | Ἰλίου εὕρωσιν, ἐπεὶ ὣς φίλον ἔπλετο θυμῷ | 命定的終局降臨──既然這正是你們這些不死的女神 |
| 32 | ὑμῖν ἀθανάτῃσι, διαπραθέειν τόδε ἄστυ. | 心中所願，要將這座城池徹底毀滅。」 |
| 33 | τὸν δʼ αὖτε προσέειπε θεὰ γλαυκῶπις Ἀθήνη· | 灰眸的女神雅典娜回答他道： |
| 34 | ὧδʼ ἔστω ἑκάεργε· τὰ γὰρ φρονέουσα καὶ αὐτὴ | 「遠射之神啊，就這樣吧；我自己心中所想 |
| 35 | ἦλθον ἀπʼ Οὐλύμποιο μετὰ Τρῶας καὶ Ἀχαιούς. | 也正是如此，才自奧林波斯來到特洛伊人與亞該亞人之間。 |
| 36 | ἀλλʼ ἄγε πῶς μέμονας πόλεμον καταπαυσέμεν ἀνδρῶν; | 但說吧，你打算如何讓這場戰事止息？」 |
| 37 | τὴν δʼ αὖτε προσέειπεν ἄναξ Διὸς υἱὸς Ἀπόλλων· | 王者、宙斯之子阿波羅回答她道： |
| 38 | Ἕκτορος ὄρσωμεν κρατερὸν μένος ἱπποδάμοιο, | 「讓我們激起馴馬者赫克托耳強健的鬥志， |
| 39 | ἤν τινά που Δαναῶν προκαλέσσεται οἰόθεν οἶος | 使他向達那奧斯人中的某人單獨挑戰， |
| 40 | ἀντίβιον μαχέσασθαι ἐν αἰνῇ δηϊοτῆτι, | 在這場慘烈的殺伐中面對面較量； |
| 41 | οἳ δέ κʼ ἀγασσάμενοι χαλκοκνήμιδες Ἀχαιοὶ | 青銅脛甲的亞該亞人見狀必心生激憤， |
| 42 | οἶον ἐπόρσειαν πολεμίζειν Ἕκτορι δίῳ. | 推派一人出戰光耀的赫克托耳。」 |
| 43 | ὣς ἔφατʼ, οὐδʼ ἀπίθησε θεὰ γλαυκῶπις Ἀθήνη. | 他如此說罷，灰眸的女神雅典娜並未拒絕。 |
| 44 | τῶν δʼ Ἕλενος Πριάμοιο φίλος παῖς σύνθετο θυμῷ | 普里阿摩斯的愛子赫勒諾斯心中領會了 |
| 45 | βουλήν, ἥ ῥα θεοῖσιν ἐφήνδανε μητιόωσι· | 諸神所謀劃、令他們滿意的這番計策； |
| 46 | στῆ δὲ παρʼ Ἕκτορʼ ἰὼν καί μιν πρὸς μῦθον ἔειπεν· | 他便走到赫克托耳身旁，對他說道： |
| 47 | Ἕκτορ υἱὲ Πριάμοιο Διὶ μῆτιν ἀτάλαντε | 「赫克托耳，普里阿摩斯之子，智謀堪與宙斯匹敵的人啊， |
| 48 | ἦ ῥά νύ μοί τι πίθοιο, κασίγνητος δέ τοί εἰμι· | 你可願聽我一言？我畢竟是你的兄弟： |
| 49 | ἄλλους μὲν κάθισον Τρῶας καὶ πάντας Ἀχαιούς, | 讓其餘的特洛伊人與全體亞該亞人都坐下歇息， |
| 50 | αὐτὸς δὲ προκάλεσσαι Ἀχαιῶν ὅς τις ἄριστος | 你自己則向亞該亞人中最勇武的一位挑戰， |
| 51 | ἀντίβιον μαχέσασθαι ἐν αἰνῇ δηϊοτῆτι· | 在這慘烈的殺伐中與你面對面較量； |
| 52 | οὐ γάρ πώ τοι μοῖρα θανεῖν καὶ πότμον ἐπισπεῖν· | 因為命運尚未注定你將死去、迎向終局： |
| 53 | ὣς γὰρ ἐγὼ ὄπʼ ἄκουσα θεῶν αἰειγενετάων. | 這是我從永生諸神的話語中聽來的。」 |
| 54 | ὣς ἔφαθʼ, Ἕκτωρ δʼ αὖτε χάρη μέγα μῦθον ἀκούσας, | 他如此說罷，赫克托耳聽聞此言，心中大喜， |
| 55 | καί ῥʼ ἐς μέσσον ἰὼν Τρώων ἀνέεργε φάλαγγας, | 便走到陣前，將特洛伊人的隊伍向後止住， |
| 56 | μέσσου δουρὸς ἑλών· οἳ δʼ ἱδρύνθησαν ἅπαντες. | 以長槍中段按住隊伍；眾人便都坐了下來。 |
| 57 | κὰδ δʼ Ἀγαμέμνων εἷσεν ἐϋκνήμιδας Ἀχαιούς· | 阿伽門農也讓脛甲精良的亞該亞人坐下； |
| 58 | κὰδ δʼ ἄρʼ Ἀθηναίη τε καὶ ἀργυρότοξος Ἀπόλλων | 雅典娜與銀弓的阿波羅 |
| 59 | ἑζέσθην ὄρνισιν ἐοικότες αἰγυπιοῖσι | 也化作兀鷲的模樣棲坐下來， |
| 60 | φηγῷ ἐφʼ ὑψηλῇ πατρὸς Διὸς αἰγιόχοιο | 落在持神盾之父宙斯那株高聳的橡樹上， |
| 61 | ἀνδράσι τερπόμενοι· τῶν δὲ στίχες εἵατο πυκναὶ | 欣賞著眼前的人群；那些密集的隊列 |
| 62 | ἀσπίσι καὶ κορύθεσσι καὶ ἔγχεσι πεφρικυῖαι. | 因盾牌、頭盔與長槍而顯得森然聳立。 |
| 63 | οἵη δὲ Ζεφύροιο ἐχεύατο πόντον ἔπι φρὶξ | 猶如西風初起時 |
| 64 | ὀρνυμένοιο νέον, μελάνει δέ τε πόντος ὑπʼ αὐτῆς, | 海面泛起的漣漪，海水也隨之轉暗， |
| 65 | τοῖαι ἄρα στίχες εἵατʼ Ἀχαιῶν τε Τρώων τε | 亞該亞人與特洛伊人的隊列 |
| 66 | ἐν πεδίῳ· Ἕκτωρ δὲ μετʼ ἀμφοτέροισιν ἔειπε· | 便如此列於平原之上；赫克托耳於是對雙方說道： |
| 67 | κέκλυτέ μευ Τρῶες καὶ ἐϋκνήμιδες Ἀχαιοὶ | 「特洛伊人與脛甲精良的亞該亞人啊，聽我說， |
| 68 | ὄφρʼ εἴπω τά με θυμὸς ἐνὶ στήθεσσι κελεύει. | 讓我說出心中所要說的話。 |
| 69 | ὅρκια μὲν Κρονίδης ὑψίζυγος οὐκ ἐτέλεσσεν, | 居高位的克洛諾斯之子並未成全那誓約， |
| 70 | ἀλλὰ κακὰ φρονέων τεκμαίρεται ἀμφοτέροισιν | 而是心懷惡意，為雙方注定了 |
| 71 | εἰς ὅ κεν ἢ ὑμεῖς Τροίην εὔπυργον ἕλητε | 這樣的結局：要嘛你們攻下城牆堅固的特洛伊， |
| 72 | ἢ αὐτοὶ παρὰ νηυσὶ δαμείετε ποντοπόροισιν. | 要嘛你們自己在渡海的船隻旁被制服。 |
| 73 | ὑμῖν δʼ ἐν γὰρ ἔασιν ἀριστῆες Παναχαιῶν· | 你們之中既有全體亞該亞人的勇士， |
| 74 | τῶν νῦν ὅν τινα θυμὸς ἐμοὶ μαχέσασθαι ἀνώγει | 此刻，若有誰的心驅使他前來與我一戰， |
| 75 | δεῦρʼ ἴτω ἐκ πάντων πρόμος ἔμμεναι Ἕκτορι δίῳ. | 就讓他從眾人之中站出來，作為對抗光耀的赫克托耳的先鋒。 |
| 76 | ὧδε δὲ μυθέομαι, Ζεὺς δʼ ἄμμʼ ἐπιμάρτυρος ἔστω· | 我如此宣告，願宙斯為我們見證： |
| 77 | εἰ μέν κεν ἐμὲ κεῖνος ἕλῃ ταναήκεϊ χαλκῷ, | 倘若那人以修長銳利的青銅將我殺死， |
| 78 | τεύχεα συλήσας φερέτω κοίλας ἐπὶ νῆας, | 就讓他剝去我的甲冑，帶回深闊的船隊， |
| 79 | σῶμα δὲ οἴκαδʼ ἐμὸν δόμεναι πάλιν, ὄφρα πυρός με | 但要將我的遺體交還故鄉，好讓 |
| 80 | Τρῶες καὶ Τρώων ἄλοχοι λελάχωσι θανόντα. | 特洛伊人與特洛伊人的妻子們，能為我這死者舉行火葬之禮。 |
| 81 | εἰ δέ κʼ ἐγὼ τὸν ἕλω, δώῃ δέ μοι εὖχος Ἀπόλλων, | 倘若是我殺了他，阿波羅賜我這份榮耀， |
| 82 | τεύχεα σύλησας οἴσω προτὶ Ἴλιον ἱρήν, | 我便要剝下他的甲冑，帶回神聖的伊利昂， |
| 83 | καὶ κρεμόω προτὶ νηὸν Ἀπόλλωνος ἑκάτοιο, | 懸掛在遠射者阿波羅的神廟之中， |
| 84 | τὸν δὲ νέκυν ἐπὶ νῆας ἐϋσσέλμους ἀποδώσω, | 而將他的遺體交還給那些堅固的船隻， |
| 85 | ὄφρά ἑ ταρχύσωσι κάρη κομόωντες Ἀχαιοί, | 好讓長髮的亞該亞人為他舉行葬禮， |
| 86 | σῆμά τέ οἱ χεύωσιν ἐπὶ πλατεῖ Ἑλλησπόντῳ. | 並在遼闊的赫勒斯滂岸邊為他築起墳塚。 |
| 87 | καί ποτέ τις εἴπῃσι καὶ ὀψιγόνων ἀνθρώπων | 日後也將有後代子孫這樣說道， |
| 88 | νηῒ πολυκλήϊδι πλέων ἐπὶ οἴνοπα πόντον· | 當他乘著多槳之船，航行在酒色深沉的海上： |
| 89 | ἀνδρὸς μὲν τόδε σῆμα πάλαι κατατεθνηῶτος, | 『這是一位早已亡故之人的墳塚， |
| 90 | ὅν ποτʼ ἀριστεύοντα κατέκτανε φαίδιμος Ἕκτωρ. | 他當年英勇奮戰，卻被光輝的赫克托耳所殺。』 |
| 91 | ὥς ποτέ τις ἐρέει· τὸ δʼ ἐμὸν κλέος οὔ ποτʼ ὀλεῖται. | 將來必有人如此說道；而我的榮名將永不磨滅。」 |
| 92 | ὣς ἔφαθʼ, οἱ δʼ ἄρα πάντες ἀκὴν ἐγένοντο σιωπῇ· | 他如此說罷，眾人皆陷入一片沉默； |
| 93 | αἴδεσθεν μὲν ἀνήνασθαι, δεῖσαν δʼ ὑποδέχθαι· | 他們既羞於拒絕，又懼於應戰。 |
| 94 | ὀψὲ δὲ δὴ Μενέλαος ἀνίστατο καὶ μετέειπε | 終於，墨涅拉俄斯站了起來，開口說話， |
| 95 | νείκει ὀνειδίζων, μέγα δὲ στεναχίζετο θυμῷ· | 他滿懷責備地斥罵眾人，心中悲嘆不已： |
| 96 | ὤ μοι ἀπειλητῆρες Ἀχαιΐδες οὐκέτʼ Ἀχαιοί· | 「唉，你們這些誇口之輩，是亞該亞的女人，不再是亞該亞的男兒！ |
| 97 | ἦ μὲν δὴ λώβη τάδε γʼ ἔσσεται αἰνόθεν αἰνῶς | 這將會是奇恥大辱，恥辱至極， |
| 98 | εἰ μή τις Δαναῶν νῦν Ἕκτορος ἀντίος εἶσιν. | 倘若此刻沒有一個達那奧斯人敢上前迎戰赫克托耳。 |
| 99 | ἀλλʼ ὑμεῖς μὲν πάντες ὕδωρ καὶ γαῖα γένοισθε | 但願你們統統化作水與泥土， |
| 100 | ἥμενοι αὖθι ἕκαστοι ἀκήριοι ἀκλεὲς αὔτως· | 就這樣一個個坐在原地，喪盡心志、毫無榮名！ |
| 101 | τῷδε δʼ ἐγὼν αὐτὸς θωρήξομαι· αὐτὰρ ὕπερθε | 我要親自披甲迎戰此人；至於勝負的 |
| 102 | νίκης πείρατʼ ἔχονται ἐν ἀθανάτοισι θεοῖσιν. | 繩索，終究握在不死的諸神手中。」 |
| 103 | ὣς ἄρα φωνήσας κατεδύσετο τεύχεα καλά. | 他如此說罷，便穿上那副精美的甲冑。 |
| 104 | ἔνθά κέ τοι Μενέλαε φάνη βιότοιο τελευτὴ | 墨涅拉俄斯啊，此時你的性命本將終結 |
| 105 | Ἕκτορος ἐν παλάμῃσιν, ἐπεὶ πολὺ φέρτερος ἦεν, | 於赫克托耳之手，因為他遠比你強壯， |
| 106 | εἰ μὴ ἀναΐξαντες ἕλον βασιλῆες Ἀχαιῶν, | 若非亞該亞人的眾王一躍而起，將你攔住， |
| 107 | αὐτός τʼ Ἀτρεΐδης εὐρὺ κρείων Ἀγαμέμνων | 其中包括阿特柔斯之子、統治廣大的阿伽門農， |
| 108 | δεξιτερῆς ἕλε χειρὸς ἔπος τʼ ἔφατʼ ἔκ τʼ ὀνόμαζεν· | 他握住你的右手，開口喚著你的名字說道： |
| 109 | ἀφραίνεις Μενέλαε διοτρεφές, οὐδέ τί σε χρὴ | 「宙斯養育的墨涅拉俄斯啊，你瘋了嗎？你根本不需要 |
| 110 | ταύτης ἀφροσύνης· ἀνὰ δὲ σχέο κηδόμενός περ, | 做這樣魯莽的事；儘管憂心，也請你克制， |
| 111 | μηδʼ ἔθελʼ ἐξ ἔριδος σεῦ ἀμείνονι φωτὶ μάχεσθαι | 不要為了逞一時之氣，就去與比你更強的人交戰── |
| 112 | Ἕκτορι Πριαμίδῃ, τόν τε στυγέουσι καὶ ἄλλοι. | 普里阿摩斯之子赫克托耳，連旁人都對他心懷畏懼。 |
