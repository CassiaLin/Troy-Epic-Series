# 《伊里亞德》卷六　雙語逐行對照版

| 1 | Τρώων δʼ οἰώθη καὶ Ἀχαιῶν φύλοπις αἰνή· | 特洛伊人與亞該亞人之間，那可怖的鏖戰便如此獨自延續下去； |
| 2 | πολλὰ δʼ ἄρʼ ἔνθα καὶ ἔνθʼ ἴθυσε μάχη πεδίοιο | 戰事在平原上或這方、或那方地反覆推移， |
| 3 | ἀλλήλων ἰθυνομένων χαλκήρεα δοῦρα | 雙方彼此瞄準，投擲著包覆青銅的長槍， |
| 4 | μεσσηγὺς Σιμόεντος ἰδὲ Ξάνθοιο ῥοάων. | 就在西摩伊斯河與克珊托斯河的水流之間。 |
| 5 | Αἴας δὲ πρῶτος Τελαμώνιος ἕρκος Ἀχαιῶν | 忒拉蒙之子埃阿斯，亞該亞人的堅固屏障，率先 |
| 6 | Τρώων ῥῆξε φάλαγγα, φόως δʼ ἑτάροισιν ἔθηκεν, | 突破了特洛伊人的方陣，為同伴帶來一線曙光， |
| 7 | ἄνδρα βαλὼν ὃς ἄριστος ἐνὶ Θρῄκεσσι τέτυκτο | 他擊倒了色雷斯人中最為傑出之人， |
| 8 | υἱὸν Ἐϋσσώρου Ἀκάμαντʼ ἠΰν τε μέγαν τε. | 那是歐宋羅斯之子、俊美高大的阿卡瑪斯。 |
| 9 | τόν ῥʼ ἔβαλε πρῶτος κόρυθος φάλον ἱπποδασείης, | 埃阿斯率先擊中他頭盔上那飾有濃密馬鬃的角飾， |
| 10 | ἐν δὲ μετώπῳ πῆξε, πέρησε δʼ ἄρʼ ὀστέον εἴσω | 刺入他的額頭，那青銅槍尖徑直穿透了 |
| 11 | αἰχμὴ χαλκείη· τὸν δὲ σκότος ὄσσε κάλυψεν. | 頭骨；黑暗頓時籠罩了他的雙眼。 |
| 12 | Ἄξυλον δʼ ἄρʼ ἔπεφνε βοὴν ἀγαθὸς Διομήδης | 那擅長吶喊的狄俄墨得斯則殺死了阿克敘羅斯， |
| 13 | Τευθρανίδην, ὃς ἔναιεν ἐϋκτιμένῃ ἐν Ἀρίσβῃ | 透特拉斯之子，他居於那建造精良的阿里斯柏， |
| 14 | ἀφνειὸς βιότοιο, φίλος δʼ ἦν ἀνθρώποισι. | 家境富裕、生活優渥，深受眾人喜愛。 |
| 15 | πάντας γὰρ φιλέεσκεν ὁδῷ ἔπι οἰκία ναίων. | 因他家宅坐落於大道旁，向來熱情款待過往行人。 |
| 16 | ἀλλά οἱ οὔ τις τῶν γε τότʼ ἤρκεσε λυγρὸν ὄλεθρον | 然而那些他曾款待過的人，如今卻無人能為他擋下 |
| 17 | πρόσθεν ὑπαντιάσας, ἀλλʼ ἄμφω θυμὸν ἀπηύρα | 這場悲慘的滅亡、無人挺身相助；狄俄墨得斯奪去了他與 |
| 18 | αὐτὸν καὶ θεράποντα Καλήσιον, ὅς ῥα τόθʼ ἵππων | 他隨從卡萊西俄斯二人的性命，那隨從當時 |
| 19 | ἔσκεν ὑφηνίοχος· τὼ δʼ ἄμφω γαῖαν ἐδύτην. | 正擔任馭馬的副手；二人便一同倒臥入土。 |
| 20 | Δρῆσον δʼ Εὐρύαλος καὶ Ὀφέλτιον ἐξενάριξε· | 歐律阿羅斯則殺死了德瑞索斯與俄斐爾提俄斯； |
| 21 | βῆ δὲ μετʼ Αἴσηπον καὶ Πήδασον, οὕς ποτε νύμφη | 他隨即又轉向埃塞波斯與佩達索斯二人，他們是 |
| 22 | νηῒς Ἀβαρβαρέη τέκʼ ἀμύμονι Βουκολίωνι. | 那水澤仙女阿巴爾巴瑞埃，與無可挑剔的布科利翁所生。 |
| 23 | Βουκολίων δʼ ἦν υἱὸς ἀγαυοῦ Λαομέδοντος | 布科利翁本是那聲名顯赫的拉俄墨東之子， |
| 24 | πρεσβύτατος γενεῇ, σκότιον δέ ἑ γείνατο μήτηρ· | 是家中的長子，卻是母親私下所生的私生子； |
| 25 | ποιμαίνων δʼ ἐπʼ ὄεσσι μίγη φιλότητι καὶ εὐνῇ, | 他在牧羊之時，與那仙女共赴魚水之歡， |
| 26 | ἣ δʼ ὑποκυσαμένη διδυμάονε γείνατο παῖδε. | 仙女因此懷孕，生下了這對孿生子。 |
| 27 | καὶ μὲν τῶν ὑπέλυσε μένος καὶ φαίδιμα γυῖα | 墨基斯透斯之子則奪去了他們的力量、 |
| 28 | Μηκιστηϊάδης καὶ ἀπʼ ὤμων τεύχεʼ ἐσύλα. | 使他們光輝的四肢頹然倒下，並剝取了他們肩上的甲冑。 |
| 29 | Ἀστύαλον δʼ ἄρʼ ἔπεφνε μενεπτόλεμος Πολυποίτης· | 那堅毅善戰的波呂波忒斯則殺死了阿斯圖阿羅斯； |
| 30 | Πιδύτην δʼ Ὀδυσεὺς Περκώσιον ἐξενάριξεν | 奧德修斯則以青銅長槍，殺死了珀爾科忒人 |
| 31 | ἔγχεϊ χαλκείῳ, Τεῦκρος δʼ Ἀρετάονα δῖον. | 皮杜特斯；透克洛斯則殺死了神聖的阿瑞塔翁。 |
| 32 | Ἀντίλοχος δʼ Ἄβληρον ἐνήρατο δουρὶ φαεινῷ | 涅斯托爾之子安提洛科斯以那閃亮的長槍， |
| 33 | Νεστορίδης, Ἔλατον δὲ ἄναξ ἀνδρῶν Ἀγαμέμνων· | 殺死了阿布勒羅斯；眾人之王阿伽門農則殺死了埃拉托斯； |
| 34 | ναῖε δὲ Σατνιόεντος ἐϋρρείταο παρʼ ὄχθας | 埃拉托斯本居於那水流暢通的薩特尼俄埃斯河畔、 |
| 35 | Πήδασον αἰπεινήν. Φύλακον δʼ ἕλε Λήϊτος ἥρως | 高聳的佩達索斯城。英雄勒伊托斯則擊殺了正在逃跑的 |
| 36 | φεύγοντʼ· Εὐρύπυλος δὲ Μελάνθιον ἐξενάριξεν. | 菲拉科斯；歐律皮羅斯則殺死了墨蘭提俄斯。 |
| 37 | Ἄδρηστον δʼ ἄρʼ ἔπειτα βοὴν ἀγαθὸς Μενέλαος | 那擅長吶喊的墨涅拉俄斯，隨即生擒了 |
| 38 | ζωὸν ἕλʼ· ἵππω γάρ οἱ ἀτυζομένω πεδίοιο | 阿德拉斯托斯；因他那對戰馬在平原上受驚狂奔， |
| 39 | ὄζῳ ἔνι βλαφθέντε μυρικίνῳ ἀγκύλον ἅρμα | 被一根檉柳的枝椏纏住，折斷了那彎曲戰車 |
| 40 | ἄξαντʼ ἐν πρώτῳ ῥυμῷ αὐτὼ μὲν ἐβήτην | 前端的車轅，那對戰馬便逕自 |
| 41 | πρὸς πόλιν, ᾗ περ οἱ ἄλλοι ἀτυζόμενοι φοβέοντο, | 奔向城中，正如其餘受驚逃竄之馬匹的去向一般， |
| 42 | αὐτὸς δʼ ἐκ δίφροιο παρὰ τροχὸν ἐξεκυλίσθη | 而阿德拉斯托斯自己則自戰車上滾落，摔在車輪旁， |
| 43 | πρηνὴς ἐν κονίῃσιν ἐπὶ στόμα· πὰρ δέ οἱ ἔστη | 面朝下、口鼻著地地跌入塵土之中；阿特柔斯之子 |
| 44 | Ἀτρεΐδης Μενέλαος ἔχων δολιχόσκιον ἔγχος. | 墨涅拉俄斯手持那投影修長的長槍，站到了他身旁。 |
| 45 | Ἄδρηστος δʼ ἄρʼ ἔπειτα λαβὼν ἐλίσσετο γούνων· | 阿德拉斯托斯隨即抱住他的雙膝，苦苦哀求道： |
| 46 | ζώγρει Ἀτρέος υἱέ, σὺ δʼ ἄξια δέξαι ἄποινα· | 「阿特柔斯之子啊，饒我一命吧，收下與我相稱的贖金； |
| 47 | πολλὰ δʼ ἐν ἀφνειοῦ πατρὸς κειμήλια κεῖται | 我那富裕的父親家中，收藏著無數珍寶， |
| 48 | χαλκός τε χρυσός τε πολύκμητός τε σίδηρος, | 有青銅、有黃金，也有那精工鍛造的鐵器， |
| 49 | τῶν κέν τοι χαρίσαιτο πατὴρ ἀπερείσιʼ ἄποινα | 我父親必會慷慨贈予你無數的贖禮， |
| 50 | εἴ κεν ἐμὲ ζωὸν πεπύθοιτʼ ἐπὶ νηυσὶν Ἀχαιῶν. | 只要他得知我仍活著、身在亞該亞人的船隊之中。」 |
| 51 | ὣς φάτο, τῷ δʼ ἄρα θυμὸν ἐνὶ στήθεσσιν ἔπειθε· | 他如此說道，這番話說動了墨涅拉俄斯的心； |
| 52 | καὶ δή μιν τάχʼ ἔμελλε θοὰς ἐπὶ νῆας Ἀχαιῶν | 他正打算將他交給自己的隨從， |
| 53 | δώσειν ᾧ θεράποντι καταξέμεν· ἀλλʼ Ἀγαμέμνων | 帶回亞該亞人那迅捷的船隊；然而阿伽門農 |
| 54 | ἀντίος ἦλθε θέων, καὶ ὁμοκλήσας ἔπος ηὔδα· | 卻疾步跑來，厲聲斥責他道： |
| 55 | ὦ πέπον ὦ Μενέλαε, τί ἢ δὲ σὺ κήδεαι οὕτως | 「親愛的墨涅拉俄斯啊，你為何如此顧惜 |
| 56 | ἀνδρῶν; ἦ σοὶ ἄριστα πεποίηται κατὰ οἶκον | 這些人的性命？難道特洛伊人在你家中， |
| 57 | πρὸς Τρώων; τῶν μή τις ὑπεκφύγοι αἰπὺν ὄλεθρον | 對你做過什麼天大的好事嗎？別讓他們之中任何一人， |
| 58 | χεῖράς θʼ ἡμετέρας, μηδʼ ὅν τινα γαστέρι μήτηρ | 逃過那陡峭的滅亡、逃過我們的雙手，即便是母親腹中 |
| 59 | κοῦρον ἐόντα φέροι, μηδʼ ὃς φύγοι, ἀλλʼ ἅμα πάντες | 尚未出世的男嬰也不例外，一個都不許逃脫，讓他們全都 |
| 60 | Ἰλίου ἐξαπολοίατʼ ἀκήδεστοι καὶ ἄφαντοι. | 隨伊利昂一同滅亡，屍骨無存、無人憑弔。」 |
| 61 | ὣς εἰπὼν ἔτρεψεν ἀδελφειοῦ φρένας ἥρως | 這位英雄如此說完，便扭轉了他兄弟的心意， |
| 62 | αἴσιμα παρειπών· ὃ δʼ ἀπὸ ἕθεν ὤσατο χειρὶ | 因他這番話合乎情理；墨涅拉俄斯便伸手推開了 |
| 63 | ἥρωʼ Ἄδρηστον· τὸν δὲ κρείων Ἀγαμέμνων | 英雄阿德拉斯托斯；統治者阿伽門農隨即 |
| 64 | οὖτα κατὰ λαπάρην· ὃ δʼ ἀνετράπετʼ, Ἀτρεΐδης δὲ | 一槍刺入他的腰側；他便向後倒下，阿特柔斯之子 |
| 65 | λὰξ ἐν στήθεσι βὰς ἐξέσπασε μείλινον ἔγχος. | 一腳踏在他的胸口，將那梣木長槍拔了出來。 |
| 66 | Νέστωρ δʼ Ἀργείοισιν ἐκέκλετο μακρὸν ἀΰσας· | 涅斯托爾則向阿爾戈斯人高聲呼喊道： |
| 67 | ὦ φίλοι ἥρωες Δαναοὶ θεράποντες Ἄρηος | 「諸位好友，達那奧斯人的英雄們啊，阿瑞斯的隨從們， |
| 68 | μή τις νῦν ἐνάρων ἐπιβαλλόμενος μετόπισθε | 如今誰也別只顧著在後方搜刮戰利品、 |
| 69 | μιμνέτω ὥς κε πλεῖστα φέρων ἐπὶ νῆας ἵκηται, | 只想著滿載而歸、返回船邊， |
| 70 | ἀλλʼ ἄνδρας κτείνωμεν· ἔπειτα δὲ καὶ τὰ ἕκηλοι | 讓我們先專心殺敵；之後你們自能從容不迫地 |
| 71 | νεκροὺς ἂμ πεδίον συλήσετε τεθνηῶτας. | 在這片平原上，剝取那些屍體的財物。」 |
| 72 | ὣς εἰπὼν ὄτρυνε μένος καὶ θυμὸν ἑκάστου. | 他如此說完，激起了每個人心中的力量與鬥志。 |
| 73 | ἔνθά κεν αὖτε Τρῶες ἀρηϊφίλων ὑπʼ Ἀχαιῶν | 這時，特洛伊人恐怕已在那深受戰神所愛的亞該亞人面前， |
| 74 | Ἴλιον εἰσανέβησαν ἀναλκείῃσι δαμέντες, | 因喪失鬥志而敗退回伊利昂城中了， |
| 75 | εἰ μὴ ἄρʼ Αἰνείᾳ τε καὶ Ἕκτορι εἶπε παραστὰς | 若非普里阿摩斯之子赫勒諾斯，那位卜鳥術中 |
| 76 | Πριαμίδης Ἕλενος οἰωνοπόλων ὄχʼ ἄριστος· | 最為出眾之人，走到埃涅阿斯與赫克托耳身旁開口道： |
| 77 | Αἰνεία τε καὶ Ἕκτορ, ἐπεὶ πόνος ὔμμι μάλιστα | 「埃涅阿斯與赫克托耳啊，特洛伊人與呂基亞人的 |
| 78 | Τρώων καὶ Λυκίων ἐγκέκλιται, οὕνεκʼ ἄριστοι | 重擔，如今最為沉重地落在你們二人身上，因你們二人 |
| 79 | πᾶσαν ἐπʼ ἰθύν ἐστε μάχεσθαί τε φρονέειν τε, | 無論在戰鬥或謀略上，各方面都是最為傑出之人， |
| 80 | στῆτʼ αὐτοῦ, καὶ λαὸν ἐρυκάκετε πρὸ πυλάων | 你們且駐守此地，四處奔走，攔住百姓， |
| 81 | πάντῃ ἐποιχόμενοι πρὶν αὖτʼ ἐν χερσὶ γυναικῶν | 別讓他們在城門前潰逃，落入婦人們的懷抱之中， |
| 82 | φεύγοντας πεσέειν, δηΐοισι δὲ χάρμα γενέσθαι. | 那將成為敵人的一大樂事。 |
| 83 | αὐτὰρ ἐπεί κε φάλαγγας ἐποτρύνητον ἁπάσας, | 待你們督促全軍各支方陣完畢之後， |
| 84 | ἡμεῖς μὲν Δαναοῖσι μαχησόμεθʼ αὖθι μένοντες, | 我們便留在此地，與達那奧斯人繼續奮戰， |
| 85 | καὶ μάλα τειρόμενοί περ· ἀναγκαίη γὰρ ἐπείγει· | 儘管我們已疲憊不堪；因情勢所迫，不得不然； |
| 86 | Ἕκτορ ἀτὰρ σὺ πόλιν δὲ μετέρχεο, εἰπὲ δʼ ἔπειτα | 赫克托耳啊，但你且返回城中，去告訴 |
| 87 | μητέρι σῇ καὶ ἐμῇ· ἣ δὲ ξυνάγουσα γεραιὰς | 你我共同的母親；讓她召集城中的老婦人， |
| 88 | νηὸν Ἀθηναίης γλαυκώπιδος ἐν πόλει ἄκρῃ | 前往那位於衛城高處、灰眸的雅典娜的神殿， |
| 89 | οἴξασα κληῗδι θύρας ἱεροῖο δόμοιο | 用鑰匙打開那神聖殿堂的大門， |
| 90 | πέπλον, ὅς οἱ δοκέει χαριέστατος ἠδὲ μέγιστος | 取出她認為最為華美、最為碩大、 |
| 91 | εἶναι ἐνὶ μεγάρῳ καί οἱ πολὺ φίλτατος αὐτῇ, | 家中最為珍愛的一件長袍， |
| 92 | θεῖναι Ἀθηναίης ἐπὶ γούνασιν ἠϋκόμοιο, | 將它獻上，放置在那秀髮雅典娜的膝上， |
| 93 | καί οἱ ὑποσχέσθαι δυοκαίδεκα βοῦς ἐνὶ νηῷ | 並向她許諾，將在神殿中為她獻祭 |
| 94 | ἤνις ἠκέστας ἱερευσέμεν, αἴ κʼ ἐλεήσῃ | 十二頭未曾配種、未受過鞭策的小牛，若她願意憐憫 |
| 95 | ἄστύ τε καὶ Τρώων ἀλόχους καὶ νήπια τέκνα, | 這座城池與特洛伊人的妻子與幼小的孩兒， |
| 96 | ὥς κεν Τυδέος υἱὸν ἀπόσχῃ Ἰλίου ἱρῆς | 讓她使圖丟斯之子遠離神聖的伊利昂， |
| 97 | ἄγριον αἰχμητὴν κρατερὸν μήστωρα φόβοιο, | 那狂暴的槍手、令人聞風喪膽的強悍之人， |
| 98 | ὃν δὴ ἐγὼ κάρτιστον Ἀχαιῶν φημι γενέσθαι. | 依我看來，他正是亞該亞人中最為強悍之人。 |
| 99 | οὐδʼ Ἀχιλῆά ποθʼ ὧδέ γʼ ἐδείδιμεν ὄρχαμον ἀνδρῶν, | 就連壯士的統帥阿基里斯，我們也從未如此畏懼過， |
| 100 | ὅν πέρ φασι θεᾶς ἐξέμμεναι· ἀλλʼ ὅδε λίην | 那位人稱是女神之子的阿基里斯；然而狄俄墨得斯此人 |
| 101 | μαίνεται, οὐδέ τίς οἱ δύναται μένος ἰσοφαρίζειν. | 卻已瘋狂至極，無人能與他的力量相抗衡。」 |
| 102 | ὣς ἔφαθʼ, Ἕκτωρ δʼ οὔ τι κασιγνήτῳ ἀπίθησεν. | 他如此說道，赫克托耳並未違逆他兄弟的話語。 |
| 103 | αὐτίκα δʼ ἐξ ὀχέων σὺν τεύχεσιν ἆλτο χαμᾶζε, | 他立刻身披甲冑，自戰車上一躍而下， |
| 104 | πάλλων δʼ ὀξέα δοῦρα κατὰ στρατὸν ᾤχετο πάντῃ | 揮舞著銳利的長槍，穿梭於全軍各處， |
| 105 | ὀτρύνων μαχέσασθαι, ἔγειρε δὲ φύλοπιν αἰνήν. | 催促眾人投入戰事，重新點燃了那可怖的鏖戰。 |

| 437 | ἠδʼ ἀμφʼ Ἀτρεΐδας καὶ Τυδέος ἄλκιμον υἱόν· | 阿特柔斯的兩個兒子，以及圖丟斯那勇猛的兒子； |
| 438 | ἤ πού τίς σφιν ἔνισπε θεοπροπίων ἐῢ εἰδώς, | 或許是某位精通神諭之人向他們指點了此處， |
| 439 | ἤ νυ καὶ αὐτῶν θυμὸς ἐποτρύνει καὶ ἀνώγει. | 又或者是他們自己的直覺催促、引導他們前往那裡。」 |
| 440 | τὴν δʼ αὖτε προσέειπε μέγας κορυθαίολος Ἕκτωρ· | 那高大、頭盔閃耀的赫克托耳隨即回答她道： |
| 441 | ἦ καὶ ἐμοὶ τάδε πάντα μέλει γύναι· ἀλλὰ μάλʼ αἰνῶς | 「夫人啊，這一切我又何嘗不掛心；但我實在深深 |
| 442 | αἰδέομαι Τρῶας καὶ Τρῳάδας ἑλκεσιπέπλους, | 敬畏特洛伊的男男女女，那些身著曳地長袍的婦人們， |
| 443 | αἴ κε κακὸς ὣς νόσφιν ἀλυσκάζω πολέμοιο· | 若我像個懦夫般，遠離戰場、躲避不前； |
| 444 | οὐδέ με θυμὸς ἄνωγεν, ἐπεὶ μάθον ἔμμεναι ἐσθλὸς | 我的心志也不容許我如此，因我早已學會，要永遠做個 |
| 445 | αἰεὶ καὶ πρώτοισι μετὰ Τρώεσσι μάχεσθαι | 傑出之人，永遠身處特洛伊人的最前線奮戰， |
| 446 | ἀρνύμενος πατρός τε μέγα κλέος ἠδʼ ἐμὸν αὐτοῦ. | 為父親、也為自己贏得莫大的榮耀。 |
| 447 | εὖ γὰρ ἐγὼ τόδε οἶδα κατὰ φρένα καὶ κατὰ θυμόν· | 因這一點我心中十分明白： |
| 448 | ἔσσεται ἦμαρ ὅτʼ ἄν ποτʼ ὀλώλῃ Ἴλιος ἱρὴ | 終有一日，神聖的伊利昂必將滅亡， |
| 449 | καὶ Πρίαμος καὶ λαὸς ἐϋμμελίω Πριάμοιο. | 普里阿摩斯與那善使梣木長槍的普里阿摩斯的百姓也必將滅亡。 |
| 450 | ἀλλʼ οὔ μοι Τρώων τόσσον μέλει ἄλγος ὀπίσσω, | 但日後那將降臨的苦難，令我最為牽掛的， |
| 451 | οὔτʼ αὐτῆς Ἑκάβης οὔτε Πριάμοιο ἄνακτος | 卻不是特洛伊人的苦難，不是赫卡柏本人、也不是普里阿摩斯王的苦難， |
| 452 | οὔτε κασιγνήτων, οἵ κεν πολέες τε καὶ ἐσθλοὶ | 更不是我那些兄弟的苦難，儘管他們人數眾多、個個傑出， |
| 453 | ἐν κονίῃσι πέσοιεν ὑπʼ ἀνδράσι δυσμενέεσσιν, | 終將倒臥在塵土之中，命喪於仇敵之手， |
| 454 | ὅσσον σεῦ, ὅτε κέν τις Ἀχαιῶν χαλκοχιτώνων | 而是你的苦難，那時某位身披青銅甲的亞該亞人， |
| 455 | δακρυόεσσαν ἄγηται ἐλεύθερον ἦμαρ ἀπούρας· | 將奪去你自由的日子，把你淚流滿面地擄走； |
| 456 | καί κεν ἐν Ἄργει ἐοῦσα πρὸς ἄλλης ἱστὸν ὑφαίνοις, | 屆時你將身在阿爾戈斯，為他人織布， |
| 457 | καί κεν ὕδωρ φορέοις Μεσσηΐδος ἢ Ὑπερείης | 也將被迫自墨塞伊斯泉或許佩瑞亞泉汲水， |
| 458 | πόλλʼ ἀεκαζομένη, κρατερὴ δʼ ἐπικείσετʼ ἀνάγκη· | 縱然萬般不願，那強大的命運卻不容你迴避； |
| 459 | καί ποτέ τις εἴπῃσιν ἰδὼν κατὰ δάκρυ χέουσαν· | 屆時，某位見你淚流滿面之人，或許會如此說道： |
| 460 | Ἕκτορος ἥδε γυνὴ ὃς ἀριστεύεσκε μάχεσθαι | 『這位正是赫克托耳的妻子，在他們圍繞伊利昂作戰之時， |
| 461 | Τρώων ἱπποδάμων ὅτε Ἴλιον ἀμφεμάχοντο. | 他是善於馴馬的特洛伊人裡作戰最勇猛的一個。』 |
| 462 | ὥς ποτέ τις ἐρέει· σοὶ δʼ αὖ νέον ἔσσεται ἄλγος | 屆時或許真有人會如此說；而對你而言，那將是新的一層苦痛， |
| 463 | χήτεϊ τοιοῦδʼ ἀνδρὸς ἀμύνειν δούλιον ἦμαρ. | 因失去了這樣一位丈夫，再也無人能為你擋下那奴役的日子。 |
| 464 | ἀλλά με τεθνηῶτα χυτὴ κατὰ γαῖα καλύπτοι | 但願在我聽見你的哭喊、聽見你被擄走的消息之前， |
| 465 | πρίν γέ τι σῆς τε βοῆς σοῦ θʼ ἑλκηθμοῖο πυθέσθαι. | 那堆積的塵土便已將我這死去之人掩埋。」 |
| 466 | ὣς εἰπὼν οὗ παιδὸς ὀρέξατο φαίδιμος Ἕκτωρ· | 光輝的赫克托耳如此說完，便伸手要抱過自己的孩子； |
| 467 | ἂψ δʼ ὃ πάϊς πρὸς κόλπον ἐϋζώνοιο τιθήνης | 那孩子卻驚叫著，向後縮回那腰帶精美的乳母懷中， |
| 468 | ἐκλίνθη ἰάχων πατρὸς φίλου ὄψιν ἀτυχθεὶς | 對親愛父親的模樣感到驚駭， |
| 469 | ταρβήσας χαλκόν τε ἰδὲ λόφον ἱππιοχαίτην, | 因他畏懼那青銅甲冑，以及那頭盔上飾有馬鬃的羽飾， |
| 470 | δεινὸν ἀπʼ ἀκροτάτης κόρυθος νεύοντα νοήσας. | 他望見那羽飾自頭盔頂端可怖地搖曳晃動。 |
| 471 | ἐκ δʼ ἐγέλασσε πατήρ τε φίλος καὶ πότνια μήτηρ· | 親愛的父親與尊貴的母親見狀，都不禁笑了起來； |
| 472 | αὐτίκʼ ἀπὸ κρατὸς κόρυθʼ εἵλετο φαίδιμος Ἕκτωρ, | 光輝的赫克托耳立刻自頭上摘下頭盔， |
| 473 | καὶ τὴν μὲν κατέθηκεν ἐπὶ χθονὶ παμφανόωσαν· | 將那閃閃發亮的頭盔放置在地上； |
| 474 | αὐτὰρ ὅ γʼ ὃν φίλον υἱὸν ἐπεὶ κύσε πῆλέ τε χερσὶν | 隨後他親吻自己親愛的兒子，將他抱起、輕輕搖晃， |
| 475 | εἶπε δʼ ἐπευξάμενος Διί τʼ ἄλλοισίν τε θεοῖσι· | 並向宙斯與其餘的神明祈禱道： |
| 476 | Ζεῦ ἄλλοι τε θεοὶ δότε δὴ καὶ τόνδε γενέσθαι | 「宙斯啊，還有諸位神明，願您們讓我這個孩子， |
| 477 | παῖδʼ ἐμὸν ὡς καὶ ἐγώ περ ἀριπρεπέα Τρώεσσιν, | 也能如我一般，成為特洛伊人中傑出出眾之人， |
| 478 | ὧδε βίην τʼ ἀγαθόν, καὶ Ἰλίου ἶφι ἀνάσσειν· | 同樣勇力過人，並以威力統治著伊利昂； |
| 479 | καί ποτέ τις εἴποι πατρός γʼ ὅδε πολλὸν ἀμείνων | 但願日後有人會說，這孩子遠比他的父親更為出色， |
| 480 | ἐκ πολέμου ἀνιόντα· φέροι δʼ ἔναρα βροτόεντα | 每當他自戰場凱旋歸來之時；願他能帶回浴血的戰利品， |
| 481 | κτείνας δήϊον ἄνδρα, χαρείη δὲ φρένα μήτηρ. | 殺死敵方的勇士，讓他的母親打從心底歡欣。」 |
| 482 | ὣς εἰπὼν ἀλόχοιο φίλης ἐν χερσὶν ἔθηκε | 他如此說完，便將自己的兒子， |
| 483 | παῖδʼ ἑόν· ἣ δʼ ἄρα μιν κηώδεϊ δέξατο κόλπῳ | 交回親愛妻子的懷中；她便將孩子擁入那芬芳的懷抱， |
| 484 | δακρυόεν γελάσασα· πόσις δʼ ἐλέησε νοήσας, | 含淚而笑；丈夫見狀，心生憐惜， |
| 485 | χειρί τέ μιν κατέρεξεν ἔπος τʼ ἔφατʼ ἔκ τʼ ὀνόμαζε· | 伸手輕撫著她，開口說道： |
| 486 | δαιμονίη μή μοί τι λίην ἀκαχίζεο θυμῷ· | 「我這奇怪的妻子啊，別在心中如此過度悲傷； |
| 487 | οὐ γάρ τίς μʼ ὑπὲρ αἶσαν ἀνὴρ Ἄϊδι προϊάψει· | 因沒有任何人，能違逆命數，將我送入黑帝斯的居所； |
| 488 | μοῖραν δʼ οὔ τινά φημι πεφυγμένον ἔμμεναι ἀνδρῶν, | 而命運，我斷言世間沒有任何凡人能夠逃脫， |
| 489 | οὐ κακὸν οὐδὲ μὲν ἐσθλόν, ἐπὴν τὰ πρῶτα γένηται. | 無論懦夫還是勇者，一旦命數降臨，皆是如此。 |
| 490 | ἀλλʼ εἰς οἶκον ἰοῦσα τὰ σʼ αὐτῆς ἔργα κόμιζε | 你且回家去，操持你自己的家務， |
| 491 | ἱστόν τʼ ἠλακάτην τε, καὶ ἀμφιπόλοισι κέλευε | 織布與紡紗，並指揮侍女們 |
| 492 | ἔργον ἐποίχεσθαι· πόλεμος δʼ ἄνδρεσσι μελήσει | 從事各項工作；至於戰事，自有男兒們操心， |
| 493 | πᾶσι, μάλιστα δʼ ἐμοί, τοὶ Ἰλίῳ ἐγγεγάασιν. | 尤其是我，那些生於伊利昂的男兒們。」 |
| 494 | ὣς ἄρα φωνήσας κόρυθʼ εἵλετο φαίδιμος Ἕκτωρ | 光輝的赫克托耳如此說完，便拾起那 |
| 495 | ἵππουριν· ἄλοχος δὲ φίλη οἶκον δὲ βεβήκει | 飾有馬鬃的頭盔；他親愛的妻子則轉身返家， |
| 496 | ἐντροπαλιζομένη, θαλερὸν κατὰ δάκρυ χέουσα. | 一步一回頭，大顆的淚珠不斷滑落。 |
| 497 | αἶψα δʼ ἔπειθʼ ἵκανε δόμους εὖ ναιετάοντας | 她隨即抵達了那安居樂業的宅邸， |
| 498 | Ἕκτορος ἀνδροφόνοιο, κιχήσατο δʼ ἔνδοθι πολλὰς | 那殺敵無數的赫克托耳的家；她在屋內遇見了眾多的 |
| 499 | ἀμφιπόλους, τῇσιν δὲ γόον πάσῃσιν ἐνῶρσεν. | 侍女，她的到來，讓所有侍女都哀嘆哭泣了起來。 |
| 500 | αἳ μὲν ἔτι ζωὸν γόον Ἕκτορα ᾧ ἐνὶ οἴκῳ· | 眾人便在他家中，為那仍活著的赫克托耳哀悼起來； |
| 501 | οὐ γάρ μιν ἔτʼ ἔφαντο ὑπότροπον ἐκ πολέμοιο | 因她們心想，他恐怕再也無法自戰場 |
| 502 | ἵξεσθαι προφυγόντα μένος καὶ χεῖρας Ἀχαιῶν. | 生還歸返，逃過亞該亞人的猛攻與雙手了。 |
| 503 | οὐδὲ Πάρις δήθυνεν ἐν ὑψηλοῖσι δόμοισιν, | 而帕里斯，也並未在那高聳的宅邸中久留， |
| 504 | ἀλλʼ ὅ γʼ, ἐπεὶ κατέδυ κλυτὰ τεύχεα ποικίλα χαλκῷ, | 他一披上那鑲嵌著精美青銅的名貴甲冑， |

| 509 | κυδιόων· ὑψοῦ δὲ κάρη ἔχει, ἀμφὶ δὲ χαῖται | 意氣風發；牠高昂著頭顱，鬃毛 |
| 510 | ὤμοις ἀΐσσονται· ὃ δʼ ἀγλαΐηφι πεποιθὼς | 隨風飄揚在肩頸之間；牠憑著自身的華美英姿， |
| 511 | ῥίμφά ἑ γοῦνα φέρει μετά τʼ ἤθεα καὶ νομὸν ἵππων· | 雙膝輕盈地馳騁，奔向那馬群慣常棲息的牧場； |

| 514 | καγχαλόων, ταχέες δὲ πόδες φέρον· αἶψα δʼ ἔπειτα | 意氣昂揚，那雙疾速的雙腳載著他向前；他隨即迅速 |
| 515 | Ἕκτορα δῖον ἔτετμεν ἀδελφεὸν εὖτʼ ἄρʼ ἔμελλε | 追上了他的兄長、神聖的赫克托耳，那時赫克托耳正要 |
| 516 | στρέψεσθʼ ἐκ χώρης ὅθι ᾗ ὀάριζε γυναικί. | 自方才與妻子話別之處轉身離去。 |
| 517 | τὸν πρότερος προσέειπεν Ἀλέξανδρος θεοειδής· | 神一般的亞歷山德羅斯率先開口對他道： |
| 518 | ἠθεῖʼ ἦ μάλα δή σε καὶ ἐσσύμενον κατερύκω | 「兄長啊，你都已心急如焚，我卻還耽擱了你這麼久， |

| 521 | δαιμόνιʼ οὐκ ἄν τίς τοι ἀνὴρ ὃς ἐναίσιμος εἴη | 「你這奇怪的傢伙，任何一位明理之人， |
| 522 | ἔργον ἀτιμήσειε μάχης, ἐπεὶ ἄλκιμός ἐσσι· | 都不會輕視你在戰場上的表現，因你確實驍勇； |

| 525 | πρὸς Τρώων, οἳ ἔχουσι πολὺν πόνον εἵνεκα σεῖο. | 種種羞辱，他們正是為了你，才承受著這無盡的苦戰。 |

| 528 | κρητῆρα στήσασθαι ἐλεύθερον ἐν μεγάροισιν | 逐出特洛伊之後，得以在殿堂中，為那天界永生的眾神， |
