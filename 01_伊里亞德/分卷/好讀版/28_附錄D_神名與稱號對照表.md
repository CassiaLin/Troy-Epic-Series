# 附錄D　神名與稱號對照表

本書的神名依希臘語境翻譯。原詩提到神祇時，常在名字前加上固定的稱號，有時也直接以稱號代替名字。下表列出本書出現的神祇，以及正文常見的稱號與別稱。各神的簡介另見附錄A。

原詩有時說明同一個人或物，在神與凡人口中有不同的叫法：除了上表的克珊托斯（斯卡曼德羅斯）與布里阿瑞俄斯（埃該翁），卷二特洛伊城前的土丘，凡人叫它巴提厄亞，眾神說那是彌里涅的墳墓；卷十四一種山中的鳥，神明叫牠「卡爾基斯」，凡人叫牠「庫敏迪斯」。

## D2　與拉丁語境稱呼對照

本書用希臘語境的神名。同一位神祇，在拉丁語境的《埃涅阿斯紀》裡另有稱呼，對照如下（只列本書出現的神祇）。

| 本書用名（希臘語境） | 《埃涅阿斯紀》用名（拉丁語境） |
|---|---|
| 宙斯 | 朱庇特 |
| 赫拉 | 朱諾 |
| 雅典娜 | 密涅瓦 |
| 波賽頓 | 涅普頓 |
| 赫耳墨斯 | 墨丘利 |
| 阿芙蘿黛蒂 | 維納斯 |
| 阿蒂蜜絲 | 黛安娜 |
| 勒托 | 拉托娜 |
| 阿瑞斯 | 瑪爾斯 |
| 赫淮斯托斯 | 沃爾坎 |
| 狄俄倪索斯 | 巴克斯 |
| 德墨忒爾 | 刻瑞斯 |
| 黑帝斯 | 普魯托 |
| 珀耳塞福涅 | 普洛塞庇娜 |
| 克洛諾斯 | 薩圖爾努斯 |

阿波羅、伊里斯、繆思女神、忒提斯、復仇女神等，在兩種語境中用同一個名字；阿波羅的別稱「福玻斯」、雅典娜的別稱「帕拉斯」，《埃涅阿斯紀》也同樣使用。
