## 附錄參考書

本叢書另收塞繆爾．巴特勒《奧德賽的女作者》（1897）全譯，作為《奧德賽》接受史的參考：
→ [90_奧德賽的女作者](../90_奧德賽的女作者/README.md)

巴特勒主張《奧德賽》出自西西里一位年輕女性之手。這是一部假說性的著作，現代荷馬研究並不接受它的結論；本叢書如實譯出，不加辯護或批駁。
