# 附錄D　神名與稱號對照表

本書的神名依希臘語境翻譯。原詩提到神祇時，常在名字前加上固定的稱號，有時也直接以稱號代替名字。下表列出本書出現的神祇，以及正文常見的稱號與別稱。各神的簡介另見附錄A。

## D1　神祇與稱號

| 阿芙蘿黛蒂 | 庫忒瑞亞；金色的；戴著美麗花冠的 | 愛與美的女神，宙斯的女兒；卷八歌者所唱的故事中，她是赫淮斯托斯的妻子（參見附錄C「8.266–366」） |
| 阿瑞斯 | 戰神；手持金韁的；屠戮凡人的 | 戰神；原詩常以「阿瑞斯的兵器」「阿瑞斯的戰具」泛指兵器 |

## D2　與拉丁語境稱呼對照

本書用希臘語境的神名。同一位神祇，在拉丁語境的《埃涅阿斯紀》裡另有稱呼，對照如下（只列本書出現的神祇）。

| 本書用名（希臘語境） | 《埃涅阿斯紀》用名（拉丁語境） |
|---|---|
| 宙斯 | 朱庇特 |
| 赫拉 | 朱諾 |
| 雅典娜 | 密涅瓦 |
| 波賽頓 | 涅普頓 |
| 赫耳墨斯 | 墨丘利 |
| 阿芙蘿黛蒂 | 維納斯 |
| 阿蒂蜜絲 | 黛安娜 |
| 勒托 | 拉托娜 |
| 阿瑞斯 | 瑪爾斯 |
| 赫淮斯托斯 | 沃爾坎 |
| 狄俄倪索斯 | 巴克斯 |
| 德墨忒爾 | 刻瑞斯 |
| 黑帝斯 | 普魯托 |
| 珀耳塞福涅 | 普洛塞庇娜 |
| 克洛諾斯 | 薩圖爾努斯 |

阿波羅、繆思女神、復仇女神、忒提斯等，在兩種語境中用同一個名字；雅典娜的別稱「帕拉斯」，《埃涅阿斯紀》也同樣使用。
