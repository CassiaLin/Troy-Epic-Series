## 一、起點與意義

- 01–05 冊與 90 冊都從 **v2.0.0** 起算，表示全新譯本；v1.x 舊版已封存。
- 本叢書這次是重譯（不是修訂），依舊倉庫製作規範「正文大規模重譯 → v2.0、建立新識別碼」，另建新倉庫，舊倉庫改名封存、不覆蓋、不刪除。

## 二、三段版號的意義

| 段 | 何時使用 |
|---|---|
| 主版號 | 重譯、成書結構重大改變、授權改變 |
| 次版號 | 新增內容但不改變既有意思：新附錄、跨冊譯名統一、補註 |
| 修訂號 | 錯字、標點、連結、排版、EPUB 相容性修正 |

- 每冊各自計算版號。Markdown 與 EPUB 共用同一個版號，任一改變就升版；只動 EPUB 排版的算修訂號。

## 三、tag

- 單冊：`01-iliad-v2.0.0`、`02-posthomerica-v2.0.0`、`03-odyssey-v2.0.0`、`04-aeneid-v2.0.0`、`05-epic-cycle-v2.0.0`、`90-odyssey-authoress-v2.0.0`。英文代號沿用，不隨中文書名改。
- 全套快照：`series-v2.0.0`。

## 四、識別碼與紀錄

- v2.0.0 每冊產生新的 UUID；之後只有主版號改變才換 UUID。
- 每次升版都更新 `CHANGELOG.md`、`VERSION_STATUS.md`、`SHA256SUMS.txt` 與書內〈版本資訊〉頁。

## 五、候選版與正式版

- 內容輪完成後是 **v2.0.0 候選版**（rc）；EPUB 經 EPUBCheck（fatal、error、warning 皆 0）並由使用者實機測試通過後，才打正式 tag。

## 六、新舊並存

- 舊倉庫（`Troy-Epic-Series-v1-archive`）設為 Archived、維持私人，**永遠不能改成公開**（其 Release 含現代版權資料）。
- 新倉庫 README 或 CHANGELOG 寫明「v1.x 封存於舊倉庫」。書內〈版本資訊〉說明這是全新譯本，以及與 v1.x 舊版的關係。
