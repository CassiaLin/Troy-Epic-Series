# 附錄B　同名消歧義

古代史詩裡，同一個名字常常屬於好幾個不同的人：戰場上一閃而過的陣亡者，可能與一位國王、一位將領或古代傳說中的人物同名。下面每個名字一節，先列本書中名叫這個名字的各位，以卷次與身分區分；再列本套書其他史詩（《伊里亞德》《奧德賽》《埃涅阿斯紀》《史詩殘篇集》）中的同名者。正文中第二位同名者出現時，已用註腳提醒；註腳寫「完整對照見附錄B」的名字，都在第一部分。「只以父名出現」表示這個人只在「某某之子」「某某的女兒」之類的稱呼裡提到；「是否同一人未定」表示原詩沒有交代清楚，本書不作判斷。

## 一、同名者眾多的名字

### 歐厄諾爾
1. 本書卷一：從杜利基昂島來的戰士，帕里斯射向斯忒涅羅斯的箭偏了方向，誤中他而死。
2. 本書卷四：替阿卡瑪斯纏手的阿革拉俄斯的父親，只以父名出現。
3. 本書卷十一：被涅俄普托勒摩斯所殺的戰士。
4. 《奧德賽》卷二、卷二十二：求婚者勒俄克里托斯的父親，只以父名出現。

### 阿革拉俄斯
1. 本書卷一：希帕索斯之子，從米利都來的戰士，被墨革斯所殺。
2. 本書卷三：邁昂之子，被大埃阿斯所殺。
3. 本書卷四：歐厄諾爾之子，在拳擊賽前替阿卡瑪斯纏手。
4. 《伊里亞德》卷八：弗拉德蒙之子，特洛伊人，轉車要逃時被狄俄墨得斯所殺。
5. 《伊里亞德》卷十一：被赫克托耳所殺的希臘人。
6. 《奧德賽》卷二十、卷二十二：達馬斯托爾之子，求婚者之一。

### 安菲馬科斯
1. 本書卷一：與納斯忒斯一同統率米利都一帶戰士的統帥。
2. 本書卷十二：藏身木馬的希臘勇士之一。
3. 《伊里亞德》卷二、卷十三：克特阿托斯之子，埃佩伊人的統帥之一，卷十三被赫克托耳所殺。
4. 《伊里亞德》卷二：諾米昂之子，與兄弟納斯忒斯統率卡里亞人；與本書第一位是否同一人未定。

### 厄提翁
1. 本書卷一、卷三、卷四、卷十三、卷十四：忒拜城的國王，安德洛瑪刻的父親，被阿基里斯所殺，只在往事與家世中提到；《伊里亞德》中安德洛瑪刻的父親也是這一位。
2. 本書卷六：被帕里斯一箭射穿下顎、身負重傷的戰士。
3. 《伊里亞德》卷十七：赫克托耳的好友波得斯的父親，只以父名出現；與安德洛瑪刻的父親是否同一人未定。
4. 《伊里亞德》卷二十一：伊姆布羅斯人，花重金把被賣作奴隸的呂卡昂贖了出來。

### 墨諾提俄斯
1. 本書卷一：帕特羅克洛斯的父親，只以父名出現；《伊里亞德》《奧德賽》中帕特羅克洛斯的父親也是這一位。
2. 本書卷八：埃勒菲諾爾的戰友，被歐律皮羅斯所殺。

### 安提馬科斯
1. 本書卷一：提西福涅的父親，只透過女兒的身分提到。
2. 本書卷六：跟隨伊多梅紐斯從克里特來的希臘人，被埃涅阿斯所殺。
3. 本書卷十二：藏身木馬的希臘勇士之一。
4. 《伊里亞德》卷十一、卷十二：特洛伊人，曾收受帕里斯的賄賂、反對歸還海倫，兒子佩桑德羅斯與希波羅科斯被阿伽門農所殺。

本書卷十三另提到特洛伊城中「安提馬科斯的宅邸」在大火中焚毀，原詩沒有交代這位安提馬科斯是誰。

### 阿卡瑪斯
1. 本書卷四、卷十二、卷十三：雅典英雄忒修斯之子，卷四在拳擊賽中與埃佩伊俄斯打成平手，卷十二藏身木馬，卷十三與兄弟得摩豐在城中遇見祖母埃特拉；《史詩殘篇集》中與得摩豐一同找到埃特拉的阿卡瑪斯也是這一位。
2. 本書卷六：特洛伊一方的戰士，被特拉緒墨得斯刺中膝蓋上方，負傷退出戰場。
3. 本書卷十：安忒諾爾之子，被菲羅克忒忒斯所殺；與上一位是否同一人，原詩沒有明說，未定。
4. 《伊里亞德》卷二、卷十一、卷十二、卷十四、卷十六：安忒諾爾之子，特洛伊將領，卷十六被墨里奧涅斯所殺；與本書第三位是否同一人未定。
5. 《伊里亞德》卷二、卷五、卷六：歐宋羅斯之子，色雷斯人的統帥，卷六被大埃阿斯所殺。
6. 《埃涅阿斯紀》卷二：藏在木馬中、在城破之夜現身的希臘勇士之一。

### 歐律皮羅斯
1. 本書卷四、卷十一、卷十二：希臘一方的統帥，卷四參加賽車時從車上摔下受傷，卷十一與奧德修斯一同攻打城門，卷十二藏身木馬；《伊里亞德》中的歐埃蒙之子、俄爾墨尼翁一帶的統帥也是這一位。
2. 本書卷六至卷九、卷十四：忒勒福斯之子，赫拉克勒斯之孫，率部眾援助特洛伊，卷八被涅俄普托勒摩斯所殺；《奧德賽》《史詩殘篇集》中的忒勒福斯之子也是這一位。
3. 《伊里亞德》：古時科斯島的國王，只在原詩卷二「歐律皮羅斯的城邦科斯」一句中提到。
4. 《埃涅阿斯紀》卷二：奉命去求神諭的希臘使者。

### 安提福斯
1. 本書卷六：來自邁錫尼、拉刻代蒙一帶的希臘戰士，被歐律皮羅斯所殺。
2. 本書卷八：奧德修斯的戰友，向歐律皮羅斯擲槍未中，憑著快腿逃過一死；原詩說他日後要死在吃人的庫克羅普斯手下（這個結局見《奧德賽》卷九），與《奧德賽》卷二那一位是否同一人未定。
3. 《伊里亞德》卷二：忒薩羅斯之子，與兄弟斐狄波斯統率科斯一帶的希臘人。
4. 《伊里亞德》卷二：塔萊墨涅斯之子，與墨斯特勒斯統率邁奧尼亞人。
5. 《伊里亞德》卷四、卷十一：普里阿摩斯之子，卷十一被阿伽門農所殺。
6. 《奧德賽》卷二：伊薩卡老人埃古普提俄斯之子，隨奧德修斯出征，在歸途中被庫克羅普斯吃掉。
7. 《奧德賽》卷十七：伊薩卡的長者，奧德修斯家的老朋友。

### 狄馬斯
1. 本書卷七：站在特洛伊一方的墨革斯的父親，只以父名出現；與《伊里亞德》中赫卡柏的父親是否同一人未定。
2. 本書卷八：住在奧利斯、隨阿爾克西拉俄斯來到特洛伊的希臘人，被埃涅阿斯所殺。
3. 《伊里亞德》卷十六：赫卡柏與阿西俄斯的父親，只在家世中提到。
4. 《奧德賽》卷六：以航海聞名的費埃克斯人，雅典娜化作他女兒的模樣去見瑙西卡。
5. 《埃涅阿斯紀》卷二：城破之夜追隨埃涅阿斯作戰的特洛伊勇士。

### 墨東
1. 本書卷八：精通木工的匠人，與伊菲阿娜莎生下墨納爾克斯，只在兒子的家世中提到。
2. 本書卷十：澤基斯的父親，只以父名出現。
3. 本書卷十一：被菲羅克忒忒斯射向埃涅阿斯的箭射中，從城樓上墜落而死。
4. 《伊里亞德》卷二、卷十三、卷十五：俄伊琉斯的私生子，小埃阿斯的異母兄弟，代替菲羅克忒忒斯統率他的部隊，卷十五被埃涅阿斯所殺。
5. 《伊里亞德》卷十七：特洛伊一方的盟軍將領。
6. 《奧德賽》：伊薩卡的傳令官，侍候求婚者，卻忠於奧德修斯一家。

### 希波墨東
1. 本書卷八：被涅俄普托勒摩斯所殺的戰士。
2. 本書卷十一：邁納洛斯之子，仙女俄庫洛厄在桑加里俄斯河邊所生，也被涅俄普托勒摩斯所殺。
3. 本書卷十一：墨諾提斯的父親，只以父名出現；與上兩位是否同一人，原詩沒有明說，未定。

### 墨蘭提俄斯
1. 本書卷九：希臘戰士，涅斯托爾的御者被殺後，他跳上那輛戰車接過韁繩。
2. 《伊里亞德》卷六：被歐律皮羅斯所殺的特洛伊人。
3. 《奧德賽》卷十七起：多利俄斯之子，替求婚者效力的牧羊人，卷二十二受刑而死。

### 阿斯卡尼俄斯
1. 本書卷九：被涅俄普托勒摩斯所殺的戰士。
2. 《伊里亞德》卷二：與福爾庫斯統率弗里吉亞人；與本書這一位是否同一人未定。
3. 《伊里亞德》卷十三：從阿斯卡尼亞趕來的援軍之一；與卷二那位、與本書這一位是否同一人都未定。
4. 《埃涅阿斯紀》：埃涅阿斯之子，又名尤路斯。

### 歐律馬科斯
1. 本書卷十一：跟隨尼柔斯從敘墨島來的戰士，被普魯達馬斯所殺。
2. 本書卷十一、卷十四：安忒諾爾之子，卷十一與埃涅阿斯並肩作戰，卷十四提到波呂克塞娜原本要許配給他。
3. 本書卷十二：藏身木馬的希臘勇士之一。
4. 《奧德賽》卷一起：波呂波斯之子，伊薩卡人，求婚者的兩位首領之一，卷二十二被奧德修斯所殺。

### 阿巴斯
1. 本書卷十一：被斯忒涅羅斯所殺的戰士。
2. 本書卷十三：城破之夜被狄俄墨得斯所殺的特洛伊人。
3. 《伊里亞德》卷五：解夢者歐律達馬斯之子，與兄弟波呂伊多斯一同被狄俄墨得斯所殺。
4. 《埃涅阿斯紀》卷一：埃涅阿斯船隊中的一員，船在風暴中受損。
5. 《埃涅阿斯紀》卷三：一面盾牌的原主，埃涅阿斯把這面盾牌掛在神殿門上。
6. 《埃涅阿斯紀》卷十：伊特魯里亞船隊的統帥，率兵援助埃涅阿斯。
7. 《埃涅阿斯紀》卷十：被勞蘇斯所殺的戰士。

### 伊利俄紐斯
1. 本書卷十三：特洛伊城中的老年長老，向狄俄墨得斯哀求饒命，仍被殺死。
2. 《伊里亞德》卷十四：福爾巴斯之子，被佩涅琉斯所殺。
3. 《埃涅阿斯紀》卷一、卷七、卷九：埃涅阿斯部眾中的年長者，卷一向蒂朵陳情，卷七出使拉丁努斯。

## 二、其他同名者

### 埃阿斯
1. 本書卷一起：忒拉蒙之子，薩拉米斯人，人稱大埃阿斯，卷五因阿基里斯的鎧甲判給奧德修斯而自盡。
2. 本書卷一起：俄伊琉斯之子，洛克里斯人的統帥，人稱小埃阿斯；卷六伏下他死在歸途的結局，卷十三他在雅典娜神廟對卡珊德拉施暴，卷十四在海上受懲而死。

其他幾部史詩中的大小埃阿斯，也都是這兩位。

### 拉俄墨東
1. 本書卷一起：特洛伊的舊王，普里阿摩斯的父親，多以父名與往事出現；《伊里亞德》《埃涅阿斯紀》《史詩殘篇集》中的拉俄墨東王也是這一位。
2. 本書卷二：被特拉緒墨得斯所殺的戰士。

### 希波呂忒
1. 本書卷一：彭忒西勒亞的姊妹，被彭忒西勒亞誤殺。
2. 本書卷六：亞馬遜女王，刻在歐律皮羅斯的盾牌上，赫拉克勒斯要奪她的腰帶；與上一位是否同一人，原詩沒有明說，未定。
3. 《埃涅阿斯紀》卷十一：傳說中的亞馬遜女王，詩中用來比擬卡米拉身邊的女戰士；與本書的兩位是否同一人未定。

### 於洛斯
1. 本書卷一：被大埃阿斯所殺的戰士。
2. 本書卷十：忒耳珊德羅斯與阿瑞圖薩之子，克里特人，被埃涅阿斯所殺，伊多梅紐斯為他哀傷。

### 墨革斯
1. 本書卷一、卷六、卷十、卷十二、卷十三：菲勒烏斯之子，希臘將領，卷十二藏身木馬；《伊里亞德》《史詩殘篇集》中的菲勒烏斯之子也是這一位。
2. 本書卷七：狄馬斯之子，站在特洛伊一方的富人，兩個兒子被涅俄普托勒摩斯所殺。

本書卷二另有「墨革斯之子波呂姆尼俄斯」被希臘人所殺；這位墨革斯是否就是第二位，原詩沒有明說，未定。

### 希帕索斯之子
1. 本書卷六：帕蒙的御者，被投石擊中，摔下戰車而死。
2. 本書卷九：涅斯托爾的御者，被得伊福玻斯所殺。

本書卷一的阿革拉俄斯、卷十的得摩勒昂也都是「希帕索斯之子」；卷十一另有一位希帕索斯本人，被阿革諾爾所殺。《伊里亞德》中的希帕索斯是卡羅普斯與索科斯、許普塞諾爾、阿皮薩昂的父親，只以父名出現。

### 阿爾卡托俄斯
1. 本書卷三：被阿基里斯一槍刺穿下顎而死的戰士。
2. 本書卷十：守護雅典娜神像的特洛伊守衛，命運女神預定他日後死在潛入城中奪取神像的狄俄墨得斯手下。
3. 《伊里亞德》卷十二、卷十三：埃緒厄忒斯之子，安基塞斯的女婿，卷十三被伊多梅紐斯所殺。

### 忒斯托爾
1. 本書卷三：被大埃阿斯所殺的戰士。
2. 本書卷六：先知卡爾卡斯的父親，只以父名出現；《伊里亞德》卷一中卡爾卡斯的父親也是這一位。
3. 《伊里亞德》卷十二：阿爾克馬翁的父親，只以父名出現。
4. 《伊里亞德》卷十六：厄諾普斯之子，被帕特羅克洛斯所殺。

### 邁納洛斯
1. 本書卷三：佩桑德羅斯之子，原住阿彼多斯，被奧德修斯所殺。
2. 本書卷十一：希波墨東的父親，只在介紹兒子的家世時提到，原詩說他再也盼不到兒子回家。

### 托阿斯
1. 本書卷四：狄俄倪索斯之子，利姆諾斯的古王，許普西碧勒的父親，只在獎品的來歷中提到；《伊里亞德》《奧德賽》中利姆諾斯的托阿斯王也是這一位。
2. 本書卷四、卷六、卷十一、卷十二：埃托利亞人的統帥，卷四參加賽車，卷十二藏身木馬；《伊里亞德》《奧德賽》中的安德賴蒙之子、《埃涅阿斯紀》卷二藏在木馬中的托阿斯、《史詩殘篇集》中打傷奧德修斯的托阿斯，也都歸為這一位。
3. 《伊里亞德》卷十六：被墨涅拉俄斯所殺的特洛伊人。
4. 《埃涅阿斯紀》卷十：被哈萊蘇斯所殺的戰士。

### 涅索斯
1. 本書卷五、卷六：半人馬，以奸計害死赫拉克勒斯，卷六刻在歐律皮羅斯的盾牌上。
2. 本書卷六：被歐律皮羅斯所殺的希臘戰士。

### 狄俄墨得斯
1. 本書卷一起：圖丟斯之子，希臘一方的勇將；其他幾部史詩中的圖丟斯之子也是這一位。
2. 本書卷六：色雷斯的國王，豢養吃人的馬，被赫拉克勒斯所殺，刻在歐律皮羅斯的盾牌上。

### 呂孔
1. 本書卷八：被得伊福玻斯所殺的戰士。
2. 本書卷十一：被墨里奧涅斯所殺的戰士。
3. 《伊里亞德》卷十六：被佩涅琉斯所殺的特洛伊人。

### 墨諾提斯
1. 本書卷九：普里阿摩斯派去見阿伽門農、請求雙方火化死者的使者。
2. 本書卷十一：希波墨東之子，被透克洛斯一箭射死。

### 安菲諾俄斯
1. 本書卷十：被涅俄普托勒摩斯所殺的戰士。
2. 本書卷十：被狄俄墨得斯所殺的戰士。

## 三、其他史詩中另有同名者的人物

- **提西福涅**：本書卷一，馴馬人安提馬科斯的女兒、墨涅普托勒摩斯的妻子，激勵特洛伊婦女出戰的凡人女子；《埃涅阿斯紀》卷六、卷十，復仇女神之一。
- **摩利昂**：本書卷一，被彭忒西勒亞所殺的戰士；《伊里亞德》卷十一，廷布萊俄斯的隨從，被奧德修斯所殺。
- **海蒙**：本書卷一，被彭忒西勒亞所殺的一位戰士的父親，只以「海蒙之子」的稱呼出現；《伊里亞德》卷四，涅斯托爾麾下的皮洛斯將領，同卷另有忒拜人邁昂的父親海蒙，卷十七另有拉厄爾刻斯的父親海蒙；《埃涅阿斯紀》卷九，率眾殺入特洛伊營寨的敵將。
- **拉俄戈諾斯**：本書卷一，被亞馬遜女戰士德里諾厄所殺的戰士；《伊里亞德》卷十六，俄涅托爾之子，被墨里奧涅斯所殺；《伊里亞德》卷二十，比阿斯之子，被阿基里斯所殺。
- **伊圖摩紐斯**：本書卷一，從米利都來的戰士，被墨革斯所殺；《伊里亞德》卷十一，埃利斯人，涅斯托爾年輕時所殺。
- **涅埃拉**：本書卷一，德瑞塞俄斯的母親，只透過兒子的家世提到；《奧德賽》卷十二，太陽神赫利俄斯的妻子。
- **歐律諾摩斯**：本書卷一，被大埃阿斯所殺的戰士；《奧德賽》卷二、卷二十二，埃古普提俄斯之子，求婚者之一；《史詩殘篇集》，冥府中的一位神靈。
- **埃紐斯**：本書卷一，被大埃阿斯所殺的戰士；《伊里亞德》卷九，統治斯庫羅斯的人，阿基里斯攻下他的城。
- **得伊俄科斯**：本書卷一，被大埃阿斯所殺的戰士；《伊里亞德》卷十五，轉身逃跑時被帕里斯射殺的希臘人。
- **伊洛斯**：本書卷一、卷二，特洛伊的先祖，特羅斯之子，伊利昂因他得名（《伊里亞德》《埃涅阿斯紀》中的先祖伊洛斯也是這一位）；《奧德賽》卷一，厄費瑞人墨爾墨羅斯之子；《埃涅阿斯紀》卷一，阿斯卡尼俄斯在特洛伊時的舊名。
- **達爾達諾斯**：本書卷一起，宙斯之子，特洛伊王族的始祖，多以「達爾達諾斯的血脈」之類的稱呼出現（《伊里亞德》《埃涅阿斯紀》《史詩殘篇集》中的始祖也是這一位）；《伊里亞德》卷二十，比阿斯之子，被阿基里斯所殺。
- **特羅斯**：本書卷二，埃里克托尼俄斯之子，伊洛斯的父親，只在家世中提到（《伊里亞德》中的始祖特羅斯也是這一位）；《伊里亞德》卷二十，阿拉斯托爾之子，向阿基里斯求饒，仍被殺。
- **忒摩忒斯**：本書卷二，特洛伊的長老；《伊里亞德》卷三，與普里阿摩斯同坐城樓的特洛伊長老；《埃涅阿斯紀》卷十，希刻塔翁之子，卷十二另有一位落馬死於圖爾努斯之手。與本書這一位是否同一人都未定。
- **門特斯**：本書卷二，被阿基里斯所殺的戰士；《伊里亞德》卷十七，基科涅斯人的統帥，阿波羅化作他的模樣；《奧德賽》卷一，塔福斯人的首領，雅典娜化作他的模樣。
- **皮拉索斯**：本書卷二，被安提洛科斯誤殺的門農同伴的父親，只以「皮拉索斯之子」的稱呼出現；《伊里亞德》卷十一，被大埃阿斯刺傷的特洛伊人。
- **呂庫爾戈斯**：本書卷二，逼得狄俄倪索斯逃亡的暴君；《伊里亞德》卷六，德律阿斯之子，色雷斯的國王，曾迫害狄俄倪索斯；《伊里亞德》卷七，阿爾卡狄亞人；《埃涅阿斯紀》卷三，色雷斯古時的國王。本書這一位與《伊里亞德》卷六、《埃涅阿斯紀》卷三那兩位是否同一人未定。
- **希波諾俄斯**：本書卷三，被阿基里斯所殺的戰士；《伊里亞德》卷十一，被赫克托耳所殺的希臘將領。
- **尼索斯**：本書卷三，被大埃阿斯所殺的戰士；《奧德賽》卷十六、卷十八，杜利基昂島人，求婚者安菲諾摩斯的父親。
- **邁昂**：本書卷三，阿革拉俄斯的父親，只以父名出現；《伊里亞德》卷四，海蒙之子，忒拜伏兵的首領之一，被圖丟斯放回。
- **埃律馬斯**：本書卷三，呂基亞人，格勞科斯的戰友，被大埃阿斯所殺；《伊里亞德》卷十六，被伊多梅紐斯所殺的特洛伊人；《伊里亞德》卷十六另有一位，被帕特羅克洛斯所殺的特洛伊人。
- **阿提姆尼俄斯**：本書卷三，仙女珀伽西斯與埃瑪提翁之子，被奧德修斯所殺；《伊里亞德》卷十六，阿米索達羅斯之子，薩爾佩東的夥伴，被安提洛科斯所殺；《伊里亞德》卷五另有米冬的父親阿提姆尼俄斯，只以父名出現，與卷十六那一位是否同一人未定。
- **埃瑪提翁**：本書卷三，阿提姆尼俄斯的父親，只以父名出現；《埃涅阿斯紀》卷九，在攻城戰中被利格爾所殺的戰士。
- **普洛透斯**：本書卷三，俄瑞斯比俄斯的父親，只以父名出現；《奧德賽》卷四、《埃涅阿斯紀》卷十一，海中老人。
- **佩桑德羅斯**：本書卷三，邁納洛斯的父親，只以父名出現；《伊里亞德》卷十一，安提馬科斯之子；《伊里亞德》卷十三，被墨涅拉俄斯所殺的特洛伊人；《伊里亞德》卷十六，阿基里斯麾下第三隊的統帥；《奧德賽》卷十八、卷二十二，波呂克托爾之子，求婚者之一。
- **格勞科斯**：本書卷三起，希波羅科斯之子，呂基亞人的君王，卷三被大埃阿斯所殺（《伊里亞德》中的也是這一位）；《伊里亞德》卷六，西西弗斯之子，柏勒洛豐的父親；《埃涅阿斯紀》，化身海神的漁夫、安忒諾爾之子、伊姆布拉索斯之子三位；《史詩殘篇集》，一位被引用的古代學者。
- **福伊尼克斯**：本書卷三、卷四、卷七、卷九，阿基里斯的老師（《伊里亞德》《埃涅阿斯紀》《史詩殘篇集》中的也是這一位）；《伊里亞德》卷十四，古時的國王，只在宙斯的話中提到。本書卷八另有呂基亞的地名福伊尼克斯。
- **埃俄羅斯**：本書卷三、卷十四，掌管眾風的神（《奧德賽》《埃涅阿斯紀》中的風神也是這一位）；《奧德賽》卷十一，克瑞透斯的父親；《埃涅阿斯紀》卷六，號手米塞努斯的父親，卷十二另有來自呂爾涅索斯的特洛伊戰士。
- **安凱俄斯**：本書卷四，涅斯托爾年輕時在阿馬呂格科斯墳旁摔倒的強者；《伊里亞德》卷二十三的安凱俄斯，普琉戎人，涅斯托爾摔跤打敗的對手，與本書所說是同一件往事；《伊里亞德》卷二另有阿伽佩諾爾的父親安凱俄斯，只以父名出現，與上述這一位是否同一人未定。
- **阿卡斯托斯**：本書卷四，佩利阿斯之子，涅斯托爾的堂兄弟；《奧德賽》卷十四，杜利基昂的國王，出現在奧德修斯編造的經歷中。
- **波呂多羅斯**：本書卷四，普里阿摩斯之子，被阿基里斯所殺，只在往事與獎品的來歷中提到（《伊里亞德》中普里阿摩斯的幼子、《埃涅阿斯紀》卷三的普里阿摩斯幼子也是這一位）；《伊里亞德》卷二十三，涅斯托爾年輕時比賽擲槍的對手。
- **呂卡昂**：本書卷四，普里阿摩斯之子，只在阿基里斯的往事與獎品的來歷中提到（《伊里亞德》中的普里阿摩斯之子也是這一位）；《伊里亞德》卷二、卷四、卷五，潘達羅斯的父親；《埃涅阿斯紀》依拉丁語境寫作「呂卡翁」，卷九是格諾索斯的鑄劍工匠，卷十是埃里凱特斯的父親。
- **俄伊諾馬俄斯**：本書卷四，古時精於駕車的國王，希波達彌亞的父親，不肯讓女兒出嫁；《伊里亞德》卷五，埃托利亞的槍手，被赫克托耳所殺；《伊里亞德》卷十二，阿西俄斯的同伴；《伊里亞德》卷十三，被伊多梅紐斯所殺的特洛伊人，與卷十二那一位是否同一人未定。
- **希波達彌亞**：本書卷四，俄伊諾馬俄斯之女，她的父親不肯讓她出嫁；《伊里亞德》卷二，佩里托俄斯之妻，波呂波忒斯的母親；《伊里亞德》卷十三，安基塞斯的長女；《奧德賽》卷十八，潘妮洛碧的侍女。
- **阿德拉斯托斯**：本書卷四，古時從神明那裡得到神馬的人（《伊里亞德》中最早在西庫昂稱王的古王、《埃涅阿斯紀》卷六的阿德拉斯托斯，都歸為這一位）；《伊里亞德》卷二，墨羅普斯之子；《伊里亞德》卷六，向墨涅拉俄斯求饒的特洛伊人；《伊里亞德》卷十六，被帕特羅克洛斯所殺的特洛伊人。
- **斯忒涅羅斯**：本書卷一起，卡帕紐斯之子，狄俄墨得斯的戰友（《伊里亞德》中的、《埃涅阿斯紀》卷二藏身木馬的斯忒涅羅斯也是這一位）；《伊里亞德》卷十九，珀爾修斯之子，歐律斯透斯的父親；《埃涅阿斯紀》卷十二，死在圖爾努斯手下的戰士。
- **歐律阿羅斯**：本書卷四、卷八、卷十一、卷十二，狄俄墨得斯的部將，卷四標槍得勝（《伊里亞德》中的墨基斯透斯之子也是這一位）；《奧德賽》卷八，費埃克斯青年；《史詩殘篇集》，奧德修斯之子。
- **波達勒里俄斯**：本書卷四起，希臘聯軍的醫者（《伊里亞德》《史詩殘篇集》中的也是這一位）；《埃涅阿斯紀》卷十二，被阿爾蘇斯所殺的戰士。
- **布科利翁**：本書卷六，被歐律皮羅斯所殺的希臘戰士；《伊里亞德》卷六，拉俄墨東私下所生的長子。
- **克羅米俄斯**：本書卷六，被歐律皮羅斯所殺的希臘戰士；《伊里亞德》中另有五位（皮洛斯將領、普里阿摩斯之子、呂基亞人、卷八被透克洛斯射殺的特洛伊人、卷十七的盟軍將領），卷二另有密西亞統帥克羅米斯；《埃涅阿斯紀》卷十一，克羅米斯，被卡米拉所殺。
- **費瑞斯**：本書卷六，跟隨伊多梅紐斯從克里特來的戰士，被埃涅阿斯所殺；《伊里亞德》卷二、卷二十三，歐邁羅斯的祖父，只以「費瑞斯之孫」的稱呼出現；《奧德賽》卷十一，堤羅與克瑞透斯所生的兒子。
- **福爾庫斯**：本書卷六，搭大埃阿斯的船從薩拉米斯島來的戰士，被帕里斯射殺；《伊里亞德》卷二、卷十七，法伊諾普斯之子，弗里吉亞人的統帥。
- **厄刻蒙**：本書卷六，托阿斯的戰友，被歐律皮羅斯的隨從刺成重傷，再被歐律皮羅斯追上殺死；《伊里亞德》卷五另有一位厄刻蒙，普里阿摩斯之子，被狄俄墨得斯所殺。
- **歐律提翁**：本書卷六，革律翁的牧牛人，刻在歐律皮羅斯的盾牌上；《奧德賽》卷二十一，在佩里托俄斯家醉酒鬧事的半人馬；《埃涅阿斯紀》卷五，神射手潘達羅斯的兄弟。
- **佩里波亞**：本書卷七，站在特洛伊一方的墨革斯的妻子，只透過兒子的家世提到；《伊里亞德》卷二十一，阿克塞薩墨諾斯的長女，阿斯特羅派俄斯的祖母；《奧德賽》卷七，巨人王歐律墨東最小的女兒。
- **呂科墨得斯**：本書卷七，斯庫羅斯的老王，涅俄普托勒摩斯的外祖父（《史詩殘篇集》中德伊達彌亞的父親也是這一位）；《伊里亞德》卷九起，克瑞翁之子，希臘將領（《史詩殘篇集》中的克瑞翁之子也是這一位）。
- **墨拉紐斯**：本書卷八，阿勒克西諾摩斯之子，被涅俄普托勒摩斯所殺；《奧德賽》卷二十四，求婚者安菲墨東的父親，只以父名出現。
- **摩律斯**：本書卷八，從弗里吉亞來的槍手，被涅俄普托勒摩斯所殺；《伊里亞德》卷十三、卷十四，希波提昂之子，被墨里奧涅斯所殺。
- **波呂波斯**：本書卷八，被涅俄普托勒摩斯所殺的戰士；《伊里亞德》卷十一，安忒諾爾之子；《奧德賽》中另有四位（求婚者歐律馬科斯的父親、埃及忒拜的富人、費埃克斯的工匠、卷二十二被歐邁俄斯所殺的求婚者）。
- **克瑞烏薩**：本書卷八，墨涅斯的母親，在林多斯河口生下他，只透過兒子的家世提到；《埃涅阿斯紀》卷二、卷九，埃涅阿斯的妻子，《史詩殘篇集》也提到她。
- **歐邁俄斯**：本書卷八，住在達爾達諾斯城的戰士，被狄俄墨得斯所殺；《奧德賽》，奧德修斯忠心的牧豬人。
- **佩塞諾爾**：本書卷八，格勞科斯的戰友克勒摩斯的父親，只以父名出現；《伊里亞德》卷十五，克萊托斯的父親；《奧德賽》卷一、卷二、卷二十，女管家歐律克蕾亞的祖父；《奧德賽》卷二，伊薩卡的傳令官。
- **歐律托斯**：本書卷八，埃勒菲諾爾的戰友，被歐律皮羅斯所殺；《伊里亞德》卷二，俄卡利亞人，與阿波羅比箭的神射手（《奧德賽》卷八、卷二十一中的也是這一位），同卷另有埃佩伊統帥塔爾皮俄斯的父親歐律托斯；《埃涅阿斯紀》卷十，工匠克洛努斯的父親。
- **埃律拉俄斯**：本書卷八，墨拉尼翁的父親，只透過兒子的家世提到；《伊里亞德》卷十六，被帕特羅克洛斯用石塊砸死的特洛伊人。
- **埃同**：本書卷八，戰神阿瑞斯的四匹神馬之一；《伊里亞德》卷八，赫克托耳的戰馬之一；《奧德賽》卷十九，奧德修斯對潘妮洛碧謊稱的名字；《埃涅阿斯紀》卷十一，帕拉斯的戰馬。
- **佩里墨得斯**：本書卷八，住在斯明特翁神廟附近的戰士，被涅俄普托勒摩斯所殺；《伊里亞德》卷十五，斯刻狄俄斯的父親，只以父名出現；《奧德賽》卷十一、卷十二，奧德修斯的同伴。
- **伊菲阿娜莎**：本書卷八，墨納爾克斯的母親，木匠墨東的妻子；《伊里亞德》卷九，阿伽門農的女兒之一（《史詩殘篇集》中的也是這一位）。
- **赫勒諾斯**：本書卷八起，普里阿摩斯之子，善於察知徵兆（《伊里亞德》中的普里阿摩斯之子也是這一位）；《伊里亞德》卷五，俄諾普斯之子，被赫克托耳所殺的希臘人。
- **波利特斯**：本書卷八、卷十一、卷十三，普里阿摩斯之子，卷十三被涅俄普托勒摩斯的槍擊中（《伊里亞德》《埃涅阿斯紀》中的也是這一位）；《奧德賽》卷十，奧德修斯的同伴。
- **俄伊諾普斯**：本書卷九，被涅俄普托勒摩斯所殺的戰士；《奧德賽》卷二十一，求婚者雷俄得斯的父親，只以父名出現。
- **哈爾帕利翁**：本書卷十，阿里澤羅斯之子，隨普洛托厄諾爾來的皮奧提亞人，被埃涅阿斯所殺；《伊里亞德》卷十三，帕夫拉戈尼亞王皮萊墨涅斯之子，被墨里奧涅斯射殺。
- **忒耳珊德羅斯**：本書卷十，克里特人於洛斯的父親，只以父名出現；《史詩殘篇集》，波呂尼刻斯之子，被忒勒福斯所殺，另有西西弗斯之子忒耳珊德羅斯。
- **阿瑞圖薩**：本書卷十，於洛斯的母親，在克里特的勒泰俄斯河畔生下他；《埃涅阿斯紀》卷三，西西里敘拉古一帶的泉水仙女。
- **斯刻狄俄斯**：本書卷十，被涅俄普托勒摩斯所殺的戰士；《伊里亞德》卷二、卷十七，伊菲托斯之子，福基斯人的統帥；《伊里亞德》卷十五，佩里墨得斯之子；兩位都被赫克托耳所殺。
- **恩諾摩斯**：本書卷十，被涅俄普托勒摩斯所殺的戰士；《伊里亞德》卷二，密西亞人的鳥卜師；《伊里亞德》卷十一，被奧德修斯所殺的特洛伊人；《伊里亞德》卷十七另有一位觀鳥占卜的盟軍將領。
- **安菲翁**：本書卷十，埃佩伊俄斯的隨從，被埃涅阿斯所殺；《伊里亞德》卷十三，埃佩伊人的將領之一；《奧德賽》卷十一，宙斯與安提娥珮之子，修築忒拜城牆的人；《奧德賽》卷十一，伊阿索斯之子，俄爾科墨諾斯的國王。
- **梅農**：本書卷十，被狄俄墨得斯所殺的戰士；《伊里亞德》卷十二，被勒翁透斯所殺的特洛伊人。
- **得摩勒昂**：本書卷十，希帕索斯之子，原住拉科尼亞，隨墨涅拉俄斯出征，被帕里斯射殺；《伊里亞德》卷二十，安忒諾爾之子，被阿基里斯所殺。
- **拉俄達馬斯**：本書卷十一，在呂基亞克珊托斯河畔長大的戰士，被涅俄普托勒摩斯所殺；《伊里亞德》卷十五，安忒諾爾之子，被大埃阿斯所殺；《奧德賽》卷七、卷八，費埃克斯王阿爾基諾俄斯最疼愛的兒子。
- **伊菲提昂**：本書卷十一，被涅俄普托勒摩斯所殺的戰士；《伊里亞德》卷二十，俄特隆透斯之子，第一個被阿基里斯所殺的特洛伊人。
- **波呂伊多斯**：本書卷十一，基特伊亞人，被奧德修斯所殺；《伊里亞德》卷五，解夢者歐律達馬斯之子；《伊里亞德》卷十三，科林斯的占卜師。
- **拉俄多科斯**：本書卷十一，被狄俄墨得斯所殺的戰士；《伊里亞德》卷四，安忒諾爾之子，雅典娜化作他的模樣；《伊里亞德》卷十七，安提洛科斯的同伴。
- **德律阿斯**：本書卷十一，被得伊福玻斯所殺的戰士；《伊里亞德》卷一，拉皮斯族英雄；《伊里亞德》卷六，色雷斯王呂庫爾戈斯的父親，只以父名出現。
- **阿爾基摩斯**：本書卷十一，被得伊福玻斯所殺的戰士；《伊里亞德》卷十九、卷二十四，阿基里斯的同伴；《奧德賽》卷二十二，門托爾的父親，只以父名出現。
- **阿爾基墨東**：本書卷十一，小埃阿斯麾下最出色的洛克里斯人，攀上雲梯時被埃涅阿斯用石頭砸落；《伊里亞德》卷十六、卷十七，拉厄爾刻斯之子，阿基里斯麾下第五隊的統帥。
- **歐律達馬斯**：本書卷十三，安忒諾爾的女婿，被狄俄墨得斯所殺；《伊里亞德》卷五，解夢的老人；《奧德賽》卷十八、卷二十二，求婚者之一。
- **密格東**：本書卷十三，科洛柏斯的父親，只以父名出現；《伊里亞德》卷三，弗里吉亞人的首領；與本書這一位是否同一人未定。
- **安菲墨東**：本書卷十三，被小埃阿斯所殺的戰士；《奧德賽》卷二十二、卷二十四，墨拉紐斯之子，求婚者之一。
- **德伊俄皮特斯**：本書卷十三，城破之夜被墨革斯所殺的特洛伊人；《伊里亞德》卷十一，被奧德修斯刺中肩膀的特洛伊人，與本書這一位是否同一人未定。
- **拉俄狄刻**：本書卷十三，普里阿摩斯的女兒，祈求大地把她吞下，免得淪為奴隸（《伊里亞德》《史詩殘篇集》中普里阿摩斯的女兒也是這一位）；《伊里亞德》卷九，阿伽門農的女兒之一。
- **丟卡利翁**：本書卷十四，上古大洪水時代的丟卡利翁，只在提到那場洪水時出現；《伊里亞德》卷十二、卷十三、卷十七，米諾斯之子，伊多梅紐斯的父親（《奧德賽》卷十九中的也是這一位）；《伊里亞德》卷二十，被阿基里斯所殺的特洛伊人。
- **普里阿摩斯**：本書，特洛伊的老國王（其他幾部史詩中的也是這一位）；《埃涅阿斯紀》卷五，波利特斯之子，承襲祖父名字的少年。
- **阿革諾爾**：本書，安忒諾爾之子，特洛伊將領（《伊里亞德》中的也是這一位）；《埃涅阿斯紀》卷一，腓尼基的古王。
- **帕拉斯**：本書中是雅典娜的別稱；《埃涅阿斯紀》卷八起，埃萬德爾之子帕拉斯；《史詩殘篇集》，克律塞的父親帕拉斯。
