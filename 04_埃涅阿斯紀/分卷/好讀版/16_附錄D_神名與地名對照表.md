# 附錄D　神名與地名對照表

《埃涅阿斯紀》是羅馬詩人維吉爾的拉丁文作品，本書的神名與部分人名、地名依拉丁語境翻譯；同一位神祇或同一個地方，在《伊里亞德》《奧德賽》《荷馬續篇》《史詩殘篇集》等希臘史詩中另有希臘語境的稱呼。下表列出本書出現、而在希臘語境中另有名稱者。各名在本書首次出現時，正文註腳已作說明。

## D1　神祇

| 本書用名 | 希臘語境稱呼 | 說明 |
|---|---|---|
| 朱庇特 | 宙斯 | 眾神與人類之王 |
| 朱諾 | 赫拉 | 天后，朱庇特的姊妹與妻子；本書中一再阻撓埃涅阿斯 |
| 維納斯 | 阿芙蘿黛蒂 | 愛與美的女神，埃涅阿斯的母親；又稱「庫特瑞亞」「阿基達莉亞」 |
| 密涅瓦 | 雅典娜 | 智慧與戰爭女神；本書也稱她「帕拉斯」「特里托妮亞」 |
| 涅普頓 | 波賽頓 | 海神 |
| 墨丘利 | 赫耳墨斯 | 眾神的使者；本書也稱「邁亞的兒子」「居勒涅之神」 |
| 黛安娜 | 阿蒂蜜絲 | 狩獵女神，阿波羅的孿生姊妹；本書也稱「拉托娜之女」 |
| 拉托娜 | 勒托 | 黛安娜與阿波羅的母親 |
| 沃爾坎 | 赫淮斯托斯 | 火神與工匠之神；本書有時以他的名字代指火焰 |
| 瑪爾斯 | 阿瑞斯 | 戰神 |
| 巴克斯 | 狄俄倪索斯 | 酒神；本書有時以他的名字代指酒，也稱「呂埃烏斯」 |
| 刻瑞斯 | 德墨忒爾 | 穀物女神；本書有時以她的名字代指穀物 |
| 普魯托 | 黑帝斯 | 冥界之王；本書也稱他「冥界的朱庇特」 |
| 普洛塞庇娜 | 珀耳塞福涅 | 冥界的王后 |
| 薩圖爾努斯 | 克洛諾斯 | 朱諾與朱庇特的父親 |
| 帕爾開 | 摩伊拉 | 命運三女神 |
| 維斯塔 | 赫斯提亞 | 灶神；本套書的希臘史詩中沒有出現這位女神 |

本書另有一些神祇只見於拉丁語境，在希臘史詩中沒有對應的稱呼，例如丘比特（愛神，維納斯之子）、雅努斯（雙面門神）、歐爾庫斯（冥界之稱）、福努斯（拉丁努斯之父，林野之神）、庫柏勒（眾神之母，本書也稱「柏瑞辛提亞」）。他們的簡介見附錄A。

| 尤利西斯 | 奧德修斯 | 伊薩卡之王；本書也稱他「伊塔卡人」「埃俄羅斯的後裔」 |

## D3　地名與河流

| 本書用名 | 希臘語境稱呼 | 說明 |
|---|---|---|
| 帕爾拉西亞 | 帕拉西亞 | 卷八說即阿卡狄亞，埃萬德爾的故鄉；本書稱埃萬德爾為「帕爾拉西亞人」 |
